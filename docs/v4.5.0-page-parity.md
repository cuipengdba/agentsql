# v4.5.0 页面与定位验收矩阵

[中文](v4.5.0-page-parity.md) | [English](en/v4.5.0-page-parity.md)

状态：验收范围，尚未完成。对照基线为 [SQLBot 社区版 v1.10.2](https://github.com/dataease/SQLBot/releases/tag/v1.10.2) 的未修改本机镜像与浏览器。以下记录的是 2026-10-26 实际可见入口和流程；每个入口仍须继续补齐操作、响应、权限和错误行为的对照用例。AgentSQL 界面独立设计和实现，不复制原产品的页面代码、图标或品牌。

## 页面功能矩阵

| 能力区 | 固定基线已观察到的页面流程 | v4.5.0 交付和验收 |
| --- | --- | --- |
| 智能问数 | 新建、搜索和查看对话；选数据源、推荐问题、多轮追问；结果表、SQL、图表、执行日志、分析与预测入口 | AgentSQL 自有问数页面完成相同用户任务；原版请求、流事件、历史标识、图表数据与导出逐项对照；每轮重新授权并有持久审计 |
| 数据源 | 新建数据库或本地 Excel/CSV；文件预览、选表、保存；数据源列表、表结构、字段搜索、表备注、字段状态与数据预览 | 独立数据源页面覆盖连接、编辑、测试、文件导入、表列管理和删除；原版客户端请求形态逐项兼容；托管文件只能进入隔离数据源并按所有者授权 |
| 仪表板 | 树形列表、搜索、新建；画布可添加图表、富文本与 Tab，并提供预览、保存 | 独立画布支持创建、编辑、布局、查看、分享或嵌入、权限及导入导出；图表读数始终重新检查当前权限 |
| 小助手应用 | 基础应用与高级应用；名称、描述、跨域地址、模型和数据源设置；高级应用关联第三方数据校验 | 独立应用管理页与嵌入 SDK/API 完成两类应用配置、授权、会话、回调、域名校验和撤销；原程序不改接入参数验收 |
| 成员与权限 | 工作空间成员搜索和添加；规则组配置、行权限、列权限和受限用户选择 | 独立页面覆盖成员、规则组、行列规则及变更审计；查询、预览、图表、导出、MCP 和嵌入调用一致执行当前规则，撤权立即生效 |
| 术语与 SQL 示例 | 搜索、筛选、新建、启停、批量导入及全部导出；按数据源和高级应用限定 | 独立页面完成增删改查和批量操作；术语、样例只能作为已授权上下文，不能直接放行或执行样例 SQL |
| 用户与工作空间 | 系统用户搜索、筛选、添加和状态管理；工作空间列表、成员分配与类型 | 独立管理页面与原 ID 迁移完成用户、成员、工作空间和来源管理；跨空间读取与身份伪造必须拒绝 |
| 模型配置 | 模型列表、搜索、添加及系统默认模型 | 独立模型配置、连通测试、默认模型和故障关闭；本机真实模型通过测试。公网 Demo 明示模拟，不部署或调用真实模型 |
| 嵌入式管理 | 嵌入应用列表、搜索与创建 | 兼容基础/高级嵌入入口、令牌、SDK、回调、跨域和数据权限；原业务程序代码与配置校验值不变的切换测试 |
| 系统设置 | 问数参数：助手名称、思考过程、行数限制、SQL/日志展示、上下文轮数；系统变量搜索和新增 | 独立设置页只显示实际生效的参数；更新、持久化、重启恢复和权限检查逐项通过；变量按作用域隔离 |
| 账户与语言 | 修改密码、API Key、语言、关于、帮助和退出登录 | 独立账户页完成密钥轮换、语言切换和会话撤销；中英文页面与文档同步 |

## 两种产品形态

| 形态 | AgentSQL 的责任 | 对外表述的验证条件 |
| --- | --- | --- |
| SQLBot 安全网关 | 保留现有 SQLBot 问数界面，业务数据库只经 AgentSQL 做身份映射、表列/行规则、只读执行、脱敏与持久审计 | 原版 SQLBot 与真实数据库在隔离环境通过允许、拒绝、撤权、脱敏、故障关闭和审计链；说明适配版本与已验证数据库 |
| 独立问数产品 | AgentSQL 自己提供问数、数据源、图表、仪表板、助手、嵌入和管理页面，以及兼容 API/MCP | 停止 SQLBot 后，原客户端和业务程序在原地址、路径、标识、SDK 和回调下完成同一测试；无未实现页面或空壳接口 |

官网、GitHub 和 AgentSQL Web 应用同一套准确说明：AgentSQL 是独立实现的数据库安全与问数产品，可作为 SQLBot 的安全网关，也可独立提供问数能力。只有上述两种形态分别通过验收，才能宣称对应能力；“现有业务系统零改动替换”另需用户实际隔离环境的前后对照证据。页面、代码和素材保持 AgentSQL 自有品牌，当前发行版授权说明只呈现 Apache-2.0。

## 逐页完成判定

每一行至少记录可见入口、创建/读取/更新/删除、分页与搜索、错误与权限、持久化、重启/回滚，以及原版客户端响应差异；不能用静态页面、路由数量或模拟数据代替通过。模型相关真实测试在本机完成；线上只展示标明“模拟演示，不接入真实模型”的交互。发布前再核对中英文官网、GitHub 当前说明与文档、Web、Demo、安装包和 Release 指向相同的实际版本。
