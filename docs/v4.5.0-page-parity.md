## 两种产品形态

| 形态 | AgentSQL 的责任 | 对外表述的验证条件 |
| --- | --- | --- |
| SQLBot 安全网关 | 保留现有 SQLBot 问数界面，业务数据库只经 AgentSQL 做身份映射、表列/行规则、只读执行、脱敏与持久审计 | 原版 SQLBot 与真实数据库在隔离环境通过允许、拒绝、撤权、脱敏、故障关闭和审计链；说明适配版本与已验证数据库 |
| 独立问数产品 | AgentSQL 自己提供问数、数据源、图表、仪表板、助手、嵌入和管理页面，以及兼容 API/MCP | 停止 SQLBot 后，原客户端和业务程序在原地址、路径、标识、SDK 和回调下完成同一测试；无未实现页面或空壳接口 |

官网、GitHub 和 AgentSQL Web 应用同一套准确说明：AgentSQL 是独立实现的数据库安全与问数产品，可作为 SQLBot 的安全网关，也可独立提供问数能力。只有上述两种形态分别通过验收，才能宣称对应能力；“现有业务系统零改动替换”另需用户实际隔离环境的前后对照证据。页面、代码和素材保持 AgentSQL 自有品牌，当前发行版授权说明只呈现 Apache-2.0。

## 逐页完成判定

每一行至少记录可见入口、创建/读取/更新/删除、分页与搜索、错误与权限、持久化、重启/回滚，以及原版客户端响应差异；不能用静态页面、路由数量或模拟数据代替通过。模型相关真实测试在本机完成；线上只展示标明“模拟演示，不接入真实模型”的交互。发布前再核对中英文官网、GitHub 当前说明与文档、Web、Demo、安装包和 Release 指向相同的实际版本。

## 当前核验记录

2026-10-27 已清理 GitHub 历史 v0.4.0、v0.5.0 Release 正文中的过时推广内容和失效链接；API 回读确认相应内容已移除。v0.4.0 发布时的 GNU AGPLv3 许可证事实仍保留，历史 tag 与资产未改动。当前分支的官网、README 和文档授权文案扫描通过；公网官网与正式版本仍为 v4.3.0，须在 v4.5.0 完整验收后统一发布更新。

同日使用未修改的 SQLBot 社区版 v1.10.2 前端在本机连接 AgentSQL Go 候选服务，完成管理员登录、问数参数保存与刷新读取，以及用户管理页创建用户和刷新读取。原版页面读取登录参数和初始密码入口时，AgentSQL 明确隐藏共享初始密码提示，并不向浏览器返回固定密码。测试配置了隔离环境专用初始用户密码；这些原版专有前端脚本只用于本地对照，未加入 AgentSQL 产品资产。此证据尚不能覆盖其他页面、真实模型、原业务系统接入或零改动替换。

原版模型页的默认模型卡片与编辑表单已能打开，适配使用固定基线的通用 OpenAI 供应商编号 15 和大语言模型类型编号 0。当前空间已有默认模型可从原版页面保存名称和配置，刷新后仍保留；端点与可选密钥通过实例登录公钥加密，Go 服务仅对当前模型解密和审计写入。原版保存后的连通请求只探测已保存模型，不执行生成的 SQL；本机 Qwen 在 60 秒窗口内实际返回 `Model reachable`。另在隔离空工作空间使用未修改的原版“添加模型”表单创建 HTTPS 配置，POST 返回 200，刷新后默认模型卡片仍在；非回环 HTTP 地址按安全规则被拒绝，测试 HTTPS 地址的模型连通探测预期失败。当前 v4.5.0 草稿已新增当前空间的非默认第二模型目录、编辑、删除和已保存模型探测；服务端定向测试通过；未修改的原版浏览器创建第二个模型、刷新显示、改名并删除，默认模型保持不变。原版表单自带的 temperature=0.6 现可直接保存，重新打开仍显示 0.6；服务端定向测试验证数值实际进入本机模型请求，修改和清除也生效。AgentSQL 自有英文页面也保存并刷新读回 0.25，随后恢复为 0 并再次读回。随后自有页面创建第二模型、切为默认、恢复本机 Qwen 默认模型并删除测试模型；中英文目录控件均正常显示。自有 API 定向测试覆盖管理员权限、密钥不回显、版本冲突和可逆切换。仅此有界参数通过，其他高级参数仍拒绝。原版页面已将测试模型设为默认、刷新确认，再切回本机 Qwen 默认模型并删除测试模型；服务端注入审计写入失败时，模型交换整体回滚。跨空间映射、原版密钥轮换和完整真实问数矩阵仍未通过。原版 API Key 弹窗的创建、停用和删除在隔离环境中通过，但它的“账户完全权限”提示宽于 AgentSQL 当前受限 Key 的实际作用范围，完整接入兼容仍未通过。

2026-10-28 的后续候选版按固定 v1.10.2 前端的供应商编号，增加百度千帆、DeepSeek、腾讯混元、Gemini、OpenAI、Kimi、腾讯云、火山引擎、MiniMax 及通用 OpenAI 的配置身份保存和读回；这些编号仅复用已有 OpenAI 兼容请求协议，并未逐家验证真实云端模型。需要专用请求参数的阿里云、讯飞，以及未列入的编号仍明确拒绝。服务端测试覆盖九个新增编号的创建、原版详情回读、温度边界与不支持编号的拒绝；原版未修改浏览器实测 DeepSeek 新增、刷新、编辑及删除，默认本机 Qwen 保持不变。AgentSQL 自有中英文页面显示供应商选择及对应温度上限；MCP 模型列表可列出当前工作空间的非默认模型及供应商编号，不回传端点或密钥。正式供应商连通、真实问数和跨空间授权仍待逐项验收。

同一候选版还从未修改的原版问数页面调用本机 Qwen，针对合成数据源提交“列出地区和金额，仅查询两行”，受控响应返回 `east/10`、`west/20` 和审计号 735；刷新后历史数据再次经过网关读取，返回同样两行及新审计号 749。这只证明指定工作空间、数据源、问法和管理员路径，不能代替完整问数、权限撤销、异常恢复或原业务系统零改动替换的验收。

原版用户管理页的本地用户停用、再启用及“恢复初始密码”在隔离环境完成：停用与重置均令旧令牌返回 401；先设置的临时密码在原版重置后失效，部署者配置的初始用户密码可再次登录。原版系统变量页的文本变量完成创建、编辑、刷新持久化和删除。原版编辑与删除分别提交字符串 ID 与字符串 ID 数组；Go 适配层现在严格解析规范十进制字符串或 JSON 整数，继续拒绝越界与非规范值。原版删除返回 200，刷新后为空。变量仍未进入行权限求值，不能据此宣称变量规则生效。

2026-10-28，已补用户 XLSX 模板、批量导入和错误报告下载的原版 API 形态；仅在管理员身份和部署者明确配置初始密码时接受导入。当前仅接受本地普通成员；管理员批量创建在可安全降权和删除的完整生命周期实现前拒绝。有效行通过现有用户创建事务与管理审计写入，重复账号、管理员角色及不支持的外部身份逐行记入加密错误报告；普通成员与错误报告伪造 ID 被拒绝。定向测试覆盖成功、失败、禁用成员、初始密码和报告读取。本机 AgentSQL 自有中英文用户页完成模板下载、上传一条有效及一条无效记录、显示成功 1／失败 1、列表读回与错误报告下载。固定 SQLBot v1.10.2 源码中批量导入按钮被注释，未修改的原版页面没有可操作入口，因此目前只有兼容 API 和 AgentSQL 自有页面证据。旧 XLS、管理员与外部用户身份以及真实业务批量数据尚未验收。

原版工作空间页的“添加成员”弹窗固定请求候选分页 `1/1000000`；适配层仅对该候选接口接受此请求，候选人数超过 10000 时拒绝。隔离页面实测完成测试用户添加为普通成员、改为管理员、移除，并在刷新后确认该空间成员数仍为零。普通成员页和其他超大分页保持限制。此证据不覆盖原版批量操作及全部成员权限规则。

原版页面还完成工作空间重命名并在刷新后读回新名称；另建空空间的删除成功。含测试模型的空间删除被拒绝，资源保持原状；服务端现返回明确的资源或成员冲突错误。原版所提示的关联资源级联删除尚未实现，不能将空空间删除视为完整删除兼容。

原版默认模型卡片虽然有“删除”入口，页面点击后会先提示默认模型不可删除，不发送请求；直接请求后端时适配层返回 409 并保留模型及加密密钥，越权用户和其他模型 ID 分别被拒绝。原版“授权空间列表”此前错误显示 0 个；现在管理员读取当前模型所属的当前空间，弹窗正确显示 1 个。原版新增授权发送 `POST`，移除发送 `DELETE`：重复当前空间可无副作用返回，跨空间共享或移除唯一映射明确拒绝。服务端测试覆盖这些路径。非默认模型删除已通过服务端定向测试和原版浏览器确认；默认切换与切回已通过服务端定向测试和原版浏览器确认；完整模型映射仍未验收。

原版问数结果页对本机合成两行触发“数据分析”时，真实本机 Qwen 生成的文字在原版事件流和页面中显示。刷新后最初只读取会话元数据，导致分析文字消失；候选版现仅对分析/预测子记录重新执行当前授权查询、验证结果摘要和审计后返回历史文字。重建候选服务后，未修改的原版浏览器刷新并重新打开会话，历史分析文字显示成功。服务端定向测试还验证结果变化时不显示旧文字，以及撤销数据源绑定时整个历史读取关闭。其他分析问法、完整预测流程及权限组合尚未通过。
