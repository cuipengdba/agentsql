# AgentSQL v3.4.0 发布说明

**语言 / Language:** [简体中文](release-notes-v3.4.0.md) | [English](en/release-notes-v3.4.0.md)

状态：发布候选。正式交付以[验收记录](v3.4.0-acceptance.md)和 GitHub Release 为准。

## 本版改进

| 范围 | 变化 |
| --- | --- |
| 金仓列授权 | 在指定 KingbaseES V9R1C10 PG 模式单实例上，PostgreSQL 协议的 B2 目录关闭绑定器通过单表受限 `SELECT`、实时列授权、允许与越权列拒绝测试。该结论不包含 B5 写入。 |
| 金仓写入边界 | 实测发现 B5 DML 受影响行数与 PostgreSQL 合同不一致。对识别出的 KingbaseES 内核关闭会话、写事务、直接执行与 B5 DML 绑定入口，防止协议兼容被误当成写入安全证明。身份探测失败也关闭这些入口。 |
| Vastbase 查询成本 | G100 V3.0 Build 9、commit 30156 的版本识别覆盖真实多行版本字符串。`LIMIT` 下按已知物理扫描节点汇总扫描估算，未知结构与无效估算拒绝执行。 |
| Vastbase 类型与运维 | 指定单实例的整数、精确数值、文本、日期时间、布尔、二进制、JSONB 与空值真库复验通过；验证 TLS、证书热重载、密码轮换、权限撤销及断连恢复。 |

## 接入与升级

两款厂商结论只覆盖验收记录中的固定构建、PG 模式、单实例及合成数据。金仓 B2 仅对已证明的单一基础表受限 `SELECT` 开放；无法确定列来源的表达式、视图、JOIN、函数、子查询及通配符仍拒绝。金仓写入继续关闭。Vastbase 的独立只读适配器保持表级权限、脱敏和审计；其 B2 列授权真库探测尚未通过，因此继续失败关闭，不继承 PostgreSQL 绑定器结论。

升级前成套备份元数据、审计与配置，记录旧版本镜像及签名。先在隔离环境复核版本、许可、模式、最小权限账号、CA 和主机名，再用真实 MCP 调用验证允许、拒绝、脱敏与持久审计；失败时恢复旧版二进制与备份。其他厂商版本、集群拓扑、高可用切换及生产负载均需单独验收。
