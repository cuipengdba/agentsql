| 金仓外部客户端与恢复 | v3.4.0 当前二进制启动后，MCP Inspector 0.16.8 和 Dify 1.17.1 MCPClient 的允许/拒绝调用均通过，共增加 4 条持久审计。撤销 Agent 表策略及数据库 `SELECT` 后不返回敏感结果；恢复后脱敏查询通过。断开专用网络后不返回允许结果，恢复后再获脱敏结果及持久审计。 |

| Vastbase MCP 防护 | 真库查询、未授权表与写入拒绝、手机号脱敏、审批单次执行、变更后拒绝和持久审计通过。数据库 `SELECT` 授权撤销后不返回敏感值，恢复后重新脱敏并审计。网络断连期间不返回允许结果，恢复后再次获得脱敏结果与审计。 |
| Vastbase 外部客户端 | MCP Inspector 0.16.8 与 Dify 1.17.1 MCPClient 各完成一次允许和 R010 拒绝调用，新增四条持久审计；所有允许结果保持手机号脱敏。 |
| Vastbase TLS 与轮换 | 正确 CA/主机名连接成功；错误 CA、错误主机名和明文连接拒绝。服务端证书热重载后，新连接使用新证书并通过校验；只读账号密码轮换后新密码可用、旧密码拒绝。 |
| Vastbase 有界负载 | 12 次真实 MCP 调用、并发 2、连接池上限 2，12 次均返回脱敏值和独立持久审计；隔离测试 P50 6.8 毫秒、P95 42.4 毫秒。仅为小样本观测，不是生产 SLA。 |
| 通用回归 | Go 1.26.10 容器 `go test -short -timeout 20m -p 2 ./...` 通过。既有 10 Agent/50 同步请求用例在 Docker tmpfs 中连续 3 轮通过；持久化临时目录会触发已记录的 SQLite 同步写入超时，见[历史诊断](v0.5-known-issues-task7.md)。 |

## 未开放与复测要求

Vastbase B2 探测在真实 G100 上返回 `AUTH_DATABASE_ERROR`，列授权继续失败关闭。金仓 B5 写入不满足 PostgreSQL 行数合同，继续关闭。两款数据库都不声明完整生产支持。正式主备、集群、其他 Build、厂商认证与生产负载均未验收；上线前还需按自身证书、最小权限和运维故障流程复测。
