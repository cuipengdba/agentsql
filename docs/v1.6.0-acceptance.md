## 代码和页面边界

- PostgreSQL、达梦/Oracle 窄 SQL 路径与 MySQL 两条结果路径在读行结束后再次检查请求上下文；取消或超时不得交付已收集的敏感行。`TestPostgresQueryRejectsCancellationAfterRows` 与 `TestSQLQueryRejectsCancellationAfterRows` 已在 Go 1.26 容器通过。
- 达梦连接使用按数据源语句超时设置的网络截止时间，并在取消时直接关闭与该请求绑定的物理连接；为使建连上下文与单次请求绑定，达梦只读池不保留空闲连接。`TestDMDeadlineConnClosesBlockedSocket` 已通过，真库锁等待用例也通过；连接复用减少带来的性能影响尚待负载测试量化。
