v4.18.0 验收独立 MCP Server 和基本助手、Type 4 页面嵌入。固定 SQLBot Community v1.10.3 问数矩阵覆盖 I2 与 I3。确切发行提交通过两项新增验收和既有场景复测后，目标为 20/25（80%）。[评分合同](sqlbot-community-chatbi-score-v1103.md)

## 独立 MCP Server

在网关登记 PostgreSQL、专用只读账号和调用方专用 Agent。启用 PostgreSQL 授权的部署在登记新数据源后，按部署流程重新启动网关，确认目录授权已激活。通过控制台配置表权限并绑定所需列。MCP 客户端使用独立 Agent 凭据连接 Streamable HTTP `/mcp`，调用 `list_datasources`、`list_schema` 和 `query`。可见结构、受控查询、结果和审计分别核对。

验收使用固定社区镜像内的 Python MCP SDK，在隔离真实 PostgreSQL 中对照两张合成表。验证已授权查询、有数据库读权限但没有网关授权的表、密钥轮换后旧凭据被拒绝，以及数据库中断与恢复。记录实际返回的行和网关审计。[三种使用方式](PRODUCT_MODES.md)

## 基本助手与 Type 4 页面嵌入

通过专用嵌入监听器开放批准的宿主来源和数据源。基本助手按指定游客身份执行。Type 4 页面由宿主应用签发短期身份声明，查数时使用当前成员的个人绑定。两个入口均以现行权限检查历史和导出。管理监听器保持各自的访问与帧策略。

使用未修改的固定社区 SDK、本地模型、真实网关和合成 PostgreSQL 数据验证中文界面的问数与历史。禁用助手或撤销授权后，验证旧历史、客户端状态与网关查询审计。截图包含独立问数或明确标注的原版客户端。公网 Demo 明示模拟模型与合成数据。[SQLBot 客户端接入](SQLBOT.md)
