## 安全与适用范围

AgentSQL 是独立实现的数据库安全与问数产品：既可为现有 SQLBot 部署提供受控数据库网关，也可使用自己的问数与管理页面。兼容对照只证明上述固定客户端、合成数据和指定操作，不代表 SQLBot 社区版全部功能或页面已经复写完成。用户业务系统的零改动替换仍需其隔离环境做切换前后对照，属于 v4.5.0 的独立验收门槛。

嵌入应用签名密钥只在受权限保护的管理接口中可见；公开的应用握手不返回密钥。应用禁用、密钥轮换、用户状态或授权变化会使后续读取失效。嵌入应用指定数据源列表时，请求还受该列表限制；未指定时沿用签名账号当前的授权数据源。

当前列级安全模式会拒绝无法证明安全的聚合、排序或复杂 SQL；本机实测的 `count(*)` 与排序请求均未释放结果，不能表述为已支持。图表复杂映射、仪表板分享、全部助手回调、API/MCP 兼容矩阵及实际业务接入仍按后续版本验证。公网 Demo 中涉及模型的交互只作明确标注的模拟，不运行或调用真实模型。
