## 支持边界

PostgreSQL B2 列级授权执行器与只读审批尚未组合验收；B2 开启时审批申请失败关闭，完整审批链仅覆盖明确关闭 B2 的隔离配置。本版未提升任何数据库的生产支持级别。控制台在 390px 宽度下存在横向溢出，后续界面版本处理；公网 Demo 不代表生产 SLA。
