# AgentSQL v3.0.1 设计

**语言 / Language:** [简体中文](v3.0.1-design.md) | [English](en/v3.0.1-design.md)

## 用户问题

官网和控制台此前只有中文，GitHub 英文 README 停留在旧版，海外用户难以理解当前能力边界。控制台左侧菜单随着条目增加，在显示缩放较大或浏览器 CSS 视口较矮时，底部条目被裁切，无法滚动到达。

## 范围与实现

- 官网提供中文 `/`、英文 `/en/`；Live Demo 安全入口提供 `/demo/` 与 `/en/demo/`，各页有显式语言切换和 alternate/canonical 元数据。英文入口把 `?lang=en` 传给独立 Demo 控制台。
- GitHub 项目 README 提供中文与英文链接，英文 README 与当前版本对齐。GitHub 平台界面的语言由用户在 GitHub 设置。
- Web 控制台登录页及页头提供语言按钮。浏览器持久保存选择，接受 `?lang=en|zh` 深链。Ant Design、日期和数字跟随语言。既有页面的静态文案用受检入库的英文目录覆盖；新增界面应使用显式 locale key。SQL、代码、可编辑字段及查询结果值不翻译。
- 左侧菜单放在独立可聚焦的 flex 滚动区域，品牌区固定，短视口可使用鼠标、触摸板或键盘抵达末项。

## 兼容与安全边界

无 API、数据库协议、权限、执行、脱敏、审计或 schema 变更。英文目录涵盖当前静态界面文案；从后端传入且恰好与目录键相同的非结果值仍可能被识别为界面文案，新页面应逐步迁移到显式 key。详细操作文档和 PDF 仍为中文，英文官网明确标注。数据库适配范围沿用 v3.0.0 与各适配版证据。

## 验收

检查中英文站点、Demo 安全入口、README 链接、控制台登录与至少 20 条业务路由、语言持久化和深链；在短 CSS 视口验证菜单末项可见；运行 Web 类型检查、测试、i18n 目录检查、生产构建、Go 回归和官网静态检查。发布门禁见[验收记录](v3.0.1-acceptance.md)。
