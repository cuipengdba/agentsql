# AgentSQL v4.17.0 数据接入与受控问数

**语言** [简体中文](v4.17.0-query-guide.md) · [English](en/v4.17.0-query-guide.md)

## 使用 AgentSQL 独立问数

1. 安装签名问数组件和网关，在问数服务配置本地文本模型。使用管理员账号进入网关数据源管理，登记 PostgreSQL 及专用只读账号，然后测试连接。
2. 为成员和授权对象配置个人绑定与表列权限。在问数服务配置该绑定后，以成员身份登录，选择已授权的数据源并提出业务问题。
3. 核对结果、生成的 SQL 和网关审计编号。访问历史或下载时，网关会按当前权限重新获取数据。

托管 CSV/XLSX 需要在网关启用独立文件导入配置，分离文件发布账号和只读账号。管理员上传文件、预览字段、选定工作表并保存；使用已授权的表进行问数。原版 SQLBot Community v1.10.3 的文件流程在验收中使用了两表工作簿和带中文列的 CSV。[部署与使用方式](PRODUCT_MODES.md) · [SQLBot 客户端接入](SQLBOT.md)

## 使用独立 MCP Server 网关

在网关为调用方创建专用只读 Agent，指定数据源和授权对象。将网关的 MCP 地址及该 Agent 的凭据配置到 MCP 客户端，依次读取 `list_datasources`、`list_schema`，再使用 `query` 执行受控查询。按调用方、数据源与审计编号查看执行结果。[MCP Server 使用步骤](PRODUCT_MODES.md)

## 同时启用问数与 MCP

使用同一个网关登记和管理连接。员工问数使用当前用户的个人绑定，外部 MCP 客户端使用独立 Agent。数据库账号轮换时，在维护窗口保存新凭据后重启网关以清理旧连接池，再测试连接、问数与工具调用。撤销用户绑定或 Agent 访问后，核对旧历史与工具调用的拒绝结果。[权限与验收记录](v4.17.0-acceptance.md)
