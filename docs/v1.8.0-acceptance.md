## 边界与后续验证

1. 该试用许可实例没有真实主备拓扑。正式许可、复制、主备切换、故障终态和生产负载均**未验证**；单实例重连、证书热重载不能替代 HA。
2. 本版不扩大 SQL 子集，不给 Vastbase 授予 PostgreSQL B2 列级绑定或 B5 跨请求事务能力。其他 G100 Build、协议模式、CPU/系统及厂商驱动未验证。
3. 达梦 DM8 服务端身份可验证的 TLS 与正式主备切换继续未验证；金仓和瀚高的能力边界仍以各自正式验收为准。
