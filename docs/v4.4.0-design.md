# v4.4.0 设计：管理、数据源与接入矩阵收敛

**语言 / Language：** [简体中文](v4.4.0-design.md) | [English](en/v4.4.0-design.md)

状态：设计中，尚未发布。固定对照为 SQLBot 社区版 v1.10.2（`aa41fc1033bb974a703df9200a98ec8b9eec5f25`）；AgentSQL 使用自己的 Go 服务、Web 页面和品牌。v4.3.0 代码的静态路由对照为 135 个上游方法路径中 65 个同形注册、70 个未在原生问数服务注册；部分接入路径由 AgentSQL 网关另行提供。路由数量只用于发现工作项，不证明行为兼容。

## 用户目标与范围

v4.4.0 覆盖社区版数据源、用户、工作空间、成员、模型、系统变量、权限规则、表关联、语言与 MCP 管理流程，完成本地数据迁移和离线部署矩阵。每项都要求原版客户端和 AgentSQL 自有页面完成同一用户任务；全部功能与真实业务零改动替换仍是 v4.5.0 的最终门槛。

| 工作流 | 实现合同 | 发布验收 |
| --- | --- | --- |
| 数据源管理 | 独立页面及原版 API 的连接、测试、选择表、同步结构、表列备注、文件导入和删除；每次访问确认工作空间、所有权及后端数据库支持边界 | 原版页面与自有页面逐项对照；跨空间 ID、更换连接参数、数据库断线、托管文件故障均拒绝或明确失败 |
| 用户与工作空间 | 用户搜索、新建、禁用、密码轮换、语言；工作空间创建、编辑、成员授予与撤销；ID 迁移保留原值与关系 | 原版管理页和自有页面完成增删改查、重启恢复；非管理员、越权、禁用及旧令牌负向集 |
| 模型与变量 | 工作空间模型列表、默认模型、连通性和变更审计；系统变量按作用域校验、持久化及重启恢复 | 本机真实模型通过允许与故障测试；公网只展示标注模拟的页面，绝不保存或调用云端模型密钥 |
| 权限与表关联 | 数据源规则组、用户授予、行列权限和表关系配置；问数、预览、图表、导出、API、MCP 和嵌入共用当前授权 | 撤权后旧历史、图表和嵌入不可读；审计写失败、规则不确定、连接断开时故障关闭 |
| 接入与迁移 | 社区版 API/MCP 的身份、会话、错误和事件形态逐项对照；只读预检、隔离导入、成套备份及恢复 | 原版客户端不改动完成选定流程；离线新装、v4.3.0 升级、失败回滚、双架构包与签名验证 |

## 安全调用链

浏览器、原版 API/MCP 和嵌入 SDK 进入 Go 问数服务后，先验证令牌、用户与工作空间状态，再验证应用或成员范围及当前数据源/表列/行规则。元数据查询和生成 SQL 进入 AgentSQL 受控网关；返回结果脱敏并写持久审计，任何必需步骤失败都不释放结果。客户端提交的用户、工作空间、规则、模型或连接信息只是请求参数，不成为授权事实。管理写入需要版本并发控制和同事务审计。

## 数据库与语言边界

对照 SQLBot 社区版数据源列表逐项记录连接协议、厂商版本、TLS、元数据、最小权限、查询、撤权和故障结果。AgentSQL 已有网关数据库能力不会自动成为问数服务的完整数据库支持；仅把实际通过的组合写入 v4.4.0 兼容矩阵。原版多语言入口按固定基线核查；翻译须覆盖自有页面、错误、帮助与模型提示词，原文、数字和审计不得因语言切换改变。

## 发布阻断项

每个工作流提交可复现的浏览器与接口证据，运行 Go/Web/双语文档 CI、安全负向集、真实本地模型及指定数据库、断网安装、升级与成套恢复。签名资产、双架构镜像、GitHub Release、官网和公开 Demo 与同一源码提交对齐。未通过的入口不得用空壳响应或模拟数据标记为已支持；v4.5.0 的完整页面、接入与业务系统替换结论另行验收。

## 当前开发记录

已实现独立账户设置页、密码变更与语言保存，以及管理员用户列表、筛选、读取、创建、编辑、重置密码和启停页面。用户创建和密码重置需要管理员在自有页面输入密码，或由部署者设置 `AGENTSQL_CHATBI_INITIAL_USER_PASSWORD`；不会使用固定的公开默认密码。账号索引与管理审计在同一事务内写入，审计失败则回滚。用户编辑、密码重置与状态变更也与管理审计同事务完成，并撤销旧令牌。工作空间读取、创建、改名及空空间删除已接入原版 API 与自有用户页面；改名同步更新成员名称，删除拒绝仍有成员或数据的空间。成员批量授予、撤销和权重调整采用同事务审计；成员列表及候选用户查询有分页和权限检查，自有用户页面可操作成员关系。SQLBot MCP HTTP 辅助接口已有令牌、会话、工作空间、数据源和问数路径。MCP 数据源列表只返回公开元信息；会话首次提问前才绑定当前成员有权访问的数据源；问数沿用受控网关、脱敏、审计和持久化结果门槛。已针对跨工作空间、令牌撤销和缺失网关审计建立负向测试。原版超级管理员跨全部旧空间访问及第三方助手 MCP 路径尚未完成；用户创建和重置密码仍需与原版客户端及部署配置对照，流式文本也需逐事件对照。当前分支静态路由对照为 135 个上游方法路径中 99 个同形注册、36 个未在原生服务注册；这不表示已实现完整功能或原业务零改动替换。

用户删除现支持单个与批量请求；账号索引、用户私有加密对象与管理审计在同一事务内变更，旧令牌随用户记录删除而失效。仍有托管文件导入或其数据源的账号暂拒删除，需先完成网关资源回收的专项流程。
MCP 模型列表已提供受令牌和成员关系保护的公开模型元信息，不暴露端点或密钥；原版无凭证请求仍不兼容，需要安全的身份适配。

原版 `mcp_model_list` 的仅含 `oid` 请求体，现在可配合已有的 `X-SQLBOT-TOKEN: Bearer` 请求头使用；服务端从当前令牌重新核验用户和空间成员关系，并在响应前再次核验。无请求头的匿名调用、跨空间、失效令牌及同时提供请求体和请求头两份凭证均拒绝。原版完全无凭证调用仍是兼容缺口，不能为了凑齐路由而开放模型枚举。

新建工作空间时，创建者的管理员成员关系与目录、审计在同一事务内写入；删除无其他成员或数据的空间时同步撤销该成员关系。成员可用原版工作空间切换接口更新当前令牌空间及下次登录默认空间；两项选择与审计同事务持久化。原版超级管理员对所有旧空间的访问行为仍待单独验收。

AgentSQL 自有 Web 页面现在在账户区显示已加入的工作空间并调用同一切换接口。切换成功后刷新页面，重新按新空间读取数据源和历史；只有一个空间时不显示切换控件。

系统变量管理接口与 AgentSQL 自有中英文页面已开始实现：自定义变量按工作空间加密保存，创建、修改、删除与审计同事务；管理员可分页、筛选及编辑，普通成员不能读取。当前变量还没有接入行权限计算，页面明确说明配置不会改变查询权限；这不属于可发布的完整变量功能。

当前工作空间的模型配置现有 AgentSQL 自有中英文管理页面和 API：管理员可在空工作空间首次创建默认模型，也可读取不含密钥的模型信息、按版本号更新模型标识、端点、输出上限及密钥；留空密钥保持原值。创建、更新均与管理审计同事务提交；重复创建、旧版本并发写入及审计失败会拒绝或回滚。此处仍仅管理单个工作空间默认模型；原版 SQLBot 全局模型目录、多个模型、工作空间映射、任意配置连通测试及真实模型端到端验收未完成。

管理员可在该页面对已保存模型发起有界连通测试；测试请求不接受客户端端点或密钥，只调用当前工作空间的模型，生成的测试 SQL 不进入数据库，成功响应不回显模型输出或秘密。此测试只证明当时模型服务响应；原版 SQLBot 的新增模型时任意配置连通测试、真实模型问数和故障关闭仍需单独验收。

账户 API Key 的原版列表、创建、启停和删除接口及 AgentSQL 自有双语页面已开始实现。每个账户至多五个密钥，控制库加密保存；创建、状态变更、删除与管理审计同事务提交，删除用户时同时清理密钥及访问索引。`X-SQLBOT-ASK-TOKEN: sk <JWT>` 当前只接入受限问数及数据源读取路由，每次核验 HS256 签名、密钥状态和当前用户；不能访问密钥管理接口。仍需以原版客户端逐请求验证 ASK 令牌载荷、允许路由、错误形态以及真实业务接入，不据此宣称全部 API Key 兼容。

原版模型管理页的列表和详情读取入口已接入当前工作空间默认模型，限制为管理员；列表支持名称筛选，详情只显示有无密钥而不返回密钥。原版首次创建和现有默认模型编辑也已接入，均保留工作空间、供应商及配置限制。AgentSQL 尚无原版全局多模型目录、模型映射和原版页面完整增删改流程，此处是逐页兼容工作的受限阶段。

原版 v1.10.2 前端实测发现模型列表需使用其有效的“通用 OpenAI”供应商编号 15 和大语言模型类型编号 0；此前的编号会让卡片或编辑表单抛出脚本异常。修正后原版卡片及编辑表单可打开。原版首次创建与编辑提交的端点和可选密钥使用与本实例登录相同的 RSA 公钥加密；Go 适配层只允许在当前空间首次创建通用 OpenAI 默认模型，或编辑已存在的默认模型，编辑时保留未填写的旧密钥，并沿用加密存储、版本检查和管理审计。重复创建、明文端点、其他供应商及高级参数被拒绝。原版保存后的模型连通请求只探测已保存配置，不执行模型生成的 SQL；首次创建时原版提交的空模型 ID 也只指向刚保存的当前空间模型。2026-10-27 本机原版页面保存并刷新现有模型名称，60 秒本地 Qwen 探测实际返回 `Model reachable`；随后在隔离空工作空间通过原版“添加模型”表单创建 HTTPS 配置，刷新后卡片仍在。非回环 HTTP 端点被安全规则拒绝，测试用 HTTPS 端点的连通探测预期不可用。单元测试覆盖越权、错误输入、密钥保留、重复创建及模型故障。全局多模型目录、第二个模型、删除、默认切换、原版密钥轮换和完整真实模型问数矩阵仍未通过验收。

原版数据源页面的 `chooseTables` 写入入口现仅支持已认领的托管 CSV/XLSX 数据源。管理员提交的表名必须属于该文件已导入的表，当前网关元数据也必须可见；选表范围与管理审计在同一控制库事务内提交。AgentSQL 自有的中英文数据源页面可查看已导入表并调整选择。取消全部选表会关闭该数据源的表发现和 SQL 读取，重新选择后仍逐次经过网关权限与审计。数据库连接型数据源的选表尚未实现，不能将此接口视为完整数据源管理。

原版问数参数页的读取和 multipart 保存入口，以及 AgentSQL 自有的中英文问数设置页，现可管理助手显示名称、思考过程显示、SQL/日志显示和 0–3 轮上下文。设置加密持久化，写入与管理审计同事务；模型实际收到的历史轮数跟随设置，用户撤权或审计失败时写入关闭。查询行数上限始终开启，提交关闭请求会拒绝；这些显示选项仅控制客户端呈现，不是隐藏 API 响应字段的权限规则。原版登录参数的只读入口现在明确表示使用账号密码登录并隐藏共享初始密码；管理员默认密码查询返回空值，不向浏览器发布固定密码。原版登录与平台参数的完整配置、更多上下文轮数及完整设置页仍待单独实现和验收。

2026-10-27 在本机将未修改的 SQLBot 社区版 v1.10.2 前端静态资源与当前 AgentSQL Go 候选 API 接到同一测试域名：原版页面完成管理员登录、进入参数配置、修改问数名称和上下文轮数、保存、刷新后读取；随后在配置测试用初始密码的隔离控制库中，原版用户管理页隐藏共享密码提示并完成用户创建，刷新列表显示新用户。原版前端专有静态脚本仅用于本地兼容对照，没有加入 AgentSQL 产品资产。该证据只覆盖上述路径；原版其他页面、密码重置、停用、原业务系统接入以及完整零改动替换仍未验收。

同一隔离候选服务在当前默认工作空间通过未修改的原版问数页面向本机 Qwen 模型提交“列出地区和金额，仅查询两行”；合成数据源返回 `east/10` 和 `west/20` 两行，原版记录数据接口返回网关审计号 735。页面刷新后再次打开会话，记录数据接口重新读取同样两行并取得审计号 749。此证据仅覆盖该合成数据源、一个问法和一个管理员账号；复杂问法、撤权、故障、更多图表与真实业务替换仍须逐项验证。

原版用户管理页在隔离环境停用再启用一名本地用户，停用后旧令牌返回 401，重新启用也不恢复旧令牌。将用户密码先改为另一测试值后，原版“恢复初始密码”按钮返回 200；修改后的密码无法登录、重置前令牌返回 401，而本机配置的初始用户密码可以重新登录。此流程依赖部署者配置初始用户密码；不能把测试值当作公开固定密码。

原版系统变量页面创建文本变量 `test_region_filter=east` 后，编辑提交的字符串 ID 起初返回 422；适配层改为同时接受规范十进制字符串和 JSON 整数，不经过浮点转换，并继续拒绝非规范或越界 ID。修正后原版页面将值改为 `west`、刷新后仍显示 `west`，再以字符串 ID 数组删除，接口返回 200，刷新后为空。创建、更新和删除仍在当前工作空间加密保存并与管理审计同事务。变量尚未接入行权限计算，此页面流程不能证明变量规则实际生效。

2026-10-28 增加原版 `kv` 键值型系统变量的有界保存和 AgentSQL 自有双语键值编辑器。隔离本机的自有页面创建 `north: 北区`、`south: 南区`，将 `north` 改为 `华北区`，刷新后仍保留；未修改的 SQLBot 社区版前端读取同一变量，再把 `south` 改为 `华南区`，保存后列表即时显示新值。原版前端另创建 `channel: 微信`，AgentSQL 自有页面也读取并显示第二个变量。服务端拒绝重复键、空键值、额外字段、错误类型和越权修改；变量值仍未接入行权限计算，此证据只覆盖变量管理，不代表变量驱动的查询规则已经生效。

同日补齐数值与日期变量的双端区间形态。原版页面创建 `0～100` 数值区间，AgentSQL 自有页面读到零起点并改为 `5～100`，原版页面刷新后显示新值；自有页面创建 `2026-01-01～2026-12-31` 日期区间，原版页面显示相同日期。服务端只接受两个有限数值或两个有效日期，拒绝倒置区间、缺失端点及多余端点。该变量配置仍不改变查询权限；行权限解析尚未实现。

用户管理接口现可在当前工作空间创建、修改和清除系统变量绑定，并验证所选文本/键值属于定义值、数值/日期处于定义区间。绑定随用户加密持久化，管理写入沿用同事务审计；读取只返回当前工作空间的绑定，省略更新字段会保留现有绑定，显式空数组才清除。原版 SQLBot v1.10.2 下拉框对先前生成的 16 位变量 ID 显示错位；隔离浏览器试验将 ID 映射为较短数值后显示正常。因此新建变量改用 13 位随机 ID，并在创建碰撞时拒绝覆盖已有变量。用实际候选服务和未修改的原版前端创建变量（后更名为 `原版13位变量`，ID `1868975266965`）、将 `south` 绑定到测试用户，再刷新用户编辑页，名称和取值均正确回显；原版页面更名后用户页也显示新名称。原版“添加用户”表单又创建了 `original-bound-v440` 测试账号并选中相同绑定，刷新接口读取到 `variableValues:["south"]`。AgentSQL 自有用户页现在可编辑当前工作空间的文本/键值、数值和日期绑定，并在界面说明它们尚不参与行权限。自有英文页面读取上述原版账号的绑定，新增 `25` 数值绑定并通过接口读回，再移除该数值绑定且保留原文本绑定；英文新建用户页创建 `native-bound-v440` 并保存 `south` 绑定。此前生成的 16 位测试变量仍可能在原版用户下拉框错位；这批草案数据不构成迁移验收。绑定目前只用于管理和展示，尚不驱动行权限或任何查询授权。

原版工作空间“添加成员”弹窗固定请求候选人分页 `1/1000000`。适配层只在候选人接口接受这一精确请求，实际候选人超过 10000 时拒绝返回；普通成员分页和其他超大参数仍被拒绝。2026-10-27 本机原版页面在隔离工作空间打开弹窗、选择测试用户并添加为普通成员，随后切换为管理员、移除，刷新并重选该工作空间后成员数仍为零。权限变化的令牌失效由工作空间服务测试覆盖；原版页面的更多角色和批量操作仍需逐项验收。
