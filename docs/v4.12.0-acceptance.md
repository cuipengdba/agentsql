# AgentSQL v4.12.0 验收与范围

AgentSQL 是独立 AI 问数 Agent 与独立 MCP Server 数据库安全网关。本版聚焦历史、导出和会话生命周期：导出收据提交后仍复核当前权限与身份；原生页面清空失败后的旧结果，并隔离迟到的历史响应和下载。问数服务不依赖 SQLBot 运行。

## 精确版本与环境

正式构建源码为 `8d5f7c25dabf9a6661239254b5cdcd59c33e237a`，五项[精确 CI](https://github.com/cuipengdba/agentsql/actions/runs/42577824627)全部成功。真实运行使用同一签名原生包的 ChatBI 和网关，固定 ONNX、本地 Qwen3-4B-Instruct-2507-Q4_K_M、PostgreSQL 17.11 与128张显式受权合成表。主表只有三行合成数据。ChatBI为2CPU/4GiB，网关和数据库各2CPU/2GiB，文本模型4CPU/8GiB，运行于Windows Docker Desktop的Linux AMD64环境。

AMD64二进制SHA-256为 `5dcb205cbbc25f1d3b2d868c0fafcad93f5cccaddf66ddb0d80eb79e98c9780e`；ARM64为 `dc0fc24ab1c3ed682b72896cce99207f25148847af4340cfe1a1612879a692ee`。运行中的固定ONNX为 `716d380a65efde09842642540749bc0535b05f2c66737fea1106731b8b0d7ffb`。模型归档中的运输清单不属于运行模型目录；九个运行文件逐项核对哈希后使用。撤销测试通过运维CLI比较并删除同一用户的私有问数映射；网关侧映射未更改。

## 签名、升级与发布

17项内层资产和外层离线传输包使用正式Ed25519发行密钥，分别以独立可信公钥验签。外层包SHA-256为 `3e4b30ae95ff5b2093d574594c9c95a460bd51572355bbd8e507893eb33b89e5`。AMD64与QEMU ARM64在断网Debian12、PID1 systemd环境各完成新装、正式v4.11升级和首次启动失败回滚，六项完整退出0；核对真实服务、健康、版本、模型哈希、SQLite标记与完整性。QEMU不代表ARM实机。

正式下载、GHCR摘要及公网核验见[Release](https://github.com/cuipengdba/agentsql/releases/tag/v4.12.0)。官网展示本版中文实拍；公网问数Demo仍明确使用模拟结果和合成数据。

## 性能与未测边界

单次冷态原生API问数连同当前历史读回为80.469秒；原版页面一次问数记录约42.245秒。ChatBI重启并健康后，未先做历史重查的第一个CSV为HTTP200、12.686秒，随后XLSX为HTTP200、10.310秒。它们是共享测试主机上的单次观察，不是p95、吞吐或生产SLA。

原版历史通过记录来自原版页面实际创建的问数；直接API自造初始占位记录的混合客户端重开曾停留加载，未计通过，不承诺任意客户端历史互换。列全部禁用后的含糊追问曾超过45秒客户端预算，不算通过；指明目标表、采用与其他真实问数一致的300秒验收预算后，返回错误事件且无结果和新查询。初次本地广泛短测曾在SQLite fsync处超时，未计通过；最终精确CI全包短测与本地tmpfs短测成功，持久化则由真实Linux卷和systemd场景单独核验。

未在用户真实业务系统验证，不承诺80%或100%兼容、零改动切换、任意数据库创建、云模型真实推理或新的数据库生产支持等级。已发送到客户端或已下载的文件无法追溯收回；本版控制的是每次新的历史读取与下载响应。
