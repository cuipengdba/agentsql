# AgentSQL v0.7.0 验收记录

> 本记录区分截至 2026-10-16 已完成的隔离测试与 tag 建立后核验的发行闸门，不是生产环境验收报告。v0.6.1 正式资产、最终回退演练、v0.7.0 封板提交及对应 CI，以及 GitHub Release 资产、GHCR 与官网的实际结果，由 v0.7.0 GitHub Release 正文和发布证据记录；本文不提前声称通过。

## 证据口径

本轮检查针对 `feature/v0.7.0` 工作树在不同时间点构建的代码。部分检查之后仍有源码修复，因此这些结果不能合并表述为同一个不可变提交的完整验收。GUI 查询使用提交 `9429b25f800de1333d63feab72cc550fdb23f54f` 的 Linux amd64 测试包；该提交的 [GitHub CI](https://github.com/cuipengdba/agentsql/actions/runs/38815198187) 已成功。正式封板提交、干净工作树、实际命令与退出码以及从该提交重新构建的结果，以 v0.7.0 GitHub Release 正文记录为准。

数据库和客户端检查使用隔离实例、回环或私有网络、测试身份与合成数据。它们不代表真实客户环境、厂商认证、正式生产许可证、全部 SQL 语法或“完整生产支持”。封板提交及其 CI 以 v0.7.0 GitHub Release 正文和 tag 为准；版本范围和限制见[发布说明](release-notes-v0.7.0.md)与[部署指南](DEPLOY.md)。
