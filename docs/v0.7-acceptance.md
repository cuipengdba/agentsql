# AgentSQL v0.7.0 候选验收记录

> 状态：开发与验收中，尚未达到发布标准。本记录截至 2026-10-16，只说明已实际完成的本地检查和仍需执行的发布闸门；不是正式 Release 或生产环境验收报告。

## 证据口径

本轮检查针对 `feature/v0.7.0` 工作树在不同时间点构建的候选代码。部分检查之后仍有源码修复，因此这些结果不能合并表述为同一个不可变提交的完整验收。最终封板须记录提交、干净工作树、实际命令与退出码，并从该提交重新构建和复核。

数据库和客户端检查使用隔离实例、回环或私有网络、测试身份与合成数据。它们不代表真实客户环境、厂商认证、正式生产许可证、全部 SQL 语法或“完整生产支持”。版本范围和限制见[候选发布说明](release-notes-v0.7.0.md)与[部署指南](DEPLOY.md)。
