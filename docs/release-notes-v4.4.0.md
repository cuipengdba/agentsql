# v4.4.0 发布说明：管理流程与数据源关系

**语言 / Language：** [简体中文](release-notes-v4.4.0.md) | [English](en/release-notes-v4.4.0.md)

正式发布状态、签名资产和安装说明以 [GitHub Release](https://github.com/cuipengdba/agentsql/releases/tag/v4.4.0) 为准。此版是 SQLBot 社区版替代计划中的管理与数据源增量，仍保留 AgentSQL 独立问数和现有 SQLBot 数据库安全网关两种使用形态。完整功能与接入方式的后续目标见 [v4.5.0 开发 PR](https://github.com/cuipengdba/agentsql/pull/90)。

## 本版实现与本机验收

| 能力 | 验收边界 |
| --- | --- |
| 账号与工作空间 | 自有双语页面增加账号设置、用户和工作空间管理；原版 SQLBot v1.10.3 的管理员登录已在隔离控制库中对照。密码轮换、停用与成员撤销会使旧令牌失效；原版用户与工作空间全流程及完整角色矩阵仍待验证。 |
| 数据源备注与选表 | 托管文件及已由服务端绑定的 PostgreSQL/MySQL 数据源可在当前可见结构内编辑表、字段备注和选表；选表与绑定、管理审计一起持久化。本机原版页面对照了指定 PostgreSQL 备注流程，自有页面及 API 还验证了指定 MySQL 和 XLSX 往返。浏览器提交的连接配置不会创建新的数据库连接。 |
| 表关系与受控问数 | 原版 X6 页面和自有双语页面在一组 PostgreSQL 16 双表上完成读取、保存与刷新。当前授权下，本机 Qwen 生成两表聚合 JOIN，经网关执行并留下持久审计；取消相关表后旧关系和结果读取被拒绝。该结果不推广到其他数据库或任意 SQL。 |
| 管理兼容接口 | 增加用户、成员、工作空间、模型设置、系统变量、账户 API Key 与 MCP 管理的受限实现。各入口仍依当前身份、成员、绑定和管理审计校验；未完成原版逐页和逐接口对照的行为不列为完整兼容。 |

## 安全与已知边界

模型生成的 SQL 仍须通过 AgentSQL 受控网关。当前身份、数据源、表列、行规则或审计证明不足时，请求失败关闭；历史结果不能绕过撤权。公网 Demo 的模型交互仅为明确标注的模拟，本机真实模型验收不代表公网接入模型。

本版**不宣称**完整复写 SQLBot 社区版页面、API、MCP 或嵌入，也不宣称任何现有业务系统已零改动切换。原版任意连接创建和编辑、全局多模型目录、全部角色与失败分支、更多数据库及完整客户端矩阵仍按后续验收推进。用户真实业务系统的切换在 v4.5.0 发布后由用户推进，发现的问题另行规划。

## 升级与交付

升级前应保存控制库、审计、托管文件和加密密钥。正式资产须从本版标签所对应源码构建，使用包外可信公钥核验清单及 Ed25519 签名；双架构断网安装、v4.3.0 升级与失败回滚按 [发行验收流程](RELEASE_PROCESS.md) 核对。PostgreSQL 原生绑定器位于数据库服务器，应按独立可信包与实际运行角色完成预检。未通过的数据库模式或接入方式不因安装成功而成为生产支持。
