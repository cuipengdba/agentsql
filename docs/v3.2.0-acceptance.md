# AgentSQL v3.2.0 候选验收

**语言 / Language:** [简体中文](v3.2.0-acceptance.md) | [English](en/v3.2.0-acceptance.md)

状态：候选验收进行中。以下仅记录已完成的隔离合成环境检查；正式资产、CI、官网和公网 Demo 尚须单独复核。

## 实测环境与结果

隔离网关候选镜像、固定 SQLBot v1.10.2 派生镜像、MySQL Community Server 8.4.11 合成订单数据、本地模型和 PostgreSQL 16 B2 测试容器。SQLBot 的业务数据源直连地址无效，业务 SQL 必须经过 AgentSQL。MySQL 绑定使用真实登录用户、独立只读 Agent、合格的 `agentsql_demo.表名` 权限和显式的数值结果别名。

| 检查 | 结果与证据 |
| --- | --- |
| SQLBot MySQL 结构与图表 | 真实登录、表发现与选表通过；模型生成按订单状态分组的 MySQL SQL，返回 4 行和有数值纵轴的柱状图。问答的 6 项检查全真，用时 110.59 秒。合成环境本地证据为 `sqlbot-mysql-group-chart.json`。 |
| MySQL 人员与 SQL 边界 | 独立真实网关检查 7 项通过：带反引号的授权查询产生持久审计 ID；跨用户、跨工作空间、跨数据源、写语句、副作用函数及多语句均拒绝。另一 SQLBot 工作空间的普通登录用户看不到 MySQL 数据源。 |
| 持久审计 | 候选网关管理 API 可查到该 MySQL Agent 的允许及拒绝记录；审计编号在隔离副本上连续产生。 |
| PostgreSQL B2 审批 | PostgreSQL 16 真库测试通过：审批前无业务读取；批准后按实时列授权执行一次；受限列用于筛选、排序和函数派生均被拒绝，重放失败关闭。 |
| MySQL 8 真库流水线 | `TestPipelineMySQL8E2E` 通过，覆盖允许/拒绝、动态计划、只读阻断、脱敏和错误分类；耗时约 296 秒。 |
| 回归与升级 | 全量 Go 短测试、固定 SQLBot 镜像内 Python 35 项、Web 18 个文件 58 项、TypeScript 构建、英文目录 1466 项、双语文档结构 198 份均通过；PostgreSQL 18 组合/分库升级及审计回退测试通过。 |
| 独立部署升级与恢复 | 从 v3.1.0 合成实例用 SQLite 在线备份生成两份隔离副本；一份启动 v3.2.0，另一份恢复启动 v3.1.0。两者健康、SQLite 完整性、schema 24 与原有 370 条审计记录均通过；演练容器已停止。 |

## 验收边界

本地 MySQL 图表依赖明确配置 `order_count` 等数值结果别名；单个总数的问答由模型选择表格，并非图表能力失败。SQLBot 聊天记录未保留适配器内部的 `agentsql.audit_id` 扩展字段，因此审计以网关持久记录为准。当前证据只覆盖上述版本及合成单实例，不代表全数据库、集群或生产 SLA。
