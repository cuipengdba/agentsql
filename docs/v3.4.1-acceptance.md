# AgentSQL v3.4.1 候选验收

**语言 / Language:** [简体中文](v3.4.1-acceptance.md) | [English](en/v3.4.1-acceptance.md)

v3.4.1 只修复管理审计 SSE 的租户隔离，不新增数据库类型、权限或 schema。v3.4.0 对金仓和 Vastbase 的固定构建验收及失败关闭边界仍按[原验收记录](v3.4.0-acceptance.md)执行。

| 验收项 | 期望 |
| --- | --- |
| 历史事件 | 已认证的 A 租户审计查看者只能收到 A 租户的缓存事件。 |
| 实时事件 | B 租户事件不能进入 A 租户 SSE，A 租户事件正常到达。 |
| 缺少归属 | 没有已认证租户或事件缺少租户标识时失败关闭。 |
| 回归 | 管理 API 权限、SSE 连接上限、错误退出与审计查询保持正常。 |
| 升级 | 无数据库 schema 变更；对旧版合成数据做健康、允许/拒绝、脱敏和持久审计复核。 |

实际 CI、分发和公网结果见[发布证据](v3.4.1-release-evidence.md)。
