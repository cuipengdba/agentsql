# AgentSQL v4.18.0 验收结果

签名提交 `5b44e03c1ef68ca6a1ee33cb6a141d663c6dd73b` 在固定 SQLBot Community v1.10.3 问数场景中通过 **20/25（80%）**。通过场景为 Q1、Q2、Q3、Q4、Q5、Q6、H1、H2、H3、H4、V1、V2、S1、S2、S3、D1、D3、I1、I2、I3。[场景定义](sqlbot-community-chatbi-score-v1103.md)

| 场景 | 本次验收 |
| --- | --- |
| 独立 MCP Server · I2 | 原版 Python MCP SDK 通过 Streamable HTTP 连接安全网关，发现工具并查询授权 PostgreSQL 合成数据。验证未授权数据拒绝、旧密钥撤销、新密钥接续、数据库中断和恢复。结果与网关审计一致。 |
| 基本助手 · I3 | 未修改的基本助手使用本地 Qwen3-4B、受控网关和 PostgreSQL，返回两行受权数据。校验允许来源、未授权来源及撤权后的历史。网关审计 20。 |
| Type 4 页面嵌入 · I3 | 未修改页面嵌入 SDK 使用专用监听器，完成两行问数、刷新、历史恢复及撤权。网关审计 26。 |
| 既有问数回归 | 复核 128 张授权表的选表、行列权限、脱敏、并发、历史、PostgreSQL 接入和托管 CSV/XLSX。 |
| 离线安装 | amd64 和 QEMU ARM64 各通过断网 systemd 新装、正式 v4.17.0 升级及启动故障回滚。17 项签名资产与外层离线包经独立公钥验签。 |
