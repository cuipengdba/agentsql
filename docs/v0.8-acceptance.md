# AgentSQL v0.8.0 验收记录

状态：发行候选验收中。功能和升级证据对应 `feature/v0.8.0`；正式
Release、GHCR 与官网结果以封板提交和发布后证据为准。

## 功能与安全边界

| 项目 | 当前实现与检查 | 发布前仍需完成 |
| --- | --- | --- |
| 任务授权申请 | 申请人以 `query.execute` 提交单条精确 SELECT、Agent、数据源、最长 24 小时有效期与幂等键；租户来自登录身份。SQL 使用配对密钥加密入库，列表与管理审计仅提供 SHA-256。 | 目标环境仍需成套备份与恢复配对 `AGENTSQL_SECRET`。 |
| 审批与领取 | 同租户另一位具备 `strategy.manage` 和 `query.execute` 的用户可查看精确 SQL、核对后批准或拒绝；原申请人一次性领取 Key。签发和管理审计在元数据事务中提交；旧直接签发 API 返回 410。 | 独立 audit 库故障与恢复已完成隔离注入；生产部署须监控 outbox 积压。 |
| 决策审计 | 授权 ID 关联管理动作和进入 SQL 流水线的执行/拒绝；审计页可按授权 ID 查询。管理审计不含 Key 与 SQL 原文。 | 独立 audit 库 relay 失败重试已在隔离拓扑完成。 |
| 接入排障 | 向导增加认证、权限、协议、数据库和审计故障码定位。 | 控制台双账号流程已复核；真实新客户操作体验仍未取得。 |
