| 故障关闭 | 独立 PostgreSQL 18.6 审计库暂停时，MongoDB HTTP MCP 拒绝交付；恢复后允许并持久记录。三成员业务库全部停止时拒绝交付；重新选主后恢复。审计预检/终态写入有两秒上限。 |
