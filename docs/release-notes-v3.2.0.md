# AgentSQL v3.2.0 发布说明

**语言 / Language:** [简体中文](release-notes-v3.2.0.md) | [English](en/release-notes-v3.2.0.md)

状态：已正式发布。正式交付和验收门禁见[发布证据](v3.2.0-release-evidence.md)，功能边界见[验收记录](v3.2.0-acceptance.md)。

## 本版改进

| 范围 | 变化 |
| --- | --- |
| PostgreSQL B2 只读审批 | 申请只封存原 SQL 和身份，不读取业务行；批准后由原申请人单次领取，并重新经过实时 B2 列授权、对象绑定、脱敏和持久审计。越权列、撤权、审计故障及重放仍失败关闭。 |
| SQLBot MySQL | 固定 SQLBot v1.10.2 的个人绑定可映射指定 MySQL 数据源。表发现、模型问数和图表走 AgentSQL MCP，支持合法的 MySQL 反引号标识符；写语句、多语句和副作用函数被拒绝。 |
| 策略影响预览 | 表级策略包应用前展示受影响 Agent、数据源、对象和列；结果来自当前策略快照，数据库对象、实时规则及脱敏仍须在执行时复验。 |
| 结果保护 | PostgreSQL B2 下，受限列参与筛选、排序或函数计算时拒绝派生查询；SQLBot 图表数值列须显式配置结果别名，脱敏或无法精确转换的值保持文本。 |

## 接入与升级

SQLBot MySQL 绑定的 `schema_name` 必须等于该 AgentSQL 数据源的数据库名。只给只读 Agent 配置所需的 `数据库.表` 权限，并为图表中的数值结果别名配置 `numeric_columns`。接入步骤见[SQLBot 指南](SQLBOT.md)。

本版未新增数据库的“完整生产支持”声明。真实验收覆盖指定版本、隔离合成数据和单实例路径；集群、其他数据库版本、真实客户负载及容灾仍按各自验收记录界定。升级前备份元数据与审计数据，升级后复验身份、权限、允许/拒绝、脱敏和恢复路径。
