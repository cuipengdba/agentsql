# AgentSQL v4.0.0 离线交付与维护指南

**语言 / Language:** [简体中文](v4.0.0-delivery.md) | [English](en/v4.0.0-delivery.md)

本指南用于管理员交付与维护。数据库支持等级以[能力与证据表](nosql-support.md)及各版本验收报告为准；维护工具不会把连接预览升级为生产支持。

## 1. 准备可信工具与公钥

从可信安装介质获取包含验签命令的 `agentsqlctl`。首次引入 v4.0.0 工具时，可先使用已审核源码中的 `scripts/releasesign/main.go` 独立验证签名，再信任包内工具，避免用未经验证的二进制证明自身可信。通过独立渠道核对正式 Ed25519 公钥的 key ID；不要只相信与包一起下载的公钥。资产清单见[发行资产](RELEASE_ASSETS.md)。

## 2. 验证完整资产目录

```sh
agentsqlctl release verify --directory ./release-assets --public-key ./trusted-release-key.json --version v4.0.0
```

目录须恰好包含正式 15 项资产，公钥文件在目录之外。结果为固定 JSON，包含版本、源码提交、key ID、资产与签名数量。只有返回码 0 且 `status=verified` 才通过。工具不联网、不解包、不安装、不执行安装脚本；验签不代替业务验收。保持输入目录只读，收到离线运输包后重新验签。

## 3. 组装离线运输包

```sh
python3 scripts/assemble-offline-release.py --directory ./release-assets --public-key ./trusted-release-key.json --version v4.0.0 --ctl /trusted/agentsqlctl --output ./agentsql-v4.0.0-offline.tar.gz
```

脚本在输出目录下建立私有暂存目录，复制资产后调用验签器，再生成仅供运输的 tar.gz。输出必须不存在；不会下载依赖或安装软件。运输包本身不是额外的正式签名资产，包内 15 项原始签名资产才是验证对象。独立传递可信公钥；在隔离环境中解开运输包后再次执行上一步。需要 Python 3.9+、已有的受信 `agentsqlctl` 和足够磁盘空间。

## 4. 离线安装与停写升级

```sh
bash ./release-assets/install.sh install --from ./release-assets/agentsql-v4.0.0-linux-amd64.tar.gz
```

根据 CPU 架构选择 amd64 或 arm64 包。首次安装所需系统、目录权限、systemd 与 SECRET 配置遵循[部署指南](DEPLOY.md)。已有实例使用安装器对应的升级流程，先按[升级与回退](v4.0.0-upgrade.md)停写并完成成套备份。`upgrade apply --dry-run` 仍是只读预演，不会替换程序或创建真正备份。

## 5. 导出最小诊断

```sh
agentsqlctl support-bundle --config ./config.yaml --output ./support-new.json --timeout 10s
```

输出最多 256 KiB，包含工具版本、生成时间、OS/架构、元数据和审计 schema 就绪状态，以及内置静态能力证据。不包含配置正文、路径、主机名、DSN、SECRET、环境变量清单、SQL、日志、业务行或用户清单。产品能力表不是当前数据源扫描结果。检查只读，但会连接配置指定的存储；可用最小查询账号执行。

| 返回码 | 含义 | 处理 |
| --- | --- | --- |
| 0 | 检查就绪 | 结合当前症状和业务验收复核。 |
| 2 | 待执行迁移 | 停写、成套备份后使用迁移账号执行。 |
| 1 | 检查或输出受阻 | 查阅报告中的固定 action；若没有有效 JSON，检查文件权限并换新路径重试。 |

输出拒绝覆盖已有文件及符号链接。配置上限 1 MiB，检查超时最多 1 分钟；数据库和实例 ID 文件不会因诊断被创建。发送诊断前仍应由管理员审阅；本版不自动发送文件或收集遥测。

## 6. 维护和问题受理

记录运行版本、发行提交、资产哈希、操作系统/架构、数据库准确产品版本和拓扑、复现步骤及固定字段诊断。客户 SQL、数据、密钥或日志如需排查，应另行脱敏和授权；默认诊断包不包含这些内容。没有约定付费维护期限或 SLA；安全报告遵循仓库 SECURITY 文档，不在公开 issue 粘贴秘密。
