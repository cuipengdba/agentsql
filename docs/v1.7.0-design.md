# AgentSQL v1.7.0 设计：瀚高 HighGo 指定实例深度适配

状态：设计与开发中。基线为已发布 v1.6.0；本文件中的目标须以最终真库、客户端和发行验收结果确认。

## 用户问题与范围

现有 HighGo 9.0.10 企业版 PG 模式验证通过 `db_type=postgres` 的合成表查询、脱敏、R006 和审计，但这会把瀚高误放在 PostgreSQL 的能力边界内；超时、取消、权限撤销、断连和审计库故障也未形成该厂商的完整证据。本版提供独立的 `highgo` 数据源类型及只读执行路径，只声明 **HighGo 9.0.10 企业版、PG 模式、单实例、合成数据和限定 SELECT 子集**。

## 产品与技术决策

| 项目 | v1.7.0 决策 | 验收依据 |
| --- | --- | --- |
| 注册与身份 | `highgo` 是独立类型，默认端口 5866；控制台和兼容矩阵展示具体版本、模式和未测项 | 不再要求用户把 HighGo 配为 `postgres`；旧 PostgreSQL 数据源不自动迁移 |
| 协议与驱动 | 当前使用 pgx/v5 PostgreSQL wire protocol，但经过独立 HighGo executor；这是驱动选择，不继承 PostgreSQL 的 B2、B5、DML 或生产支持声明 | 真库版本握手和 PG 模式检查通过；普通 PostgreSQL 服务器拒绝作为 HighGo 接入 |
| 服务器校验 | 连接时查询 `pg_catalog.highgo_version()`，要求 V9.0 企业版 9.0.10；读取内部参数 `ivorysql.database_mode=pg` 与只读事务状态；校验失败关闭连接 | 2026-10-18 本机官方包隔离实例返回 `瀚高数据库管理系统V9.0-企业版-9.0.10`、`pg`；其他版本和模式拒绝 |
| SQL 子集 | 单条、显式 schema、单表、直接列投影、非恒真 WHERE、LIMIT 的只读 SELECT；不放行 CTE、JOIN、函数、聚合、排序、锁、写入、未知语法 | 解析、授权和执行分别拒绝越界形状；数据库账号另以最小 SELECT 权限兜底 |
| 查询与审计 | 使用独立只读池，服务端语句超时、客户端取消、行收集后上下文复核和持久审计屏障；审计失败不得返回结果 | 真库锁等待、取消、审计库停机及恢复后的脱敏查询复跑 |
| 发现与策略 | 仅使用已审查的 PG catalog 元数据路径；HighGo 不启用 PostgreSQL B2 列级绑定器或 B5 写事务 | 表授权、规则拒绝、敏感列脱敏和审计可追溯；越权发现、列策略与写入失败关闭 |

安全链路：真实 MCP 客户端 → Agent Key／租户身份 → 数据源与对象授权 → HighGo 受限解析 → 最小权限只读连接与服务器身份校验 → 限时查询 → 结果来源与脱敏 → 持久审计成功 → 交付结果。任一环节不可证明时返回固定错误和审计状态，不交付原始敏感行。

## 验收矩阵

1. 隔离官方 HighGo 9.0.10 企业版镜像，license 只读挂载；记录安装包、镜像、授权到期日、PG 模式与真实端口。最小权限账号只允许合成表 SELECT，写入返回权限拒绝。
2. 对独立 `highgo` 类型运行 MCP Inspector CLI 与 Dify MCPClient 的允许、规则拒绝、越权拒绝、手机号脱敏和持久审计；Dify 可视化工作流不计入 SDK 验收。
3. 在真库上撤销表权限、断开业务库、锁等待超时、客户端取消和独立审计库故障，再恢复每一项；核对不交付部分结果、数据库端活动查询归零、审计码、恢复后掩码与最小权限。
4. 负向单元与集成测试覆盖伪装的 PostgreSQL 服务器、非 PG 模式、不同版本、写入、函数、JOIN、无 WHERE/LIMIT、未授权表、列级策略及高风险 SQL。许可或目标缺失时保持未验证，不用模拟结果替代真库结论。
5. 从 v1.6.0 正式包与已验收数据做 SQLite、PostgreSQL metadata/audit 升级和成套恢复；封版 SHA 的 CI、双架构签名资产、GHCR 匿名拉取、官网与 Live Demo 公网烟测按每版交付流程执行。

## 支持边界与回退

不覆盖 HighGo Oracle/MySQL 兼容模式、旧版本、分布式拓扑、TLS、连接池故障切换、扩展类型、B2 列级绑定、B5 写事务、生产负载或厂商认证。若握手、只读查询、故障关闭或真实客户端任一必需链路未通过，保留原先 `postgres` 协议路径的历史验证记录，但不开放 `highgo` 的新支持声明；正式发布回退到 v1.6.0 的包、镜像和备份。
