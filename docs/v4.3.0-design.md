# v4.3.0 设计：可复核的问数呈现与嵌入

状态：开发中。固定行为对照为 SQLBot 社区版 v1.10.2；AgentSQL 使用自己的 Go 服务、页面和品牌。以下是交付门槛，不代表已经实现。

## 本版目标

| 工作流 | 交付行为 | 验收方式 |
| --- | --- | --- |
| 图表 | 从当前授权查询结果生成表格、柱状、折线、饼图等图表；保存图表配置时只保存字段映射和受控查询引用 | 原版流事件及历史图表对照；撤销表列/行权限后，刷新历史图表不能继续显示旧数据 |
| 分析与预测 | 分析解释与预测结果标明数据范围、输入、方法及生成时间；本机模型运行，云端仅明示模拟 | 合成数据的准确度与失败情形对照；模型故障、无授权、审计写失败时不输出数据 |
| 仪表板 | 自有画布支持资源树、图表、文本、Tab、布局、保存、预览、删除和导出；原版 dashboard API 映射 | 原版页面逐项创建、编辑、查看、重启恢复；每次打开图表重新经网关授权和审计 |
| 小助手 | 基础与高级应用可独立创建、配置、启停、撤销；应用身份绑定到工作空间与允许的数据源 | 原版应用页面与 API 对照；跨用户、跨域、撤权、过期、并发和重放测试 |
| 嵌入 | 原版 SDK、网页嵌入、API 与 MCP 的登录、令牌、回调、域名、会话入口兼容 | 未修改原版 SDK 和嵌入页面本地接入；参数、响应、错误、回调及撤权对照 |

## 安全与数据流

图表、仪表板、助手和嵌入端都只存配置及引用。读取结果时按当前用户或应用身份重新检查工作空间、数据源、表列与行规则，交给 AgentSQL 网关执行，再对结果脱敏并写持久审计。历史结果不得作为新授权的替代品。对无法确定的 SQL、数据源或身份拒绝请求。模型生成的文字、SQL 和图表建议均视为不可信输入。

网页嵌入、API 与 MCP 共用同一授权语义，但保留各自必要的协议形态。部署在公网的演示页面仅显示清晰标记的模拟交互，不运行真实模型，也不接入业务数据库。本机真实模型和合成数据库用于功能验收。

## 发布闸门

本版独立完成设计记录、代码、功能与故障测试、原版页面对照、Go/Web/文档 CI、旧版升级回退、离线新装与失败回滚、双架构签名包、镜像匿名拉取、GitHub Release，以及官网和 Demo 同版核对。未通过的工作流不得写进已支持功能列表；完整 SQLBot 页面和真实业务系统零改动替换仍以 v4.5.0 的逐项证据为准。
