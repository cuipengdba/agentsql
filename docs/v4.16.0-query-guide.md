## 独立问数

在网关登记 PostgreSQL 数据源，使用数据库只读账号。为每名成员建立个人数据源绑定，按业务范围配置能看的表和列。地区行规则限制订单范围，脱敏策略控制邮箱等字段的返回形式。安装 AgentSQL 问数服务，配置本地问数模型，再用普通成员账号登录网页。 [三种使用模式](PRODUCT_MODES.md)

在已授权的合成订单数据源中，可以输入「列出我能查看的订单编号、地区和联系邮箱」。分别用两个成员账号运行，检查返回的地区、列和掩码是否符合各自权限。独立 AgentSQL 问数页会显示对应的网关审计编号。对回答作业务判断前，请核对生成 SQL、授权范围及数据口径。

## 作为独立 MCP Server 安全网关

为客户端配置单独的网关身份和最小只读授权，通过 MCP 工具发现可用操作和受权元数据。查询由网关检查授权、执行、脱敏并持久审计。业务角色变化后，轮换或撤销相应绑定和凭据。 [部署指南](DEPLOY.md) · [运维手册](OPERATIONS.md)

## 问数和网关一起使用，或接入 SQLBot

运行 AgentSQL 问数 Agent 和独立 MCP Server 安全网关，供各自的客户端使用。Agent 生成候选 SQL，网关决定是否执行。需要保留已验的 SQLBot 客户端时，可把相关执行路径交给 AgentSQL 适配器，再用当前用户绑定执行。通过历史重开和 CSV 或 Excel 导出时，AgentSQL 会按当前授权重新获取受控结果。 [SQLBot 接入](SQLBOT.md)

PostgreSQL 免扩展 `CATALOG_CLOSED_V1` 的实测路径采用简单基表投影。收到「当前 PostgreSQL 列授权模式不支持这类查询」时，请核对问题所需的排序、关联和其他查询能力与当前数据库授权模式。 [验收记录](v4.16.0-acceptance.md)
