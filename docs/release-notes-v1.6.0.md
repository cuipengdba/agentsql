# AgentSQL v1.6.0 发布说明（候选稿）

v1.6.0 聚焦已接入的达梦、金仓与 Vastbase 指定实例的故障关闭证据。此文在正式 Release、签名资产、官网和 Live Demo 全部验收前仅为候选稿。

## 改进

- 受控查询在读行结束后再次检查请求取消或超时状态，避免驱动返回空错误时把已经收集的敏感行交付给客户端。覆盖 PostgreSQL、达梦/Oracle 窄 SQL 路径和 MySQL 两条结果路径。
- 达梦连接增加网络请求截止时间，并在客户端取消时直接关闭请求所用的物理连接，避免锁等待时驱动同步回滚停滞。达梦只读池不再保留空闲连接；这一安全取舍可能增加连接建立开销。
- 无状态 MCP 2026-07-28 端点将客户端断连传给执行中的只读工具；旧版有状态端点保持独立服务端截止时间和 B5 会话约束。金仓等 PostgreSQL 兼容库返回的明确 `statement_timeout` 现记为超时，而普通取消仍记为中断。
- 三款指定数据库均加入同一套独立审计库故障、恢复、真实查询超时、客户端取消、数据库端活动查询终止与脱敏结果复核的可复跑测试。相关合成数据和临时凭据不随仓库或发行包分发。
- Live Demo 总览区分网关存活、依赖就绪与各演示数据源的最近连接检查；“数据源数量”改为“已配置数据源”。

## 兼容与限制

- 管理 API、MCP 工具格式和数据库 schema 未改变；现有数据源配置无需迁移。升级仍须先备份 metadata、audit 和密钥并演练恢复。
- 本版的真库结论仅适用于 [v1.6.0 验收记录](v1.6.0-acceptance.md)列出的实例、协议模式和有界只读子集。不会自动将 28 款注册数据库或三款指定厂商提升为完整生产支持。
- DM8 其他兼容模式、金仓 Oracle 模式、Vastbase 其他 Build、HA、TLS、长期许可、复杂 SQL 和生产负载未由本版故障测试证明。
- `/healthz` 仅表示进程存活，`/readyz` 检查网关所依赖的控制面、审计等状态；演示业务数据源仍需逐个 Ping 和真实 MCP 请求验收。

正式发布时补充对应提交、CI、签名资产、镜像摘要、官网／Demo 和升级恢复证据。
