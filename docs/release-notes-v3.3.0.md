# AgentSQL v3.3.0 发布说明

**语言 / Language:** [简体中文](release-notes-v3.3.0.md) | [English](en/release-notes-v3.3.0.md)

状态：**已正式发布**。交付以[验收记录](v3.3.0-acceptance.md)和[发布证据](v3.3.0-release-evidence.md)为准。

## 本版改进

| 范围 | 变化 |
| --- | --- |
| 达梦验证连接 | 新建 DM 数据源可配置 `verify-full`、网关本地 CA 文件及证书主机名。证书链、有效期和名称在 TLS 握手时校验；不能证明后续通信加密时拒绝连接。拒绝跳过验证、缺失 CA、相对路径和不支持的模式。 |
| 达梦查询成本 | 对指定 DM8 Pack3 的 `LIMIT` 计划识别 `TOPN2`，估算扫描行数时汇总物理扫描节点并检查溢出，防止把返回行数误作扫描成本。未知计划节点仍拒绝。 |
| 控制台 | 新建达梦连接默认展示验证连接所需字段和旧版未配置 TLS 连接的风险边界。 |
| 驱动来源 | 固定 `godoes/gorm-dameng` v0.7.2 的本地 MIT 副本，仅在连接配置、加密模式检查和 TLS 证书验证处做受控改动；详情见 `third_party/gorm-dameng/README.agentsql.md`。 |

## 接入与升级

在达梦服务端启用加密通信并部署有效证书，将签发 CA 安装在网关可读取的绝对路径，填写证书内的 DNS 名或 IP。只有显式配置 `verify-full` 的连接可声明服务端身份已验证；旧版未配置 TLS 的数据源继续保留兼容行为，运维人员应迁移到验证连接。

本版真库结论只覆盖验收记录中列出的 DM8 Pack3 构建、`COMPATIBLE_MODE=0`、单实例和合成数据。它不代表其他达梦版本、主备切换、双向认证或完整生产支持。升级前备份元数据与审计数据，升级后复验身份、权限、允许与拒绝、脱敏及故障恢复。

当前真库放行的查询样例限于已授权单表的直接列投影、等值过滤及有界 `LIMIT`/`OFFSET`。JOIN、复杂函数和无法确认列来源的表达式未列入本版新增验收范围；写入、多语句和未授权对象继续拒绝。R004 扫描估算依赖该构建的已知计划节点，未知节点或估算溢出拒绝执行。
