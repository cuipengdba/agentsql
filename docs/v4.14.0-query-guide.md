# AgentSQL v4.14.0 单表问数与选表指南

**语言 / Language:** [简体中文](v4.14.0-query-guide.md) | [English](en/v4.14.0-query-guide.md)

## 独立问数

1. 由运营方登记 PostgreSQL 只读网关绑定，给使用者授权需要的表，再为问数工作空间配置文本模型。
2. 登录 AgentSQL 问数页面，选择有权限的数据源并新建对话。一次说明表的业务含义、时间范围、过滤条件、返回字段和排序方式。
3. 对照原始表格和生成的 SQL 核对结果。用审计编号在网关侧核查实际查询对象、决策与行数。

单表样例

| 想了解什么 | 示例问题 |
| --- | --- |
| 取符合条件的明细 | 列出 2026 年 1 月华东地区的订单，状态等于库中的中文原值「已完成」。返回编号、地区和金额，按编号升序取前三条。 |
| 对一个表排序汇总 | 在实际销售订单明细里，按销售地区汇总 2026 年 1 月且状态等于中文原值「已完成」的订单金额，按金额降序取前两名。 |

对订单状态等固定取值，建议在问题里标清数据库保存的原文。实测中，模型偶尔会把未注明原值的中文状态词译成英文，导致筛选为空。发现这种情况时可先核对生成 SQL 的筛选值，再按库中原值重新提问。

## 授权表较多时

给容易混淆的表写上含义明确、互相区分的业务备注，例如“实际销售订单明细”“下一年度销售订单预测”和“历史取消订单归档”。问数时说明使用哪套业务口径。存在唯一匹配的业务名称时，系统把对应授权表排在候选结构前面。没有唯一匹配时，使用当前权限下的既有选表流程。

冷态与热态取决于当前用户、数据源和权限下的表向量索引。打开数据源列表可触发后台预热。变更授权后，网关在后续查询时仍按当前范围复核。选表属于生成 SQL 的参考，执行权由网关决定。

## 独立网关与组合部署

第三方 MCP 客户端可调用单独部署的安全网关执行受控查询。AgentSQL 自有问数组合部署时，问数服务负责解释问题和生成 SQL，安全网关负责身份、授权、执行和审计。固定 SQLBot 接入方式见接入文档。 [三种使用方式](PRODUCT_MODES.md) · [SQLBot 接入](SQLBOT.md)

用户真实业务系统尚未验证。隔离环境的模型、数据库、权限、规模和性能结果以本版本的发布验收为准。
