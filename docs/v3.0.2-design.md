# v3.0.2 修正与 SQLBot 适配设计

**语言 / Language:** [简体中文](v3.0.2-design.md) | [English](en/v3.0.2-design.md)

用户要求修复浅色导航、提供与中文原文完整对应的英文内容、更新现行文档入口、适配 SQLBot，并移除微信群二维码。

1. 控制台 Sider/Menu 与全局主题共用状态和颜色变量，保留短视口独立滚动。
2. 中英文 README、官网与 Markdown 文档逐节对应，记录源文件哈希并检查标题、表格、代码块和链接。现行操作指南以 v3.0.1 为已发布基线，随 v3.0.2 发布更新；历史报告保留实际版本和证据。
3. 建立当前文档索引和版本无关运维手册，修正默认入口中 v0.7 标题与过期构建命令。
4. SQLBot 官方 v1.10.2（提交 `aa41fc1033bb974a703df9200a98ec8b9eec5f25`）提供 MCP 服务，但数据库执行层仍直接连接数据库。提供可审核、固定源哈希的安装补丁和独立 Python 适配器，将已配置 SQLBot 数据源的元数据发现与 SQL 执行送入 AgentSQL `/mcp`。缺失映射、Key、授权、审计或网关连接时失败关闭，不退回数据库直连。SQLBot 内部元数据存储与业务数据源分别处理。其他 SQLBot 版本必须重新验证源文件哈希与接口。
5. README 和中英文官网只展示公众号与个人微信二维码，删除当前源码中的群二维码文件及引用。历史 Git 提交与已签发布物保留。

SQLBot 安全链路：SQLBot 生成 SQL → 固定数据源映射 → Agent Bearer → AgentSQL MCP 会话 → 身份/租户/权限/规则 → 受控执行 → 结果脱敏 → 持久审计 → SQLBot 结果模型。适配器只交付允许决策且包含持久审计 ID 的结果，未知或拒绝决策均抛错；不自动重试 SQL。

验收覆盖浅/深色和中/英文组合、折叠菜单和短视口、全文结构对齐、二维码清理、当前文档链接，以及 SQLBot 允许、拒绝、脱敏、审计、失效 Key、断线、缺失映射和直连阻断。正式 v3.0.1 的签名包不原地替换；通过后用 v3.0.2 交付新代码与更新后的文档、官网和 Demo。

新增需求：统一 AgentSQL Logo 的矢量母版、深浅背景横版标识、官网分享卡和浏览器图标；官网、GitHub README、Web 登录与侧栏共同体现，并通过 CI 检查副本一致性。官网补齐英文长文案的换行与静态资源版本参数，避免旧缓存遮蔽新 Logo 和样式。
