状态：候选验收中。正式发布、官网与 Live Demo 结果另记在发布证据文件；本页的真库结论只覆盖下述指定社区版单实例和合成数据。

## 环境与身份

- 依据[官方容器安装文档](https://docs.opengauss.org/zh/docs/7.0.0/installation_guide/installing_the_container_image.html)下载 openEuler 24.03 x86_64 归档；本地 SHA256 与官方旁置校验文件一致：`1b72ce6efc0d7885327a7d3daa72232081f40706bb3a7c4613e2f7e7347de3ee`。镜像 ID：`sha256:d504c5d14049f225069c87a287931fe543122963d016a30023ee09653a9b5517`。
- 运行中 `pg_catalog.version()` 返回 `(openGauss 7.0.0 build 2397a86f) compiled at 2026-09-23 00:09:53 ...`。连接池在每次新建物理连接时核验此构建和只读状态。Docker Hub 的 `7.0.0-RC3` 没有替代 LTS 测试。
- 隔离容器只向宿主机回环映射端口；合成表与只读账号 `agentsql_v240_ro` 只获目标普通表的 SELECT。该账号另获测试视图 SELECT，用于证明适配器拒绝视图绕过。私钥、密码、数据库备份与合成记录不进入仓库或公网 Demo。
- 测试 CA 签发 `og-lts.agentsql.test` 服务端证书，服务端 `ssl=on`；证书文件权限 0400。只读账号的非 TLS 网络连接被 HBA 拒绝。正确 CA 与主机名通过；错误 CA、错误主机名与明文连接失败。证书轮换与生产 CA 不在本次范围。

## 支持边界

本次只证明 openGauss 社区版 7.0.0 build 2397a86f、官方 x86_64 单实例容器、测试 CA 与合成数据上的受限只读路径。其他 openGauss 版本、GaussDB 商业版、主备、生产证书轮换、长期负载、客户拓扑、B2、B5、写入、任意 SQL 与完整生产支持均未验证。公开 Live Demo 保持合成 PostgreSQL 数据，不连接这台 openGauss 测试库。
