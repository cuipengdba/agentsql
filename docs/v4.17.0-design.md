## PostgreSQL 管理接入

网关管理入口负责登记和验证真实连接。管理员为普通成员建立个人绑定并选择授权对象。问数服务只能以当前用户和绑定身份获取元数据及执行结果。连接验证、凭据轮换、绑定更新和业务查询分别留存审计。

在网关控制台的数据源页面测试连接后，可按数据源查看 `datasource.ping` 审计记录。记录当前操作者、结果、用时和失败分类。连接凭据和驱动原始错误由服务端处理。审计不可用时，连接测试返回服务暂不可用。

用标准 SQLBot 客户端、真实模型和隔离合成 PostgreSQL 核对 SQL、数据和审计。验收包括错误凭据、轮换后复试、旧绑定撤销及普通成员管理拒绝。数据库凭据仅经受信网关管理通道提供。[SQLBot 接入](SQLBOT.md)

## 托管 CSV 与 XLSX

上传、预览、选择工作表及确认导入后，托管服务创建受控数据源。问数执行通过网关，区分中文字段、十进制数和空值。读取历史和导出数据前，按当前授权检查资源。

配套部署本版问数服务与网关时，未应用脱敏的托管文件问数和历史复查 JSON 结果区分 SQL `NULL`、空字符串和零。应用脱敏的结果沿用字符串格式。CSV 与 XLSX 导出以空白单元格呈现 `NULL`。

使用双表工作簿和含中文的 CSV 验证数据源范围、错误文件处理、失败后的清理和重新打开。检查删除、撤权和重启后的行为，记录真实查询使用的对象与审计。[独立问数与网关](PRODUCT_MODES.md)

验收记录绑定同一精确签名版本。对外说明分别记录测试了哪些部署、客户端、数据库和导入范围。公开 Demo 使用明确标注的模拟模型与合成数据。
