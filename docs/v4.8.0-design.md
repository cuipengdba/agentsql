# AgentSQL v4.8.0 广覆盖兼容与连接管理合同

> 已发布。正式范围由 v4.8.0 Release 的精确提交、逐入口证据和签名包验收确定；下表保留最初验收目标，未通过的组合不能据此表宣称支持。

## 产品边界

AgentSQL 同时提供独立自然语言问数 Agent 和独立 MCP Server 安全网关；SQLBot Community v1.10.3 是可选的原版客户端与协议对照，并非 AgentSQL 问数能力的来源。v4.8.0 处理上一版之后的可用社区页面/API、数据库连接创建与编辑、云模型和生产规模行为。逐项矩阵区分“已验支持”“仅配置”“明确拒绝”“未验证”，不以注册了路由或显示了页面代替功能验收。

数据库连接的实际目标和凭据只由受控网关的管理 API 或运维私有配置建立。SQLBot 浏览器送来的公开 AES 信封只能编辑展示元数据，不能创建或更换网关目标。v4.8.0 增加运维侧个人数据源映射轮换：先创建新网关绑定，再从私有文件预检新映射的受权结构与行列权限，用旧绑定 ID 和存储修订号比较写入加密本地映射与管理审计；旧查询在返回前复核修订号。随后复验真实问数并在网关撤销旧绑定。浏览器直连数据库或提交数据库密钥不属于此流程。

## 逐项矩阵与发布门槛

| 范围 | 正向证据 | 必须覆盖的负向或边界 |
| --- | --- | --- |
| 原版页面与 API | 固定官方 v1.10.3 未修改客户端逐页操作；记录请求、响应、截图与工作空间状态 | 身份、权限、禁用、删除、上传、并发版本冲突；未覆盖项写“未验证” |
| 原版 MCP 与嵌入 | 官方 SDK 和基本/高级助手、Type 4 页面嵌入各自按真实模型、真网关与真库验收 | 跨用户/来源、令牌撤销、规则变化、历史与导出、伪造消息及失败关闭 |
| 连接创建、编辑与轮换 | 网关管理 API 的创建/修改/连通验证，再绑定到个人问数；旧映射版本比较轮换 | 错误新凭据、旧 ID、并发更改、审计失败、旧请求结果释放、旧网关绑定撤销 |
| 模型供应商 | 每个声明供应商用真实凭据完成请求与故障恢复；无凭据仅验证配置形状 | 错误密钥、超时、模型中断、敏感配置回显和未授权编辑 |
| 规模与资源 | 在声明的 CPU/内存、授权表数和并发数下记录冷/热首问、吞吐与 p95 | 索引预热撤权、排队上限、模型/数据库/存储/审计故障；不得用热值代替冷值 |
| 正式交付 | 精确提交五项 CI、17 项生产签名资产与外层包独立验签、双架构断网真实服务新装/升级/回滚 | 从正式 v4.7 升级；GHCR 匿名回下载、官网/Demo 公网烟测和规范主仓库同步 |
