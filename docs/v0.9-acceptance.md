# AgentSQL v0.9.0 验收记录

本文件记录发布前验收范围。最终提交、同提交 CI、签名资产、GHCR、官网和独立 Live Demo 的实测结果以 [v0.9.0 GitHub Release](https://github.com/cuipengdba/agentsql/releases/tag/v0.9.0) 正文为准；本地测试不替代公网发布证据。

## 已完成的发布前实测

| 范围 | 结果与边界 |
| --- | --- |
| 前端与官网 | 控制台类型检查、构建及 16 个 Vitest 文件的 54 个测试通过；官网静态校验 8/8 通过，三份 v0.9.0 PDF 已生成。 |
| 任务 Key | 合成环境中默认 1 次授权由异人审批后签发；MCP Inspector 首次精确查询返回脱敏结果并原子扣减，第二次被拒绝且不返回业务数据，申请、审批、签发及两次流量共 5 条关联审计。PostgreSQL metadata/audit 分库端到端测试验证 1 次预算扣减和再次拒绝。 |
| MCP Inspector 2.11.0 | `/mcp` 和 `/mcp/2026-07-28` 的严格工具 schema 校验均通过；两入口均完成允许查询、`R010` 拒绝、手机号脱敏和持久审计。旧入口 16 个工具，新入口 8 个工具。 |
| Dify 1.17.1 | 隔离自托管工作流经 `/mcp` 调用独立 Agent 身份；允许查询返回 1 行和 `138****5678`（审计 ID 12），显式拒绝表返回 `R010`（审计 ID 10）。这一结果不推及 Dify 未测试的现代入口。 |
| 国产数据库 | DM8 Pack3、KingbaseES V9 PG 模式、Vastbase G100 Build 9 均在指定隔离实例以受限账号和合成数据完成有界查询、拒绝、脱敏及审计复核；不表示其他版本、方言或生产负载获得厂商认证。 |
| 策略与审计运维 | 离线预检对允许候选返回“未知”、对拒绝表返回“拒绝”；合并库 outbox 状态明确为不适用，租户隔离、积压与重试统计有单元测试覆盖。PostgreSQL metadata/audit 分库端到端用例验证了当前租户 3 条待投递事件的状态读取。 |

## 必须通过的门槛

| 范围 | 验收要求 |
| --- | --- |
| 任务 Key 预算 | 默认 1 次、显式 1–10 次、并发原子扣减、到期/撤销/耗尽拒绝、旧 Key 兼容、审计失败不返结果 |
| 敏感派生输出 | PostgreSQL/MySQL 的表达式、聚合、集合运算、CTE/视图、别名与未知来源负向集；原文不得出现在返回结果和审计 |
| 审计运维 | 分库 outbox 状态按租户隔离；积压、重试和状态读取故障可见 |
| 策略预检 | 仅有明确拒绝或未知，绝不误报允许；无业务库执行或流量审计写入 |
| 升级恢复 | v0.8.0 正式包到 v0.9.0 官方签名包，SQLite 合并库及 PostgreSQL metadata/audit 分库成套备份恢复 |
| 真实客户端及数据库 | Dify、MCP Inspector、DM8、KingbaseES V9、Vastbase G100 在指定已验收环境的有界回归 |
| 发布 | 同提交 CI、15 项资产三签名、双架构 GHCR 公共匿名拉取、官网 3 PDF、Demo 后端同版本与公网烟测 |

发布后的提交、CI、签名、镜像摘要、官网及 Demo 公网烟测证据写入 [v0.9.0 GitHub Release](https://github.com/cuipengdba/agentsql/releases/tag/v0.9.0) 正文。
