# AgentSQL v0.6.0 发布说明

## 本次更新

- 控制台增加用户、角色、租户管理入口和首次接入向导。管理 API 继续按调用者租户和角色约束读写，权限委派不能超过调用者已有权限。
- 普通 SQL 审批增加封存、有效期和单次执行。申请时绑定租户、Agent、数据源配置、SQL 和理由；批准后原 Agent 调用 MCP `execute_approved`，执行前重新检查当前身份、权限、风险规则和数据库连接。执行结果、审计 ID 和失败状态可在审批记录中追踪。旧版未封存审批记录不可执行；B5 事务审批保持独立合同。PostgreSQL 18 和 MySQL 8.4 的受限账号真库测试确认申请不写入、批准后仅写入一次、重复调用拒绝。
- 增加独立的 `vastbase` 数据源类型，针对 Vastbase G100 V3.0 Build 9 的 PG 兼容模式提供有界单表只读查询。连接强制只读并验证产品、版本和模式；写入、DDL、JOIN、函数等超出已测子集的 SQL 会拒绝。真实 G100 合成数据测试覆盖 MCP 查询、表授权、脱敏、申请与单次执行及持久审计。详细边界见 [G100 验证记录](vastbase-g100-v060.md)。
- 基础 MCP 工具从 7 个增加到 8 个。SQLite combined、PostgreSQL combined 和分离 metadata 的审批 schema 增加执行状态字段。SQLite→PostgreSQL 迁移器支持新字段，并正确识别 PostgreSQL 建表时预置的内置权限清单。

## 升级与安全边界

升级前停止写入并备份控制面数据库、配置和 `AGENTSQL_SECRET`。升级后检查迁移版本、管理端登录、MCP 工具发现、旧 Agent Key 和审计查询。已有审批单可查看和决策，但没有 v0.6.0 的封存信息，因此不能用作执行凭据；需要重新申请。

G100 验证使用安装程序生成的临时许可，有效期至 2027-01-12；它只支撑本次隔离测试。正式生产许可、TLS、HA、其他 Build、长时间负载和厂商认证均未完成，不能据此宣称 G100 完整生产支持。达梦与金仓沿用各自文档所述的指定版本证据，本次发布不扩大其方言或生产支持承诺。

本版的实际客户端验收目标为 Dify 和 MCP Inspector 图形界面；Inspector 可验证 MCP 工具调用，但不是 AI 助手。Claude Desktop 因缺少账号尚未实测，其接入说明保留为配置指南，不作为本版兼容性验收结论。仓库的 SDK 与协议测试只证明对应自动化路径，不能代替实际客户端记录。发布资产和部署说明以正式 [GitHub Releases](https://github.com/cuipengdba/agentsql/releases) 页面为准。
