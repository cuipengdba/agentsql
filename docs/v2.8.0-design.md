# AgentSQL v2.8.0 设计：Milvus 受控向量检索

状态：v2.8.0 已发布。实际边界为 Milvus 2.6.25 单机、`default` 数据库、gRPC TLS 与已认证的最小权限账号；不宣称集群、其他版本或完整生产支持。正式结果见[发布证据](v2.8.0-release-evidence.md)。

## 用户任务和范围

Agent 从精确授权的 collection 中检索一个向量，按相似度顺序取少量标量字段。管理员原有 Milvus 原生命令预览是连接级能力，不作为 Agent 的 MCP 权限依据。

| 路径 | 约束 |
| --- | --- |
| MCP `search_vectors` | 数据源 ID、单个 collection、FloatVector 字段、一个有限 float32 向量、1–16 个显式标量输出字段和 1–20 的 `top_k`；不接受表达式、分区、混合检索、写入或原生命令。仅在已配置精确 `default.collection` 表授权、向量字段与全部输出字段列授权时允许。 |
| 数据库连接 | 逐次从当前数据源读取账号、证书与地址，建立验证 CA 和主机名的 TLS 连接；拒绝 `root`、空密码、明文和信任任意证书。Milvus 账号应仅有目标 collection 的 `Search` 权限。连接测试也使用此受控 TLS 路径。 |
| 元数据与执行 | 核对服务器版本、非动态集合、FloatVector 维度、标量输出类型和单个 COSINE 向量索引。网关最多 5 秒、20 个命中、1 MiB 响应；gRPC 接收消息限制 2 MiB。服务端构造固定 Search 调用，输入无法传入过滤表达式。 |
| 安全链 | 每次重新验证 Agent/租户和当前策略；预检审计持久化后才连接 Milvus。校验返回列与行数，按 collection/字段来源脱敏；终态审计持久化后才交付。审计仅记录对象、阶段、行数和脱敏数，不记录向量和原始值。任何审计故障均失败关闭。 |
| 兼容 | 既有连接级 Milvus 预览保留。配置为严格 TLS 的数据源通过独立受控路径测试连接，原有预览不支持该配置。其他数据库既有行为不受新工具授权影响。 |

调用链：`HTTP MCP 身份 → Agent/租户 → 当前数据源 → 精确 collection/字段策略 → 输入校验 → 持久预检审计 → TLS/最小角色/版本/元数据 → 固定有界 Search → 返回结构校验 → 来源字段脱敏 → 持久终态审计 → MCP 响应`。

负向验收包括宽泛或撤销授权、越权字段与集合、错误 CA/主机名、明文或管理员账号、错误维度、NaN/Inf、动态字段、非 COSINE 索引、业务库停机、超时/取消以及预检和终态审计故障。Milvus 真库以官方 2.6.25 单机镜像、合成数据和单 collection Search 角色验证；MCP Inspector 与 Dify MCPClient 分别验收允许和拒绝调用。发布还需要从 v2.7.0 正式包升级与成对恢复、CI、双架构签名资产、GHCR、官网与 Live Demo 公网复验。
