# v3.3.0 达梦指定版本深化设计

**语言 / Language:** [简体中文](v3.3.0-design.md) | [English](en/v3.3.0-design.md)

状态：开发中。目标仅为 DM8 Pack3 `dm8_20241022_rev244896_x86_rh6_64`、`COMPATIBLE_MODE=0` 的可证明边界，不向其他版本、兼容模式或主备拓扑外推。

## 安全连接

现用 `godoes/gorm-dameng` v0.7.2 在 TLS 握手中设置 `InsecureSkipVerify: true`，因此不能把已有加密握手视为服务端身份校验。显式 TLS 必须提供 CA 文件、预期服务端名称，并拒绝跳过验证。连接在任何业务查询之前验证证书链、有效期和名称；明文或不能证明已加密的服务端必须失败关闭。正确证书、错误 CA、错误名称、证书轮换和旧证书失效都要在指定真库验证。现有未配置 TLS 的数据源保持原有兼容行为，界面和文档明确其未验证连接安全性。

达梦官方通信加密手册将 `ENABLE_ENCRYPT=5` 定义为客户端验证服务端的加密模式，但这台 2024 年指定构建对值 `5` 返回参数错误。隔离实例已用它支持的 `ENABLE_ENCRYPT=1` 和 `MIN_SSL_VERSION=771`（TLS 1.2）完成 AgentSQL 客户端证书校验探针：正确证书可查询、错误 CA/主机名在握手时拒绝。最终发行仍以完整 MCP 链路为门槛；不把服务端模式名称等同于已证明双向认证。

## 查询、成本与资源

只扩大解析器、对象与列来源、最小权限真库测试共同证明的只读 SELECT 子集。分页、投影、过滤与多表来源逐项列明允许和拒绝条件；未证明来源的表达式、注释、写入、多语句和系统目录保持拒绝。EXPLAIN 结构未知或估算越界必须在执行前失败关闭。R004 的扫描行阈值、每请求行数、超时、连接数及并发保留可配置上界；执行后仍检查取消、结果预算、脱敏和持久审计。

## 真库和恢复验收

隔离 DM8 Pack3 容器使用用户提供的本地镜像与只读许可证。正向查询与策略拒绝、最小权限账号、错误 TLS 配置、超时/取消、并发有界负载、数据库停启后的失败关闭和恢复查询都要通过 MCP 请求核对审计 ID。记录版本、模式、许可到期日、负载形状、P50/P95/P99、错误率和资源观测；单机停启不宣称主备切换。封版还须按 `docs/RELEASE_ROUTINE.md` 完成升级恢复、CI、签名双架构资产、GHCR 匿名拉取、官网及公网 Demo 烟测。
