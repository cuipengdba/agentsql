## 数值分析

对已授权、未脱敏、完整返回的 PostgreSQL 单维单指标结果，使用真实整数或十进制类型计算合计、占比和不同观察时间点的变化。占比以返回行的合计为分母。零分母保留绝对差值。日期序列只比较实际返回的相邻数据。原生页面标注计算方法。无法确认类型或完整结果时，沿用有界模型分析和当前权限复核。

原版客户端通过现有事件读取分析，可在历史中重开。服务在生成、保存与返回时复核当前的账号、数据源绑定、权限和结果。数据库中断、权限撤销、结果变更或存储写入失败时隐藏旧说明。

验收使用固定社区客户端、本地 Qwen 和隔离 PostgreSQL 合成订单。核对两条入口的实测数字、审计、故障和恢复，保留中文真实产品截图。公网 Demo 明示模拟模型。用户真实业务系统尚未验证。
