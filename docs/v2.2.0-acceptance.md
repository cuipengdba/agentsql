## 安全边界和未验证项

- Oracle 最小权限账号没有可验证的 `PLAN_TABLE` 写权限。本版在该路径禁用预执行 `EXPLAIN PLAN` 和静态 R010 的计划绑定；原生管理账号 `EXPLAIN` 测试不代表网关账号有此能力。R004/R005 的计划估算不适用于此 Oracle 子集，执行行数限额仍生效。
- SQL 仅开放 parser 和 executor 都确认的窄 SELECT。函数、复杂 JOIN、CTE、子查询、写入、事务、系统目录和未列出语法保持拒绝；B2 列级授权、B5 会话、TCPS、证书轮换、客户端取消与超时终止、主备/RAC、持续负载、arm64 Oracle 服务端及商业版均未验证。
- Oracle Free 镜像测试不构成厂商认证或完整生产支持。正式支持声明不得超出此版本、`FREEPDB1`、单实例、合成数据与只读子集。
