# v0.7 运维故障定位手册

本文适用于 v0.7.0 的本地验收，以及部署后的控制面升级、MCP 接入和审计依赖故障。所有检查都应在已授权的测试或维护窗口进行；记录命令退出码、时间、实际提交和部署拓扑，不在工单或日志中粘贴 API Key、DSN、SQL 原文或数据库密码。发行资产与上线结果应按[验收记录](v0.7-acceptance.md)列出的闸门，在 GitHub Release 正文及发布证据中核对。

## 迁移预检失败

先停止旧实例写入并备份 metadata、audit 存储及与其配对的 `AGENTSQL_SECRET`。在与服务相同的配置和环境变量下运行：

```bash
agentsqlctl migrate --check --config /etc/agentsql/config.yaml
```

| 退出码 | 含义 | 处理 |
| --- | --- | --- |
| 0 | 所有配置的迁移流均为 `current` | 核对输出中的 `role`、`driver`、`current` 与 `latest`，继续启动前检查。 |
| 2 | 至少一个迁移流为 `pending` | 保持新实例停止，以 migration owner 显式执行 `agentsqlctl migrate`，再重跑预检。 |
| 1 | 配置、连接、历史版本或输出错误 | 查明具体错误。不要把它当成“待迁移”继续启动。 |

合并存储只输出 metadata 一行；分库部署必须同时看到 metadata 与 audit 两行。SQLite 路径不存在或文件存在但没有 `schema_migrations` 时，预检不会创建库表；首次安装需先显式迁移。若数据库版本高于当前二进制、版本历史不连续，或两库只迁移成功一边，应保持服务停止，按备份恢复方案处理，不要仅替换旧二进制尝试降级。

启动后分别检查 `/healthz` 与 `/readyz`。前者只能证明进程存活；后者返回 503 时需检查 metadata/audit 连接及 B2/B5/脱敏状态。回滚应恢复升级前成对的数据库备份、对应密钥和旧版程序；项目没有自动 down migration。完整权限与备份步骤见 [部署指南](DEPLOY.md)。

## 审计超时或不可用

如果 MCP 工具返回 `AUDIT_UNAVAILABLE`、`AUDIT_OVERLOADED`，或 `/readyz` 返回 503，先记录请求时间、审计 ID（若有）、错误码、错误阶段和部署实例，再检查 audit 存储连接、磁盘空间、数据库连接数和写入延迟。审计库不可用时不要关闭审计或扩大权限来恢复请求；网关会按故障关闭合同拒绝结果。

对于曾提交写操作且返回 `COMMIT_OUTCOME_UNKNOWN` 的请求，**不要自动重试**。先核对业务库实际状态和审计记录，再决定人工补救。普通只读请求在依赖恢复后可用新请求 ID 重试；重试前确认原请求没有仍在运行。

依赖恢复后，从最小权限测试 Agent 发起一条允许的只读请求和一条应拒绝的请求，核对响应决策、租户、Agent、数据源和持久审计。只看 `/healthz` 或数据库 ping 不足以证明审计链路恢复。

## MCP 协议被拒绝

先确认客户端使用的路径和协议：

| 路径 | 协议与行为 | 常见排查点 |
| --- | --- | --- |
| `/mcp` | 既有有状态 Streamable HTTP；客户端初始化后保留会话 ID | 后续请求携带 `Mcp-Session-Id`、Agent Bearer 和协商的 `MCP-Protocol-Version`。 |
| `/mcp/2026-07-28` | 新版无状态路径；每次请求独立认证 | 每次 POST 携带 Agent Bearer、`MCP-Protocol-Version: 2026-07-28`、`Mcp-Method`、适用时的 `Mcp-Name`，并在 `params._meta` 中声明同版协议。 |

新版路径的缺失、重复或不匹配的协议元数据会在工具调用前返回 HTTP 400；跨源请求会被拒绝。旧路径的版本不匹配按既有 JSON-RPC 合同返回 `MCP_PROTOCOL_UNSUPPORTED`。`401` 先检查 Agent Key 状态与有效期；`429` 表示该 Agent 达到限流，不应通过换路径绕过。不要把管理员登录 token 当 Agent Key，也不要让客户端在两个路径之间静默回退。

排查完成后，用相同 Agent 在实际目标客户端做工具发现、允许查询、越权拒绝及审计核对。SDK 或本机 HTTP 单测不等于 Dify、Inspector 等客户端实测。具体请求示例见 [MCP 接入指南](INTEGRATIONS.md)。
