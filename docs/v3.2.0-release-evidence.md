## 支持边界

本版未提升其他数据库的“完整生产支持”级别。SQLBot MySQL 真模型问数、PostgreSQL B2 审批与列授权组合只在记录的版本、合成数据和单实例条件下验收；集群、真实客户负载及生产 SLA 未证明。SQLBot 聊天存储未保留适配器内部的 `agentsql.audit_id` 扩展字段，审计证据以网关持久记录为准。
