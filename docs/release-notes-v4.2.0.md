# v4.2.0 发布说明：多轮问数与受控文件数据

状态：已于 2026-10-27 正式发布。以下只描述已实现并有证据的范围；正式资产、升级与公网证据见 [v4.2.0 验收记录](v4.2.0-acceptance.md)，设计及限制见 [v4.2.0 设计记录](v4.2.0-design.md)。

## 新增能力

| 能力 | 本版范围 |
| --- | --- |
| 多轮问数 | 同一会话最多三轮成功问题和 SQL 作为上下文；每轮重新检查身份、数据源绑定、表列权限，并经网关执行和审计 |
| 业务语义 | 按工作空间与当前有权数据源管理术语、SQL 示例和推荐问题；示例只作为受限模型上下文，不直接执行 |
| 文件数据源 | 管理员导入有界 CSV/XLSX，独立托管 PostgreSQL 子绑定、加密暂存、审计发布、受控预览与删除；原版 SQLBot 页面可选择部分工作表 |
| 行规则 | PostgreSQL 单表、显式限定名和窄谓词的候选路径；行规则在网关执行，预览、历史重查和导出按当前规则重新授权 |
| 查询结果 | AgentSQL 自有页面提供当前权限下的 CSV/XLSX 导出和真实执行摘要；原版 SQLBot 的合成历史结果 Excel 下载已对照 |
| 历史迁移 | 从固定 SQLBot 社区版迁移可验证的会话元数据，保留旧 ID 与来源；旧 SQL、结果行、图表及凭据不迁移 |

## 已验证的兼容边界

本机使用未修改的 SQLBot 社区版 v1.10.2 浏览器、隔离 PostgreSQL 16 托管库和本地 Qwen 模型。合成 CSV 的登录、上传、数据源保存、结构、预览、三轮问数、历史重查、Excel 下载与删除通过原页面；双工作表 XLSX 的全选及只选 West 流程完成受控预览。临时 `region = 'east'` 行规则下，数据源预览、三条历史结果和 Excel 文件均只返回 East。重启 AgentSQL 网关及 ChatBI 应用容器后，原页面仍可读取既有托管数据源和两行预览。以上证据只覆盖指定合成数据与一个客户端版本。

文件导入拒绝公式、重复表头、路径逃逸、超限压缩展开与数值越界。所选工作表记录在加密绑定中；未选工作表不能经该数据源查询。跨用户、审计故障、授权撤销及响应丢失的定向测试分别检查失败关闭和恢复行为；这些测试不等于用户业务系统已通过验收。

## 使用限制与升级

本版不宣称 SQLBot 全部页面或 API 一致，也不宣称用户现有业务系统可以零改动替换。仪表板、助手、嵌入、完整设置、复杂图表、分析与预测等仍按后续版本逐项实现。托管文件当前只接收 CSV/XLSX，部分工作表选择后的 SQL 使用封闭 PostgreSQL SELECT 语法；未知语法和无法证明的授权路径会拒绝。行规则仅覆盖已验证的 PostgreSQL 窄形态。

升级前备份元数据库、审计库、托管数据库和 AgentSQL 加密密钥，保留原 SQLBot 实例与配置直到真实业务接入验收结束。标准离线服务包不含模型权重或运行时；公网 Demo 只提供明确标注的模拟交互，不接入真实模型或业务数据库。
