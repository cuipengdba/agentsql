# AgentSQL v1.6.0 设计：国产数据库故障关闭复验

**语言 / Language:** [简体中文](v1.6.0-design.md) | [English](en/v1.6.0-design.md)

## 用户问题与基线

v1.5.0 已在达梦 DM8 Pack3、金仓 V9R1C10 PG 模式和 Vastbase G100 Build 9 PG 模式的指定实例上验证有界只读、权限撤销、断库恢复、脱敏、持久审计与真实 MCP 客户端。逐库真实查询超时/取消和独立审计存储故障尚无同环境证据。管理员因此无法将这些场景视为已经通过生产故障验收。

本版只补齐这些故障边界，修复实际发现的问题，并使响应、日志、审计中的终态可辨识。它不扩大 SQL 方言、B2 列级授权、B5 会话或厂商版本范围，也不因故障测试通过而自动宣称完整生产支持。

## 执行合同

`MCP 客户端 → Agent/租户认证 → 数据源与策略 → 解析/规则 → 受控数据库执行 → 脱敏 → 持久审计 → 结果交付`。

1. 超时或取消发生在查询建立、读行、脱敏前或审计前时，不得交付部分原值或部分结果。驱动即使在读行后返回空错误，执行器仍须检查操作上下文。
2. 单次 SELECT 的终态审计须可持久记录；独立审计库不可用时，MCP 不返回允许结果。审计恢复后，新的允许请求须写入持久审计并按规则脱敏。
3. 有状态旧版 `/mcp` 保留 B5 会话的独立截止时间与回滚约束；无状态 `/mcp/2026-07-28` 将客户端断连传给执行中的只读工具。两条路径分别验证服务端语句超时和真实客户端取消，并保持安全、稳定的错误分类，不回显数据库原始错误、凭据或敏感数据。
4. 故障注入使用合成数据及独立测试账号，不修改生产实例。取消测试还须确认数据库端的慢查询已经结束或连接已被丢弃，不能只以客户端超时作为证据。

## 交付门槛

从 v1.5.0 正式包与数据快照演练升级和成套恢复；Go/Web、SQL 安全负向集与真实客户端复测通过；CI 对应候选提交；双架构正式包、签名、SBOM、GHCR 精确 tag、官网和 Live Demo 在同一正式版本下验收。任一必要门槛失败时保留候选证据，不发布或提升支持声明。
