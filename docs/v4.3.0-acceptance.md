## 正式发布实证

- Git tag `v4.3.0` 指向合并提交 `2af69ac81bbc7f0080471f7bc41c3863eded2f61`；主分支 CI [40408879245](https://github.com/cuipengdba/agentsql/actions/runs/40408879245) 的 Go、Web、文档集成和 govulncheck 全绿。
- 正式 AMD64 包 SHA-256 为 `f5a9abbb9ee462e25976b4a04136128a5a5de3a1d7263e9e2826b1e1e4e22eb1`，ARM64 包为 `a67f03b89e0b73bc347a85f82a2183a288362580c8d1dbeb48a885022710f3f4`。15/15 资产校验通过；独立的 `agentsqlctl release verify` 用受信公钥核实 3 份签名、来源提交和资产，报告 `status=verified`。
- `ghcr.io/cuipengdba/agentsql:v4.3.0` 与 `latest` 指向同一摘要 `sha256:9ff9c9e796cff1d367c19f081c35476a33dce00326bc6886e4afab0df585e8dd`。`v4.3.0-demo` 与 `v4.3.0-quickstart` 均可匿名读取 AMD64/ARM64 清单。
- 官网 release 目录为 `/var/www/agentsql/releases/20261026T231327Z`。中英文首页与 Demo 落地页均返回 200 和 v4.3.0；六份中英文 PDF 的公网字节与本地源文件一致。公网 Demo 镜像为 `v4.3.0-demo`，完成显式迁移检查后健康。
- 云端合成数据的内外网 MCP 查询分别得到允许审计号 303/305 和禁表拒绝审计号 304/306；两次允许查询各有 2 个脱敏单元格，拒绝命中 R010。公网未部署或接入真实模型。

当前实测使用本机合成文件数据与受控 PostgreSQL 网关，以及公网合成 Demo。真实客户业务系统的零改动替换、SQLBot 社区版全部页面和全部接入方式尚无完整证据，不能在本版宣称完成；它们属于 v4.5.0 的逐项验收。
