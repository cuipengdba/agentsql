# AgentSQL v3.7.0 MongoDB 与键值库受控读取设计

**语言 / Language:** [简体中文](v3.7.0-design.md) | [English](en/v3.7.0-design.md)

状态：实施设计。支持范围与发布结论以真实版本、拓扑和最终验收为准。

## 用户问题与范围

现有 `find_documents` 仅验证 MongoDB 7.0 指定单实例的精确集合、顶层字段、字符串等值过滤和最多 100 行读取；行数、响应字节数及超时已有上限，但未验证副本集成员切换及索引约束下的扫描成本。`read_key` 仅在指定 Redis 8.2.9 / Valkey 8.1.10 TLS/ACL 单实例读取字符串键；Hash 字段和 Sentinel 拓扑不在支持结论内。

本版目标是让管理员为明确的集合与 Hash 字段授予最小读取权，并在指定高可用拓扑故障时保持授权、脱敏和持久审计合同。继续拒绝任意 MongoDB 命令、聚合与写入，以及 Redis/Valkey 任意命令、批量枚举与写入。公开 Demo 仍只展示实际部署的 PostgreSQL/MySQL 合成场景。

## 产品流程与配置

1. MongoDB 管理员登记明确的副本集名称、种子节点、测试 CA 和每个成员的证书身份。只接受驱动发现到的同一副本集成员；不允许任意连接 URI、SRV 发现或 TLS 跳过校验。为每个受控集合配置由管理员核对的等值过滤索引；请求必须命中已批准的索引字段组合，受行数、返回字节、批次和执行时间限制。
2. Redis/Valkey 管理员登记明确的 Sentinel 主节点名称与地址清单，为 Sentinel 和数据节点分别配置 TLS/ACL 身份。发现的主节点必须处于允许的网络范围且通过证书验证；不能把 Sentinel 返回地址当作天然可信。无效发现、切主未收敛、证书不匹配或版本偏离均失败关闭。
3. Agent 的 Hash 读取使用单独的受控工具，指定一个精确键和少量显式字段。授权同时绑定 Agent、租户、数据源、逻辑库、精确键和每个字段；前缀键授权不能自动扩大到 Hash 字段。固定的只读 `EVAL_RO` 脚本须在服务端校验类型、字段存在性和总字节数后才返回结果，避免 `HSTRLEN` 与 `HMGET` 两次请求间的写入竞争导致无界响应。不开放 `HGETALL`、`HKEYS`、`SCAN` 或动态脚本。
4. MCP 返回前应用字段来源脱敏并写入最终持久审计。预检、拒绝、执行错误和审计故障均保留可定位结果；终态审计不可用时不得交付读取值。

## 安全与故障合同

| 路径 | 必须满足 | 失败行为 |
| --- | --- | --- |
| MongoDB 读取 | 当前 Agent 身份、租户和精确集合/字段授权；索引约束、超时、批次、行数及字节上限；只读数据库账号。 | 索引缺失或变化、未知执行计划、扫描超限、成员身份不可信、授权撤销时拒绝；不得退回无界扫描。 |
| Hash 字段 | 精确键和字段双重授权；字段名白名单、字段数和单值/总字节上限；只允许固定只读脚本与最小 ACL。 | 键类型变化、字段未授权、返回结构异常、主节点发现失败时不返回值。 |
| 高可用切换 | MongoDB 只连接受信副本集，Sentinel 只发现受信主节点；业务请求超时与重试次数有界。 | 旧连接或缓存不能绕过新的身份、策略、证书与 ACL 检查；不向未知地址发送凭据。 |
| 审计与脱敏 | 预检和终态持久审计、字段来源脱敏、无原始秘密值日志。 | 审计或脱敏依赖故障时失败关闭；不把数据库读成功当作可向 Agent 交付的充分条件。 |

## 验收标准

- 在指定 MongoDB 7.0 三成员副本集上，以真实 TLS/最小权限账号验证索引命中、主节点切换、证书错误、未授权集合/字段、索引删除与扫描超限；记录成员版本、镜像摘要和实际计划。分片集群不在本版声明中。
- 在指定 Redis 8.2.9 和 Valkey 8.1.10 的 Sentinel 测试拓扑上，以真实 TLS/ACL 验证 Hash 字段允许/拒绝、主节点切换、发现地址替换、无效证书、ACL 撤销、超大值及错误键类型。Cluster 不在本版声明中。
- 对两款既定 MCP 客户端完成允许与拒绝调用，并在独立审计库故障、业务库故障和恢复后核对脱敏结果与持久审计。记录无法实测的厂商/拓扑边界。
- 从上一正式版安装包及成套备份演练升级与恢复，完成 Go/Web/双语文档 CI、正式签名资产、GHCR 双架构、GitHub Release、官网和公网 Demo 验收。

本版不宣称 MongoDB 分片、Redis/Valkey Cluster、自动扩展到其他版本、长期生产 SLA 或厂商认证。
