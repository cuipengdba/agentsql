# AgentSQL v3.9.0 升级与回退

**语言 / Language:** [简体中文](v3.9.0-upgrade.md) | [English](en/v3.9.0-upgrade.md)

## 升级前

1. 停止旧网关写入，成套备份 metadata、独立 audit 库（如有）、`AGENTSQL_SECRET` 和数据源配置。先在隔离环境检查上一正式版包和 v3.9.0 包；本版预期 SQLite metadata 27/27、独立 PostgreSQL metadata 25/25 与 audit 7/7，无新增迁移。
2. Oracle TCPS 数据源在网关容器内挂载可读的 CA 文件，填写绝对路径、`verify-full`、2484 端口及与证书 SAN 匹配的连接主机。先用专用只读账号验证证书、表授权和 `PLAN_TABLE`；仅在需要 R004/R005 计划预算时设置 `{"oracle":{"explain":true}}`。既有未启用 TLS/计划的数据源保持原行为，但不能标为验证连接。
3. SQL Server 严格 TLS 数据源轮换服务器证书时同步更新受信 CA，复查主机名、数据库级 SHOWPLAN、读账号表权限和撤权。不得用 `TrustServerCertificate` 通过新路径的验收。

## 演练与回退

先在隔离候选上执行 `agentsqlctl migrate --check`，再由迁移负责人执行 `agentsqlctl migrate`；确认无 schema 变化、只读查询和拒绝、脱敏、终态审计与证书负向集后切换。停止新版网关、恢复成套备份与上一正式版二进制/镜像，再检查版本、迁移状态及健康端点。回退旧版时必须恢复升级前数据源配置；旧版不能解释新增的 Oracle 计划配置合同。
