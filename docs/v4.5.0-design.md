# v4.5.0 设计与发布验收合同

[中文](v4.5.0-design.md) | [English](en/v4.5.0-design.md)

状态：候选设计，尚未发布。正式对照基线是 [SQLBot 社区版 v1.10.3](https://github.com/dataease/SQLBot/releases/tag/v1.10.3) 的未修改客户端、服务端与公开接口；若发布前官方最新版变化，必须重新固定基线并补做变化面验收。v1.10.2 的旧证据只能定位回归，不算作 v1.10.3 通过。

## 用户目标

AgentSQL 以自己的 Go 服务、Web 页面和数据库安全网关实现完整问数产品。v4.5.0 对照 SQLBot 社区版的公开页面、API、MCP 与嵌入接入方式，并提供可离线下载、可信验签、一键安装的发行包。页面采用 AgentSQL 品牌与独立实现，原版静态资源只在隔离验收中使用。用户真实业务系统的切换与回退由用户在 v4.5.0 发布后推进，实际对接中发现的问题另行规划。

## 检索参数与知识召回的新增缺口

2026-11-02 以有效管理员会话对照原版 v1.10.3 与提交 `c3fd043c` 的 Go 候选 `GET /api/v1/system/parameter`：原版返回 18 个参数，该候选返回 9 个。该基线缺少 `embedding.enabled`、`embedding.table_enabled`、`embedding.terminology_similarity`、`embedding.terminology_top_count`、`embedding.data_training_similarity`、`embedding.data_training_top_count`、`embedding.table_count`、`embedding.table_alpha`、`embedding.keyword_enabled` 和 `embedding.datasource_count`。原版前端的系统设置页可编辑这些值；原版服务在每个问数任务开始时读取生效配置。对照记录位于 `D:\CodexLS\outputs\agentsql-v450\parameter-gap-v1103-20261102.md`。此后候选逐步加入十项接口参数；数据表与数据源行为对等仍待验证。

此项以实际行为验收：保存、重开、重启、参数边界与并发修改；开关及阈值真实影响术语、训练示例、数据表与数据源召回；同一输入在原版客户端和 AgentSQL 页面上对照。AgentSQL 只从当前身份仍可见的网关结构和知识项召回，撤权后不能继续使用旧向量或缓存提示；模型、向量库或审计故障时不得回退到未经授权的结构。仅补齐十个返回字段或展示控件不算完成。此缺口未关闭前，v4.5.0 不得声称完整问数功能对等。

进一步核查原版 v1.10.3 的术语和训练召回源码后确认：`embedding.enabled=false` 只停用向量搜索，词面命中的知识项仍返回；两个 `top_count` 只限制向量候选数。先前候选提交 `3482f54b` 与 `8085a63d` 把开关和数量限制施加到词面结果，虽然定向测试及 CI 通过，语义仍与原版不符，已在后续提交撤回。正确实现须保留当前受权词面匹配，同时加入真正的向量候选、相似度阈值和数量限制，并对原版与候选做同输入对照。此缺口仍阻断完整问数对等结论。

本机隔离原型又以 Apache-2.0 的 Hugot v0.6.0 原生 Go 后端加载原版镜像中同一 Apache-2.0 text2vec ONNX 模型。三句中文得到 768 维向量；“营业额是多少”与“销售收入是多少”的归一化余弦分数在 Go 为 0.816023、原版 Python 为 0.816024，与“今天的天气如何”的分数双方均为 0.313403。Go 首次加载约 6.2 秒，完整三句推理约 7.6 秒。模型 SHA-256、环境和命令见 `D:\CodexLS\outputs\agentsql-v450\embedding-go-prototype-v1103-20261102.md`。这证明向量推理方案可行，不是已接入的产品功能；仍须实现受权知识索引、参数生效、失效与撤权、并发、故障关闭和正式离线包的双架构模型交付。

## 本轮本地向量召回实现

候选分支现可从绝对路径 `embedding_model_path` 加载本机 ONNX 模型，不在运行时下载权重。术语和训练样例先按当前工作空间、数据源、启用状态筛选；训练 SQL 再按当前可见表列及只读解析结果筛选；词面匹配始终保留，随后才对剩余受权候选计算余弦相似度并去重。系统参数页已有 `embedding.enabled`、术语与训练的相似度及向量候选数量设置，保存使用原有管理员审计事务。模型故障拒绝此次知识召回。Go 的本地固定模型对照、参数越权和非法值、数据源隔离、不可见 SQL 与故障测试已通过；这是候选代码的局部验收。

本分支又增加数据表预选：仅对当前已授权的表列构建候选，用本地模型对问题和表结构做向量评分，可按 `embedding.table_alpha` 混合词面分数；`embedding.table_count` 限制普通候选，问题明确提到的表及表注释保留，同一处匹配优先保留长名称，未知的完整引号名不能误选其子串。`embedding.table_enabled` 和 `embedding.keyword_enabled` 在系统参数接口中可保存并作用于本轮问数。模型不可用或向量不完整时保留全部当前授权表；模型推理期间撤权须在模型生成前失败。旧版已保存的设置升级时补充新默认值。本地定向测试覆盖参数持久化、非法值、候选数量、开关和撤权。此阶段尚未复刻原版的关键词提取；持久向量索引的后续实现和验收见下文，原版客户端端到端行为对照仍未完成。

第三方数据源目录的 MCP 助手路径现增加 `embedding.datasource_count` 候选预选：先由已登记目录和当前授权映射确认可选集合，再用本地模型对目录名称与问题做余弦排序。达到数量限制时才缩减；缺失或无效向量保留全部候选，并继续要求模型显式选择。缩减到一项时仍需选择审计、模型租约及目录映射复核；被排除的 ID 不可作为模型返回值使用。原版普通聊天 `/api/v1/chat/start` 要求指定数据源；原版助手 `/api/v1/chat/assistant/start` 可不指定数据源，由首次问数从助手可用数据源中选择。MCP 第三方目录仍只实时编码目录名称；下面的内嵌助手路径使用本轮受权结构内容。候选现将当前授权候选的向量与内容指纹按工作空间和用户加密持久化；内容、固定模型或用户改变后重算。每轮仍先取实时可见内容并在选择后复核权限，缓存损坏时保留全部已授权候选。第三方目录当前只索引目录名称，原版的提前生成时机、超出 32 个候选的行为及生产规模性能仍未对等验收，不能据此声称完整对等。签名离线模型包尚未正式发布。

候选分支已补充无数据源会话创建、首次问数的当前受权候选选择、选择后的原子绑定及撤权复核。单候选不调用选择模型，多候选由模型返回候选 ID，非法或已撤销 ID 被拒绝；空问题不会先绑定数据源。内嵌助手的本地向量预选现使用本轮网关可见的表列、数据源描述和对应可见备注；不可见结构不进入向量输入，内容过大则保留全部候选。推理期间数据权限规则变化后还要重新核对，变化则停止绑定。原版助手页面已在本机 4B 模型上对只读订单库产生并显示经数据库核对的 2400 行计数；候选版原版 SDK 在另一合成销售表上完成真实模型问数、历史恢复和访客撤权。两者数据和问题不同，不能视为结果对等。另对同一订单库、同一问题和同一模型调用候选兼容 API，也得到 2400，网关审计为允许；SQL 因安全合同使用 `pg_catalog.count(*)`。原版未修改页面再通过本机静态代理连接候选 API，在同一订单库、同一问题和同一模型下显示 `row_count=2400`；在精确提交 `c92f63ac` 的本地二进制和五项全绿 CI 上重测，页面结果与重新登录后的历史重载再次显示 2400，且没有失败的 HTTP 响应。隔离别名撤销后旧会话返回 404，原版页面不再出现旧结果。网关故障时历史列表整体拒绝的安全合同未放宽。上述只证明一项页面数值及历史恢复对照；流结束原因、原版持久向量行为对照、完整行为、故障和并发验收仍未完成。

本机 `--network none` 的 Go 测试加载固定 ONNX 模型，先复核原版句向量分数，再用合成中文问题与名称真实运行数据源和数据表预选，均选中预期候选。测试还只覆盖单机 amd64；arm64、原版未修改客户端与大规模索引仍是发布门槛。

运行时加载推理会逐文件核对 SQLBot v1.10.3 固定模型目录的哈希，并拒绝缺失、改动或符号链接文件。这项校验不能代替离线包的外部公钥验签、安装校验与回滚。

模型文件清单现由内嵌的 `internal/chatbi/pinned_embedding_model.json` 统一提供给运行时和 `scripts/package-chatbi-model.py`。后者对固定目录进行全量校验，生成含模型卡与文件清单的确定性归档，并在写出后复核各成员。以相同输入和时间戳连续构建两次的归档 SHA-256 均为 `cea4c870ccd49d0551aaec8ee713fe2b2a991537138b82658142dc311ac193af`；本地生成的归档及侧车仍未进入正式签名 Release，也未完成安装和升级回滚。
构建器的 `--verify` 模式可在不解压的情况下按固定清单重新验证已有归档；正式离线安装器仍须先验签外层发布清单，之后才可调用此校验。

v4.5.0 发布资产清单扩为 17 项：在原有 15 项上增加固定 ChatBI 模型归档和 SHA-256 侧车。Go 发布验签器、离线传输包及离线安装器的资产清单按版本核对，旧版仍按 15 项验证；模型文件及侧车必须纳入已签名的 `SHA256SUMS` 和来源证明。生产装配须显式指定本地固定模型目录和 Python 解释器，归档结构及成员哈希在装配时重验。

离线安装器现先验签发布资产，再逐成员校验并安全提取模型归档；已验签的发行二进制通过 `chatbi verify-embedding-model` 独立核对固定模型。安装脚本在停止 ChatBI 前预检模型，复制后复验，将模型放入受管目录并配置服务读取路径；失败时将目录和配置回退到备份。本机断网 Linux amd64 容器中，实际固定模型的 `no-start` 新装及安装后的命令行复验通过；另用隔离故障注入验证了初始化失败时的新装回退。真实签名发行包的双架构断网新装、升级、旧版回退和服务启动仍待实测，不把这两项局部测试视为发布验收通过。

历史记录接口现按本轮权限、数据库绑定与身份指纹检查旧回答。规则变化或旧记录缺少指纹时，仅保留用户原始问题和时间等状态，不返回旧 SQL、图表、模型分析或结果，也不会重新执行旧查询；同规则下的新记录仍可读取。返回前再次核对规则快照。

## 安全与部署边界

客户端给出的用户、工作空间、数据库配置、规则和模型输出都只是待校验输入。Go 问数服务以当前服务端身份与绑定为准，在模型提示、历史读取、预览、导出、API、MCP 和嵌入查询前后重新确认权限；实际 SQL 只经 AgentSQL 受控网关执行。授权、策略、数据库绑定或审计证明不足时停止返回结果，且不能把旧结果缓存当作授权。

本分支现在保留元数据发现时的数据权限快照，在向量知识检索结束、模型调用前，以及模型生成结束、受控查询前再次核对。权限在检索期间撤销时，旧表列不会传给生成模型；权限在生成期间撤销时，SQL 不会进入查询。历史轮次的 SQL 必须再次通过本轮可见表列检查，且其独立加密保存的权限、用户与绑定指纹必须与本轮相同；旧版没有指纹的轮次不会进入模型提示词。新增行权限后旧轮次消失、相同权限下新轮次保留和旧版记录保守排除的本地测试已通过；原版客户端和真实并发环境仍须验收。

离线包默认安装应用组件；PostgreSQL 原生绑定器位于数据库服务器，必须由受信任的数据库侧交付或明确预装。选择 PostgreSQL 时，安装命令要以实际读取角色连接目标库完成绑定器能力和权限预检后才改动应用安装。公网 Demo 只提供明示的模型模拟交互，不配置或调用真实模型；真实模型验收只在本机完成。

## 已证实的兼容缺口

隔离 SQLBot v1.10.3 原版 API 在模拟模型和真实 PostgreSQL 合成表下，两次 `mcp_question` 非流式问数均返回两行、`success=true`、`title`、表格 `chart`，并在 `data` 中提供 Base64 SQL 与数值型 `datasource`；即使 `return_img=false`，原版仍返回图表配置，只跳过图片。候选现补齐该 JSON 字段形状，并在首次成功问数后持久化从问题截取的 20 字标题；定向测试覆盖再次问数不重复返回标题、关闭图片仍保留图表以及受控查询审计。原版模型可生成自己的标题和丰富图表，候选当前只提供问题截断标题与表格配置；这些行为、完整响应错误分支和原版客户端仍须逐项对照。隔离原版证据见 `D:\CodexLS\outputs\agentsql-v450\original-v1103-mcp-stubbed-model-data-20261101.md`，不能当作本机真实模型通过。

在提交 `aefb8897` 的隔离环境中，原版 v1.10.3 镜像内的 MCP Python SDK 已通过候选 SSE 入口，用本机 Qwen 和真实 PostgreSQL 合成表完成非流式及流式问数；两次网关查询各返回两行并留存审计。该测试覆盖一个 SDK 客户端路径，不等于未修改的 SQLBot 应用或业务系统零改动切换。原版服务的无效输入对照还确认：不可访问会话和非数字字符串数据源 ID 均返回 400，列表型数据源 ID 返回 422；候选已按相同状态处理，且均不触发查询。原版在某些无效令牌的 `mcp_start`、`mcp_model_list` 请求上仍返回 200，并将空问题返回 500；候选遵循网关鉴权与输入校验要求，继续拒绝这些请求。其他异常响应仍需逐项对照。证据见 `D:\CodexLS\outputs\agentsql-v450\original-image-sdk-real-qwen-pg-aefb8897-20261102.md`。
