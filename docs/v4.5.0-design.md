# v4.5.0 设计与发布验收合同

[中文](v4.5.0-design.md) | [English](en/v4.5.0-design.md)

状态：候选设计，尚未发布。正式对照基线是 [SQLBot 社区版 v1.10.3](https://github.com/dataease/SQLBot/releases/tag/v1.10.3) 的未修改客户端、服务端与公开接口；若发布前官方最新版变化，必须重新固定基线并补做变化面验收。v1.10.2 的旧证据只能定位回归，不算作 v1.10.3 通过。

## 用户目标

AgentSQL 以自己的 Go 服务、Web 页面和数据库安全网关实现完整问数产品。对已有 SQLBot 社区版集成，目标是在不修改业务系统的 URL、请求、鉴权、回调或嵌入代码的情况下切换服务；同时提供可离线下载、可信验签、一键安装的发行包。页面采用 AgentSQL 品牌与独立实现，原版静态资源只在隔离验收中使用。

## 安全与部署边界

客户端给出的用户、工作空间、数据库配置、规则和模型输出都只是待校验输入。Go 问数服务以当前服务端身份与绑定为准，在模型提示、历史读取、预览、导出、API、MCP 和嵌入查询前后重新确认权限；实际 SQL 只经 AgentSQL 受控网关执行。授权、策略、数据库绑定或审计证明不足时停止返回结果，且不能把旧结果缓存当作授权。

离线包默认安装应用组件；PostgreSQL 原生绑定器位于数据库服务器，必须由受信任的数据库侧交付或明确预装。选择 PostgreSQL 时，安装命令要以实际读取角色连接目标库完成绑定器能力和权限预检后才改动应用安装。公网 Demo 只提供明示的模型模拟交互，不配置或调用真实模型；真实模型验收只在本机完成。

## 已证实的兼容缺口

SQLBot 社区版 v1.10.3 的一个模型 ID 可映射多个工作空间，管理员可列出、替换、追加和移除映射。隔离原版 API 实测：首次创建的模型自动成为**全局默认模型**，即使它没有任何工作空间映射；移除全部映射后，模型和全局默认标志仍保留。原版源码还将全局默认模型列入每个工作空间的可用模型列表。当前候选版把模型配置单独存于一个工作空间，拒绝跨空间映射。正式兼容实现必须保留稳定模型 ID、共享配置和密钥、独立映射及管理员控制的全局默认指针；映射变更要在同一事务中完成身份、权限、审计与修订检查，运行时撤权后不得复用旧模型或返回旧结果。全局默认模型的可用性不授予任何数据库或数据访问权限。原版客户端的四种映射操作、模型编辑与密钥轮换、并发撤权和升级迁移均须通过对照验收。路径存在或静态路由数量不能替代行为证据。

候选问数执行链现在记录所选模型的修订和密文摘要；模型生成前、受控查询前、查询后及返回前重新读取。未激活目录时继续使用工作空间本地默认模型；合成负向测试在生成期间或网关查询期间轮换密钥，确认旧请求不返回 SQL 或数据。新增目录读取分支在测试中手动构造的激活状态下，可向另一工作空间解析同一个全局默认模型，并在目录切换、默认指针变化或密钥轮换后拒绝旧租约；生成期间轮换目录密钥的测试还确认网关未被调用。四种映射 HTTP 路由、全局模型列表/详情/创建/编辑/删除、全局默认模型切换、原版默认探测和模型连通性测试接口已在测试构造的激活状态下接入新目录；连通性测试在返回前复查模型修订。AgentSQL 自有模型页面使用的读、列表、增改删、设默认及连接测试 API 也已接入目录；新增工作空间映射选择控件，仅在目录激活时显示。使用模拟 API 的真实浏览器预览核对了中英文控件、保存映射发出的 PUT 请求及目录未激活时隐藏控件，尚未对实际后端完成浏览器验收。助手页面与 MCP 的工作空间模型列表使用显式映射，按原版 `by_ws` 语义排除未映射的全局默认模型；定向测试覆盖映射撤销后两处入口同步收敛。其他测试覆盖管理员限制、映射计数、密钥脱敏、编辑保留或轮换密钥、旧请求失效、默认模型删除拒绝及审计失败回滚。旧工作空间模型写入在同一控制库事务中检查激活标志，切换后拒绝写入，防止两套模型记录分叉。正式目录激活、页面映射控件对实际后端的浏览器验收、其余 MCP/嵌入入口、原版客户端完整行为对照和历史结果撤权仍未完成。

为后续迁移新增只读控制库预检：扫描现有工作空间模型，识别同一 ID 对应不同密钥或配置的冲突，统计待建映射，并在各空间默认模型不同或仅有非默认模型时要求显式决定。预检报告不含模型地址或密钥。管理员可在同一控制库事务中将旧模型暂存为加密的全局目录、显式映射和默认指针，并写入管理审计；审计失败回滚全部暂存对象，源数据变化会使重试拒绝旧快照。内部映射事务已支持同一模型追加、替换和移除多个工作空间；它核验管理员、当前模型修订和目标空间，并在同一事务中更新映射、模型修订及审计。定向测试覆盖跨空间映射、过期修订、重复或不存在的目标、审计回滚及清理已删除空间的遗留映射。暂存目录**尚未激活**，现有读写路径仍使用工作空间本地模型；正式切换、其他原版 API/页面接线、安装器升级门槛和客户端对照仍待完成。

## 发布决策

当前正式版本为 v4.3.0；v4.4.0 和 v4.5.0 均在草稿 PR 中。已完成的局部原版页面、PostgreSQL/MySQL、本机模型及脚本测试只证明其记录的环境和操作。逐页面与逐接口功能、完整安全负向矩阵、原版 MCP/嵌入客户端、业务系统零改动切换、正式双架构签名离线包与公开部署验收尚未完成。v4.5.0 Release、官网和 Demo 只能在以上门槛有可复核证据后同步发布；未完成时明确保留草稿状态，不使用“100% 兼容”表述。
