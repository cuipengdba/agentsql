# AgentSQL v4.11.0 会话、导出与嵌入闭环

> 开发合同。只有最终同一签名包的真实客户端、模型、网关和数据库正负验收全部通过，场景才可按固定矩阵计分。

## 基线与目标

AgentSQL 同时提供独立 AI 问数 Agent 与独立 MCP Server 数据库安全网关。SQLBot Community v1.10.3 是固定的可选客户端，不是 AgentSQL 问数服务的运行依赖。v4.10.0 正式版按冻结的 [25 场景合同](sqlbot-community-chatbi-score-v1103.md)严格通过 Q1、I1、H1，即 **3/25（12%）**。Q2、H2、H3、I3 已有真实正向切片，却缺完整原版页面或相关安全负向；重启后首次 CSV 曾安全拒绝 403，原因尚未确认。

本版优先闭合 Q2、H2、H3、I3，并检查 H4。五项全通过时，连同既有三项的同版复验，上限为 **8/25（32%）**，这是工作目标，不是发布承诺。未满足完整条件的场景继续计零；不修改分母或把旧版证据继承为本版通过。目标是扩大可证明的用户流程，不以放宽授权换取分数。

## 功能与安全合同

| 场景 | 正向验收 | 必需负向与故障关闭 |
| --- | --- | --- |
| Q2 受权单表表达 | 未修改原版问数页和 AgentSQL 自有页在真实本地模型、PostgreSQL 和同源码网关下，分别验证过滤、分组、排序、限量的 SQL、行值与顺序 | 未受权表列、模型给出的非只读 SQL、超出结果预算、查询期间行列规则或绑定变化均不能释放旧值；核对受控审计 |
| H2 重启历史 | 两种页面在 ChatBI 进程重启后重新登录、重开同一历史，按当前权限显示 SQL 和行值 | 另一用户、禁用成员、撤销或更换绑定、行列规则变化后旧 SQL/值不能通过列表、详情和追问恢复 |
| H3 历史导出 | 未修改原版页面的 Excel 与 AgentSQL 自有页的 CSV/XLSX 导出，文件行数和值与当前受权网关结果一致；重启后首个请求单独记录 | 撤权后旧文件 404/拒绝且无泄漏；网关审计或本地导出收据写入失败时不得发送文件；公式样式内容保持字面文本。重启后偶发 403 需归因，不能以重试成功冒充首请求稳定 |
| H4 会话生命周期 | 新建、列表、重命名或标题显示、删除、重新登录后的列表一致性及历史隔离 | 删除后详情/导出/追问拒绝；跨用户和跨工作空间 ID 不泄漏；并发删除期间不释放旧结果 |
| I3 基本与 Type 4 嵌入 | 原版 `assistant.js` 基本助手和 Type 4 页面嵌入，在允许来源完成真实问数、刷新和历史恢复 | 非允许 Origin、空或恶意 Referer、伪造或跨框架消息、游客禁用、应用或数据源撤权后不得获得令牌或旧结果，且无新增受控查询 |

每次问数、历史重查及导出都从服务端当前身份、工作空间、数据源绑定和权限得出决定。模型 SQL、浏览器参数、历史 SQL、下载地址与嵌入消息都不授予权限。执行前和返回前复核；无法确认当前权限、网关审计或持久化收据时故障关闭。排查瞬时 403 必须保留拒绝证据并定位原因，不能通过盲目重试被拒绝的查询或降低审计要求修复。

## 范围边界

本版不承诺 128 表准确选表、双表关联、任意 SQL 方言、云模型真实推理、任意数据源创建、角色/多用户活动权限、Type 1 高级助手或用户业务系统零改动切换。原版接口若有不安全放行行为，AgentSQL 保持更严格的拒绝并在计分中保留零分。ARM64 QEMU 验收不代表实体 ARM 服务器；公网 Demo 只使用合成数据和模拟模型。

## 发布门槛

1. 最终精确提交的五项 GitHub CI 全成功；行为变更有确定性测试和相关安全负向，原始日志标明源码、客户端、模型、数据库、资源与退出码。
2. 同一最终签名包重新复验 Q1/I1/H1，并逐项公布全部 25 场景的通过或零分、未通过原因及证据。任何越权、未审计执行、旧结果泄漏或危险 SQL 执行阻断发布；未达到计分目标但安全的版本可如实发布。
3. 从最终源码构建正式双架构资产与外层离线包，独立可信公钥验签；AMD64 与 QEMU ARM64 分别断网进行新装、从正式 v4.10.0 升级及注入启动失败回滚，核对服务、健康、模型哈希和元数据完整性。
4. 合并后发布 GitHub Release、GHCR 精确多架构标签并匿名回拉；官网与明示模拟的 Demo 更新到 v4.11.0，公开健康、允许、拒绝、脱敏和审计烟测通过；规范主仓库 `main` 与 `origin/main` 一致且干净。

发布说明必须写明实际分数、未在用户真实业务系统验证、ARM64 QEMU 边界及未关闭的可靠性限制，不宣称 80% 或 100% 兼容、零改动切换或生产 SLA。
