# AgentSQL v3.0.0 发布说明

状态：候选版。正式 Release、镜像、官网和公网 Demo 仅在各项发布验收完成后对外确认。

## 本版范围

- 将 30 款已注册数据库的 Agent 能力分为受控 SQL、有界 SQL、独立受控读取工具、连接或管理预览四层，统一从管理 API、控制台与已授权 MCP 数据源清单呈现。每项附工具入口、限定范围与证据文档。声明不授予权限，真实调用仍走身份、对象策略、规则、执行、脱敏和持久审计。
- 新增只读 `agentsqlctl doctor --config ... --format json|text`，检查配置及已配置的 metadata/audit 迁移历史。退出码 0 为就绪，2 为待迁移，1 为配置或存储阻断。它不运行 DDL、不创建缺失 SQLite 文件，也不输出凭据。
- 新增 `scripts/mcp-acceptance.py` 用于明确标记的合成环境，检查工具发现、允许、规则拒绝、脱敏和审计 ID。脚本仅从环境读取 API Key，不打印数据行或密钥。

## 升级与边界

v3.0.0 不增加 schema 迁移；v2.9.0 的合并 metadata 版本 23、分离 metadata 版本 22 和独立 audit 版本 6 保持不变。仍须按[部署指南](DEPLOY.md)成套备份并在隔离环境验证恢复；B2 租约存活期间不允许新旧网关并行争用。本版不增加数据库驱动、写入入口或新的厂商完整生产支持声明。验收范围见[设计](v3.0.0-design.md)和[候选记录](v3.0.0-acceptance.md)。
