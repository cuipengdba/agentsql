## 云端升级恢复与限制

首次切换 Demo 时，新程序在旧 SQLite schema 27 上拒绝启动；自动脚本从停机备份恢复旧卷与 v4.1.0 Compose，旧网关重新健康。随后重新停机备份，显式执行 v4.2.0 `agentsqlctl migrate` 与 `migrate --check`，确认 schema 29 后再启动新网关，并在内外网重跑允许、脱敏、拒绝与审计。整个过程未使用真实业务数据库或云端模型。

当前证据只覆盖列出的合成数据、客户端版本与本机/演示环境。SQLBot 的完整功能、全部页面、复杂图表与用户业务系统的零改动替换仍未验收；这些项目保留为后续版本与 v4.5.0 的独立门槛。公网问数界面只提供明确标注的模拟交互，不部署或调用真实模型。
