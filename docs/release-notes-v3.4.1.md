# AgentSQL v3.4.1 安全修复说明

**语言 / Language:** [简体中文](release-notes-v3.4.1.md) | [English](en/release-notes-v3.4.1.md)

v3.4.1 修复管理控制台审计 SSE 的租户隔离。此前，拥有“查看审计”权限的已认证用户连接事件流时，进程内事件缓存中的其他租户历史事件及实时事件可能被发送到该连接。该问题只涉及管理 SSE `/api/v1/stream`；正式审计查询 API 继续执行租户过滤。

修复后，事件流要求有效的已认证租户，并在发送历史或实时事件前核对事件的租户标识。不属于当前租户或缺少租户标识的事件不会发送。回归测试覆盖跨租户历史事件、实时事件及本租户正常接收。

使用多租户管理控制台和审计 SSE 的部署应升级到 v3.4.1。升级后重新验证审计查看权限和事件流；不需要变更数据库 schema。v3.4.0 的金仓和 Vastbase 支持边界不变，参见 [v3.4.0 发布说明](release-notes-v3.4.0.md)和[真库验收](v3.4.0-acceptance.md)。

发布状态与签名资产、镜像和公网验收结果记录在 [v3.4.1 发布证据](v3.4.1-release-evidence.md)。
