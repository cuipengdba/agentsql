# AgentSQL v2.9.0 发布说明（候选）

状态：开发中，尚未正式发布。

## 本版范围

- 增加租户策略包导出、差异计划、保守表级回放、提案、异人审批、原子应用和批准基线漂移提示。控制台新增“策略包治理”入口。
- 新增 Ed25519 审计 ZIP 外部见证与核验命令，用独立持有的密钥绑定归档字节和声明的审计链头。`verify-archive` 仍可单独校验归档内部完整性。
- 修改限于无 B2 绑定及列/行约束的表级 allow/deny 策略；一次最多 32 项变更，单租户包最多 128 条策略。离线回放只产生 `candidate`、`deny`、`unknown`，真实业务 SQL 仍需经网关执行链验证。

## 升级与边界

元数据 schema 合并部署由 22 升至 23，分库部署由 21 升至 22；独立审计库仍为 6。按[本版升级与恢复步骤](v2.9.0-upgrade.md)先做预检和成对备份，再显式迁移。此前数据库适配能力和支持级别保持原有实测边界；本版不增加新的数据库生产支持声明。完整验收见[候选记录](v2.9.0-acceptance.md)。
