## 支持边界

达梦结论只适用于上述 DM8 Pack3 构建、单实例和合成数据，不宣称完整生产支持或主备切换。连接池上限 2 时，12 次、并发 2 的负载通过；探索性并发 4 曾出现 SQLite 元数据锁等待和超时，故更高并发与 PostgreSQL 元数据部署须单独容量验收。金仓、Vastbase 和其他数据库不继承本版达梦证据。
