# AgentSQL v3.3.0 候选验收

**语言 / Language:** [简体中文](v3.3.0-acceptance.md) | [English](en/v3.3.0-acceptance.md)

状态：候选版验收中；正式资产、CI、官网和公网 Demo 尚须按 [发布流程](RELEASE_ROUTINE.md) 核对。

## 固定环境

| 项目 | 实测配置 |
| --- | --- |
| 数据库 | 用户提供的 `dm8_20241022_x86_rh6_64_single` 镜像，DM8 Pack3 `dm8_20241022_rev244896_x86_rh6_64`，单实例，`COMPATIBLE_MODE=0`，合成数据；本地只读许可证截至 2027-06-25。 |
| 通信 | `ENABLE_ENCRYPT=1`、`MIN_SSL_VERSION=771`（TLS 1.2）；AgentSQL 显式 `verify-full`，指定 CA 和证书名称。该构建拒绝官方手册列举的 `ENABLE_ENCRYPT=5`，故未声明该模式。 |
| 资源 | 隔离容器与临时 SQLite 元数据；达梦只读账号仅具 `CREATE SESSION` 和测试表 `SELECT`，数据源连接池上限 2、行上限 10、语句超时 20 秒。 |

## 已完成的真库验证

| 检查 | 结果 |
| --- | --- |
| TLS 验证 | 正确 CA/主机名可查询；错误 CA 和错误名称在握手时失败。单元测试还覆盖明文/仅握手模式、缺失配置与绕过验证的失败关闭。 |
| 证书轮换与进程重启 | 隔离 DM 实例更换新 CA/服务端证书并重启。旧 CA 随即以 `unknown authority` 被拒；新 CA 的直连查询通过，随后完整 MCP 权限、脱敏、审计、负载及故障恢复复测通过。 |
| 查询与计划 | 2505 行合成数据的字段类型、样本、分页、截断、最小权限和错误分类通过。索引与顺序扫描 EXPLAIN 均得到正规化估算；`LIMIT` 产生的 `TOPN2` 受控识别。扫描节点行数汇总与溢出拒绝有单元测试。 |
| MCP 安全链 | 真实 HTTP MCP 的允许查询获得脱敏值与审计 ID；写语句及未授权对象被拒绝，允许/拒绝记录可从持久审计读取。 |
| 有界负载 | 12 次真实 MCP 查询、并发 2、数据库连接池上限 2，成功 12、错误 0；每次返回脱敏值及审计 ID。一次隔离复测的 P50 为 2.19 秒，P95/P99 为 2.79 秒；这是小样本观测，不是生产 SLA。 |
| 故障关闭与恢复 | TCP 故障代理切断既有及新建连接后，MCP 请求拒绝且不返回原始手机号；恢复后新连接重新完成证书验证、脱敏和审计。 |
| v3.2.0 升级与回退 | 对 v3.2.0 在线 SQLite 备份制作两份独立副本。v3.3.0 候选版和 v3.2.0 回退版分别启动并通过健康/就绪检查，两份副本均保留 350 条历史审计，`quick_check` 与迁移表检查通过。原运行实例未被改动。 |
| 独立演示 MCP 验收 | 用 v3.3.0 候选镜像在隔离目录完成 Demo 播种。真实 HTTP MCP 的允许查询返回 2 个脱敏单元格与持久审计 ID；`SELECT *` 触发 R010 拒绝并记录另一审计 ID。接入文档的示例 SQL 同步修正为这套可执行剧本。 |

## 未完成与边界

仍须完成正式发布 CI、正式双架构资产及签名、GHCR 匿名拉取、官网和公网 Demo 烟测。4 路超出本次数据源连接池上限的探索性压力测试曾出现 SQLite 元数据锁等待及超时，故本版只记录上述 2 路有界结果；更高并发与 PostgreSQL 元数据部署需要单独容量验收。证据只覆盖指定构建、单实例和合成数据，不宣称达梦完整生产支持。
