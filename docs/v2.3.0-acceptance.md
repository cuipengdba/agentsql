## 边界

- 这里只证明 SQL Server 2025 Developer x86_64 Docker 单实例、合成数据、严格 TLS 和窄 SELECT MCP 安全路径。`SHOWPLAN` 是数据库级权限；未授权表的 R010 在网关静态规则阶段终止，不用管理账号代替只读账号跑执行计划。
- 尚未证明其他 SQL Server 版本、Windows、Always On、生产证书轮换、长期负载、客户拓扑、复杂 SQL、B2 列级授权、B5 会话或写入路径。不得声明厂商认证或完整生产支持。
- 官网 Live Demo 保持合成 PostgreSQL 数据，不展示 SQL Server 真库。
