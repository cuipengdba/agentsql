# AgentSQL v4.13.0 受权结果图表

## 用户目标与范围

AgentSQL 是独立 AI 问数 Agent 与独立 MCP Server 数据库安全网关。本版以正式 v4.12.0 为基线，让用户能正确地把当前受权结果切换为柱图、折线或饼图，明确选择维度和最多四个指标，并在重新打开历史时获得当前授权下的结果和问题指定的默认图表。

现有前端会把第一个数字字段当指标，可能把编号画成业务数值；空字符串、布尔值等宽松转换会误变数字；全零结果不出图；折线可能跨空值连线。本版修正这些可复现问题，增加多指标映射、明确的缺失值与数值精度边界。图表只是当前结果的投影，不新增SQL执行权或保存结果缓存。

## 实现合同

- 图表字段只来自当前受控响应。维度与指标显式可选，最多四指标；原始表格始终可用，切换不查询数据库。交互选择仅属于当前视图，不保存浏览器缓存；重开采用问题生成的持久元数据默认配置。
- 数值必须是有限的十进制数或规范十进制字符串；空值不等于零，布尔、空白、十六进制、非有限数、超过JavaScript安全数值范围的内容不画成数值。折线在缺失点断开，全零结果可画。饼图仅单指标、非负且总量为正，不静默丢弃负数。
- 最多展示当前结果前20行，明确展示行数及网关截断状态；保留原始表格数值。字段与标签以文本节点插入，不接受HTML、脚本、任意样式或浏览器给出的SQL。
- 问题明确指定柱/折线且结果为一个类别和最多四个可证明数值字段时，生成字段名组成的图表配置，供固定原版客户端与自有页面使用。饼图只接受单指标；歧义或不支持形态回退表格。配置不包含行值。
- 历史仍通过当前身份、绑定、策略指纹和受控重查；策略变化、会话删除、审计故障等既有拒绝不能被图表切换绕过。新页面或身份替换后不保留旧图。

## 验收与发布

1. 确定性测试覆盖多指标映射、默认维度、零值/空值、负值、超范围数值、恶意标签与配置歧义；浏览器核对标记、图例、断线与切换。
2. 最终同一签名包使用真实本地模型、固定ONNX、PostgreSQL与受控网关，核对原版v1.10.3客户端和原生页面的基础图、多指标柱/折线、历史重开；补撤权、跨用户、删除与故障负向。V1/V2只有完整合同通过才计分，v4.12.0的6/25也须在当前包复验，不继承。
3. 精确提交五项CI、生产双架构资产/外层包签名与独立可信公钥验签、AMD64/QEMU ARM64断网systemd新装、正式v4.12升级与失败回滚；GitHub Release、GHCR匿名回拉、官网和模拟Demo更新、公网烟测、latest及规范main闭合。

## 边界

不承诺80%或100%兼容、任意图表、自定义JavaScript、生产SLA或新的数据库生产支持等级。未在用户真实业务系统验证。QEMU不是ARM实机，公网问数Demo继续明示模拟。需要精确大整数或复杂数值时使用原始表格；图表使用有限精度数值。已经发送到客户端的数据无法追溯收回；本地切换仅投影已返回的数据，新的加载与历史重开须重新授权。

发行工具链提升到Go1.26.11，修复GO-2026-6859的net/http请求体限制头部竞态。CI、Rocky双架构原生包和Docker构建使用同一补丁版本，离线缓存按官方AMD64/ARM64固定SHA256验真；不通过忽略漏洞放行。
