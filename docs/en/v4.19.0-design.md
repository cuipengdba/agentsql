# AgentSQL v4.19.0 · Analysis of governed query results

Analysis uses current gateway-audited query results. The native Q&A page and fixed SQLBot Community v1.10.3 client retain their analysis entry points. The release targets 21 of 25 fixed cases after V3 and the existing scenarios pass. [Scenario definitions](sqlbot-community-chatbi-score-v1103.md)

## Numeric analysis

For a complete, authorized and unmasked PostgreSQL result with one dimension and one exact integer or decimal measure, the service calculates totals, shares, and changes between observed times. Shares use the sum of returned rows. Changes from zero show the absolute difference. Date series compare adjacent observations in the result. The native page identifies the calculation method. Results outside this scope use the existing bounded model analysis and authorization checks.

The original client receives the existing analysis events and can reopen saved analysis from history. The service checks the current account, bindings, permissions, and data during generation, persistence, and release. It withholds historical analysis when authorization or data changes, and closes on database or write failures.

Acceptance uses the fixed original client, local Qwen and synthetic PostgreSQL orders. It checks numeric results, gateway audits, failures and recovery in both clients and captures Chinese product screenshots. The public Demo labels its simulated model. The user's production system has yet to be validated.
