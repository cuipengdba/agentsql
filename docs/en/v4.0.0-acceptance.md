Diagnostics inspect configuration and metadata/audit schemas and attach a static product capability catalog; they do not run customer business queries. Test evidence uses synthetic data and does not expand database support claims.

The PostgreSQL upgrade fixture uses a memory-backed data directory; paired `pg_dump` backups are retained on the host. This proves migration and backup-restore correctness, not power-loss durability. Old encrypted fields use fixed synthetic opaque values: the check proves preservation, not decryption of customer ciphertext. Initial fixture failures from a misspelled masking algorithm and insufficient PostgreSQL initialization wait were corrected, with failure logs retained; passing results come from complete reruns.
