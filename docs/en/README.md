## History

Release notes, acceptance, design and performance records with file names containing `v0.*`, `v1.*`, and `v2.*` are applicable to the corresponding versions. They are for traceability and are not entry points to the current installation or operations. The local path, version, and outstanding status in earlier reports were recorded at the time; the current status is subject to the official Release and current guidelines.
