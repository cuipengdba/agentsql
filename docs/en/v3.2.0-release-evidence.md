## Support boundaries

This version does not raise any other database to “full production support.” SQLBot MySQL model-generated queries and PostgreSQL B2 approval with column authorization were accepted only on the recorded versions, synthetic data, and single-instance environments. Clusters, real customer workloads, and a production SLA are unproven. SQLBot chat storage did not retain the adapter's internal `agentsql.audit_id` extension field; durable gateway records are the audit evidence.
