Status: official release acceptance complete. The functional and upgrade tests below used candidate commit `309f97a` in synthetic environments. After one runtime stopped, a remaining node delivered the second event once, and the cursor advanced to 2. This is a local synthetic denial and receiver, not a public network or customer topology. |
| Restart and admin API | In a SQLite test, an initial webhook failure retained the cursor and retry state. After runtime restart and endpoint recovery, the same Delivery ID was delivered. ## Release conclusion and scope

All four main CI jobs passed for final commit `20a997a`. The 15 official assets, three signatures, three exact dual-architecture GHCR tags and `latest`, public website, and live Demo were verified; the [release evidence](v3.6.0-release-evidence.md) records digests and paths. A proposal, separate-person review, and apply across two actual deployments, plus external object-storage retention and archive-window coverage, are not established by these local fixtures.
