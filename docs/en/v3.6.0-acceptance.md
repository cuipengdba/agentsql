| Area | Evidence and result |

After one runtime stopped, a remaining node delivered the second event once, and the cursor advanced to 2. This is a local synthetic denial and receiver, not a public network or customer topology. |
| Restart and admin API | In a SQLite test, an initial webhook failure retained the cursor and retry state. After runtime restart and endpoint recovery, the same Delivery ID was delivered.
