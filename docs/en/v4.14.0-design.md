# AgentSQL v4.14.0 · Single-table analysis and authorized table selection

**Languages:** [Chinese](../v4.14.0-design.md) | [English](v4.14.0-design.md)

v4.14.0 addresses two tasks: verifying the filters, aggregates, ordering and result rows of single-table questions, and finding the right table for a Chinese business question among 128 authorized tables. The fixed SQLBot Community v1.10.3 matrix targets Q2 and Q3 for a cumulative 10/25. The actual score comes from testing one final signed release. [Scoring contract](sqlbot-community-chatbi-score-v1103.md)

## Acceptance scenarios

| Scenario | Required result |
| --- | --- |
| Single-table filters | Filter by region, status and date. Verify the columns, row values and exact ordering through the native and unmodified original pages backed by the same read-only gateway. |
| Grouping, ordering and limits | Sum actual order amounts by region. Verify the totals, ordering, top N and matching controlled-query audits. |
| Cold first question across 128 tables | Start without an index and ask a Chinese question without a physical table name. The fixture includes actual orders, similar forecast and canceled-order tables, ledger distractors and an inaccessible table. Verify the actual query object and result. |
| Warm first question | Repeat the question and a paraphrase once prewarming is ready. Repeat again after a service restart with a warm index. Record foreground selection, gateway and end-to-end timings, including errors and timeouts. |
| Authorization and failures | Verify policy changes, access revocation, model interruption and canceled index jobs. Revoked metadata must stay out of the index, model context, returned results and history. |

Reuse the existing authorized schema, keyword matching, pinned ONNX model and encrypted index. First measure v4.13.0 on the same real model and PostgreSQL fixture, then identify faults in selection, generation and execution to drive changes. Report timings with hardware details, concurrency, index state and sample counts. A fastest sample does not establish p95.

AgentSQL continues to offer native Q&A and independently deployed MCP Gateway. External clients retain access through current identity and permissions. This release verifies a PostgreSQL read-only scope and preserves the model, gateway and database authorization boundaries. The user's business system has not been verified.

Delivery includes the fixed matrix, real model and database evidence, authentic Chinese screenshots, GitHub documentation, signed assets, the website and a public Demo with an explicitly simulated model. [Release process](RELEASE_ROUTINE.md)
