# AgentSQL v3.0.1 Design

**Language:** [English](v3.0.1-design.md) | [Simplified Chinese](../v3.0.1-design.md)

## User issues

The official website and console were previously only in Chinese, and the GitHub English README was stuck in the old version, making it difficult for overseas users to understand the current boundaries of capabilities. As the entries in the left menu of the console increase, when the display zoom is larger or the browser CSS viewport is shorter, the bottom entries are cropped and cannot be reached by scrolling.

## Scope and implementation

- The official website provides Chinese `/` and English `/en/`; the Live Demo secure entrance provides `/demo/` and `/en/demo/`. Each page has explicit language switching and alternate/canonical metadata. The English portal passes `?lang=en` to the independent Demo console.
- The GitHub project README provides Chinese and English links, and the English README is aligned with the current version. The language of the GitHub platform interface is set by the user on GitHub.
- Language buttons are provided on the web console login page and header. Browser persistence selection, accepts `?lang=en|zh` deep link. Ant Design, dates and numbers follow the language. The static copy of the existing page should be overwritten with the checked English directory; the new interface should use an explicit locale key. SQL, code, editable fields and query result values ​​are not translated.
- The left menu is placed in an independent focusable flex scroll area, the brand area is fixed, and the short viewport can use the mouse, touchpad or keyboard to reach the last item.

## Compatibility and security boundaries

No API, database protocols, permissions, enforcement, masking, auditing, or schema changes. The English catalog covers the current static interface copy; non-result values ​​passed in from the backend that happen to be the same as the catalog key may still be recognized as interface copy, and new pages should be gradually migrated to explicit keys. Detailed operating documents and PDFs are still in Chinese, and the English official website is clearly marked. The database adaptation range follows v3.0.0 and the evidence of each adaptation version.

## Acceptance

For the release of access control, see [ acceptance record ](v3.0.1-acceptance.md).
