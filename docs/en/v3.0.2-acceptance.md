- Windows host Docker Desktop isolation project `agentsql-v302-test`; PostgreSQL 16, MySQL 8.4 demo library, only synthetic data.
- Web type check, 1398 translation term checks, 17 test files, 56 use cases and production build passed.
- The `internal/mcpserver` and `internal/policy` tests passed under Go 1.26.10; the new use case proves that the field type of the unauthorized column does not enter the MCP output.
- The real browser has a 1600×600 viewport, light navigation background `rgb(255, 255, 255)`, text `rgb(23, 32, 51)`; menu height 536, content height 970, scroll distance 434, and the bottom of the last entry is 596, reachable.
- SQLBot official v1.10.2, commit `aa41fc1033bb974a703df9200a98ec8b9eec5f25`; mirror index `sha256:1a573b42481b4cf95ac225ed9e93fbc6821d56f1ced859f779c0e014df24acb4`. The adapter installer checks the original database module SHA256, six high-level entrances are taken over, and seven low-level connection entrances are blocked.
- When the actual SQLBot Python is running, the database entry is called to complete the connection, table discovery, 5 typed field discovery, allowed query, mobile phone and email masking, explicit numeric alias conversion, unauthorized denial, cross-workspace denial, invalid Key denial, direct connection blocking and gateway unavailable denial. Persistent SQLite audit check `302=allow`, `303=deny`.
- Adapter unit tests cover permission decisions, audit IDs, result structures, numeric precision, source code drift, and no-retry paths.

- Supplementary actual fault verification: reject the request after deactivating the Agent; SQLite audit inserts a trigger to simulate a fault without delivering results, and the same allows query recovery after deleting the trigger. The first recovery use case misused unqualified column SQL that could not pass the existing B2 identity certificate. After correcting it to a verified synthetic JOIN, the entire set of retests passed; it was not a relaxation of authorization.
- The new logo uses SVG master to unify the official website, GitHub README, Web login page and sidebar, and the copy consistency is checked by CI.

## Validation boundaries

SQLBot acceptance is for specified official images, PostgreSQL execution portals, and synthetic data; there is no claim to complete production acceptance of complete natural language queries, all charts, and multiple workspaces under external model accounts. The original version, protocol and topological boundaries of the database remain unchanged.

## Release threshold

Documentation, PDFs, CI, signed dual-architecture assets, anonymous downloads, upgrade/restoration, GHCR, website and public Demo acceptance are complete. See the [release evidence](v3.0.2-release-evidence.md) for actual commits, digests and runtime results.

Supplementary key revocation actual test: After establishing an MCP session for an independent synthetic agent, the key is rotated. Subsequent tool requests from the original session are rejected; the new key re-handshakes successfully. Deleting the synthetic Agent after testing will not affect the default identity of the demonstration. The adapter unit tests ended up being 11 items.
