## Support boundaries

The PostgreSQL B2 column authorization executor and read approvals have not passed combined acceptance. Approval requests fail closed while B2 is enabled; the complete approval path covers only the isolated configuration with B2 explicitly disabled. This release does not promote any database to a higher production support tier. The console overflows horizontally at a 390px viewport; a subsequent UI release should address it. The public Demo does not imply a production SLA.
