## Security boundaries and unverified items

- The Oracle minimum privilege account does not have verifiable write permissions for `PLAN_TABLE`. This version disables the plan binding of pre-execution `EXPLAIN PLAN` and static R010 in this path; the native management account `EXPLAIN` test does not mean that the gateway account has this ability. Plan estimates for R004/R005 do not apply to this Oracle subset and the execution row limit is still in effect.
- SQL only allows narrow SELECTs acknowledged by both parser and executor. Functions, complex JOINs, CTEs, subqueries, writes, transactions, system catalogs, and unlisted syntaxes remain rejected; B2 column-level authorization, B5 sessions, TCPS, certificate rotation, client cancellation and timeout termination, active/standby/RAC, sustained load, arm64 Oracle server, and commercial editions are not verified.
- Testing of Oracle Free images does not constitute vendor certification or full production support. Official support statements are limited to this release, `FREEPDB1`, single instance, synthetic data, and read-only subsets.
