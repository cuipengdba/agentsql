## Support boundary

The Dameng result applies only to the pinned DM8 Pack3 build, one instance, and synthetic data. It does not establish complete production support or HA failover. With a datasource pool limit of two, twelve requests at concurrency two passed; exploratory concurrency four encountered SQLite metadata lock waits and timeouts. Higher concurrency and PostgreSQL metadata deployment need separate capacity acceptance. Kingbase, Vastbase, and other databases do not inherit this Dameng evidence.
