The signature assets of v0.6.1 can be found in its [ official Release](https://github.com/cuipengdba/agentsql/releases/tag/v0.6.1); the final rollback drill, v0.7.0 board submission and corresponding CI, as well as the actual results of GitHub Release assets, GHCR and official website are recorded by the v0.7.0 GitHub Release text and release evidence; this article does not claim approval in advance. ## Evidence caliber

This round examines code built at different points in time against the `feature/v0.7.0` working tree. There are still source code fixes after partial inspection, so these results cannot be combined to form a complete acceptance of the same immutable commit. GUI query for Linux amd64 test package using commit `9429b25f800de1333d63feab72cc550fdb23f54f`; commit [GitHub CI](https://github.com/cuipengdba/agentsql/actions/runs/38815198187) was successful. The official closure submission, clean working tree, actual commands and exit codes, and the results of rebuilding from this submission are subject to the v0.7.0 GitHub Release text record.

Database and client checks use isolated instances, loopbacks or private networks, test identities and synthetic data. They do not represent real customer environments, vendor certifications, official production licenses, full SQL syntax, or "full production support." The board submission and its CI are subject to the v0.7.0 GitHub Release text and tag; for version range and restrictions, see [ release notes ](release-notes-v0.7.0.md) and [ deployment guide ](DEPLOY.md).
