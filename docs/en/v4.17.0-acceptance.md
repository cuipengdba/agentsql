# AgentSQL v4.17.0 acceptance evidence

**Languages** [Chinese](../v4.17.0-acceptance.md) · [English](v4.17.0-acceptance.md)

Signed commit `ce00261d2835591b2c751f4c51dea673c2e4ae45` passed **18 of 25 cases (72%)** in the fixed SQLBot Community v1.10.3 Q&A matrix. Verified scenarios were Q1, Q2, Q3, Q4, Q5, Q6, H1, H2, H3, H4, V1, V2, S1, S2, S3, D1, D3, I1. Tests used local Qwen3-4B, the signed AgentSQL Q&A service and security gateway, the fixed community client, and synthetic data on isolated PostgreSQL.

| Scenario | Observed result |
| --- | --- |
| D1 governed PostgreSQL onboarding | An administrator created and checked the connection. Success and failure were audited. A regular member could only use their personal binding. The query returned two rows totaling 55.00, gateway audit 24. |
| D1 credential rotation and revocation | The old credential failed. Saving the replacement and restarting the gateway to clear existing pools restored access. History reopened after ChatBI restarted under current permissions, audit 96. Retiring the binding hid SQL and data from prior history. |
| D3 managed files in the original client | CSV and XLSX each returned three authorized rows totaling 15.35 after filtering, with a blank amount preserved. The two-sheet workbook granted access to the selected sheet. Gateway audits 56 and 72. |
| D3 interruption and cleanup | Regular members and unsupported file types were refused. A publish failure created no queryable source or physical table. A database dependency blocked deletion and the old result was withheld. After removing the dependency, a gateway restart removed both workbook tables during startup recovery. The original client's deletion retry succeeded. |
| Regression and offline install | Table selection across 128 authorized tables took 123.3s in the successful cold sample and 50.6s after prewarming. 2 cold attempts failed. The retry used a 6 vCPU test-container limit for prewarming. A four-request sample completed 4/4 in 97.803 seconds. Network-disconnected systemd install, upgrade from v4.16.0, and startup-failure rollback passed on Linux amd64 and QEMU ARM64. |

The public Demo clearly labels its simulated model and synthetic data. The user's production business system has yet to be validated. ARM64 tests ran under QEMU.
