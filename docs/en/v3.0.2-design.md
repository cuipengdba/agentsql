# v3.0.2 revised and SQLBot adaptation design

**Language:** [English](v3.0.2-design.md) | [Simplified Chinese](../v3.0.2-design.md)

Users requested to fix the light navigation, provide English content that fully corresponds to the original Chinese text, update the current document entrance, adapt to SQLBot, and remove the WeChat group QR code.

1. Console Sider/Menu shares state and color variables with the global theme, preserving independent scrolling of short viewports.
2. Chinese and English README, official website and Markdown documents correspond section by section, record source file hashes and check titles, tables, code blocks and links. The current operation guide uses v3.0.1 as the published baseline and is updated with the release of v3.0.2; historical reports retain the actual version and evidence.
3. Create a current document index and version-independent operation and maintenance manual, and correct the v0.7 title and expired build command in the default entry.
4. SQLBot official v1.10.2 (commit `aa41fc1033bb974a703df9200a98ec8b9eec5f25`) provides MCP services, but the database execution layer still connects directly to the database. Provides an auditable, fixed source hash installation patch and standalone Python adapter to feed metadata discovery and SQL execution of configured SQLBot data sources into AgentSQL `/mcp`. Failure to close when mapping, key, authorization, audit or gateway connection is missing will not return to direct database connection. SQLBot internal metadata storage and business data sources are handled separately. Other SQLBot versions must re-validate source file hashes and interfaces.
5. The README and Chinese and English official website only display public accounts and personal WeChat QR codes, and delete group QR code files and references in the current source code. Historical Git commits and signed releases are retained.

SQLBot Secure Link: SQLBot Generate SQL → Fixed Data Source Mapping → Agent Bearer → AgentSQL MCP Session → Identity/Tenant/Permissions/Rules → Controlled Execution → Result masking → Persistent Auditing → SQLBot Result Model. The adapter only delivers results that allow decisions and contain a persistent audit ID; unknown or deny decisions throw an error; SQL is not automatically retried.

Acceptance covers light/dark and Chinese/English combinations, folding menus and short viewports, full-text structure alignment, QR code cleaning, current document links, as well as SQLBot allow, deny, masking, audit, invalid Key, disconnection, missing mapping and direct connection blocking. The official signature package of v3.0.1 will not be replaced in place; after passing, v3.0.2 will be used to deliver new code and updated documents, official website and demo.

Additional requirement: a shared vector AgentSQL logo, horizontal wordmarks for light/dark backgrounds, website sharing cards and browser icons. The website, GitHub README, Web login and sidebar use this identity, with CI checking synchronized copies. English website navigation wraps longer labels, and versioned resource URLs prevent old caches from hiding the new logo and styles.
