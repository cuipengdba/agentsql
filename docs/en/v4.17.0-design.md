# AgentSQL v4.17.0 · PostgreSQL and managed file onboarding

**Languages** [Chinese](../v4.17.0-design.md) · [English](v4.17.0-design.md)

v4.17.0 verifies end-to-end Q&A after trusted administrators register PostgreSQL or import managed CSV and XLSX files. The release targets D1 and D3 in the fixed SQLBot Community v1.10.3 matrix, for 18 of 25 cases (72%) once both cases and prior regressions pass. [Scoring contract](sqlbot-community-chatbi-score-v1103.md)

## PostgreSQL administration

The gateway administration interface registers and verifies database connections. An administrator creates personal bindings and selects authorized objects for regular members. The Q&A service fetches metadata and executes only under the current user and binding. Connection checks, credential rotation, binding changes, and queries each produce audit evidence.

The tests compare SQL, results, and audit records using a stock SQLBot client, a real local model, and isolated synthetic PostgreSQL data. Cases cover invalid credentials, a successful question after rotation, revocation of an old binding, and denied member administration. Database credentials enter through the trusted gateway administration channel. [SQLBot setup](SQLBOT.md)

## Managed CSV and XLSX

Upload a file, preview it, select worksheets, then confirm to create a governed datasource. Q&A runs through the gateway and preserves Chinese fields, decimal values, and nulls. Opening prior conversations and downloads checks resources against current permissions.

A two-sheet workbook and a Chinese CSV fixture cover datasource scoping, invalid inputs, cleanup after failure, and reopening a saved query. Deletion, revocation, and restart are checked against actual object access and gateway audit records. [Native Q&A and the standalone gateway](PRODUCT_MODES.md)

Acceptance evidence is tied to one exact signed release. Public documentation lists the deployments, clients, databases, and import flows that were tested. The public Demo identifies its simulated model and synthetic data.
