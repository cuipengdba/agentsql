## border

- Only SQL Server 2025 Developer x86_64 Docker single instance, synthetic data, strict TLS and narrow SELECT MCP secure paths are demonstrated here. `SHOWPLAN` is a database-level permission; R010 of the unauthorized table is terminated in the gateway static rule stage, and a management account is not required to run the execution plan instead of a read-only account.
- Not proven for other SQL Server versions, Windows, Always On, production certificate rotation, long-term loads, customer topologies, complex SQL, B2 column-level authorization, B5 sessions, or write paths. May not claim manufacturer certification or full production support.
- The official website Live Demo maintains synthetic PostgreSQL data and does not display the real SQL Server database.
