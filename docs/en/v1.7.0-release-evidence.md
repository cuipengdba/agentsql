## Support ranges and unverified items

- HighGo is limited to HighGo 9.0.10 Enterprise Edition PG mode, single instance, clearly bounded read-only SELECT subset, see [HighGo acceptance ](v1.7.0-acceptance.md).
- KingbaseES is limited to KingbaseES V9R1C10 PG mode, `verify-full` on single instance synthetic data, certificate/credential rotation and existing controlled read-only links, see [Dameng and KingbaseES acceptance ](v1.7.0-dm-kingbase-depth-acceptance.md).
- Dameng DM8 TLS to verify server identity, KingbaseES/Dameng official active/standby failover, production capacity, vendor certification and untested protocol modes are still not verified. Registered or PG protocol compliant does not equal full production support.
