# AgentSQL v3.4.1 candidate acceptance

**Language:** [English](v3.4.1-acceptance.md) | [Chinese](../v3.4.1-acceptance.md)

v3.4.1 only fixes tenant isolation in management audit SSE. It adds no database engine, permission or schema. The pinned-build Kingbase and Vastbase checks and fail-closed boundaries from v3.4.0 remain governed by the [original acceptance record](v3.4.0-acceptance.md).

| Check | Expected result |
| --- | --- |
| History | An authenticated tenant A audit viewer receives only cached tenant A events. |
| Live delivery | Tenant B events do not reach tenant A's SSE; tenant A events arrive normally. |
| Missing ownership | Missing authenticated tenant or event tenant identity fails closed. |
| Regression | Admin API permissions, SSE connection limits, error cleanup and audit query remain healthy. |
| Upgrade | No database schema change; recheck health, allowed/denied, masking and durable audit against a copy of old synthetic data. |

Actual CI, distribution and public results are in the [release evidence](v3.4.1-release-evidence.md).
