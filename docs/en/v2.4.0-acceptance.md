Image ID: `sha256:d504c5d14049f225069c87a287931fe543122963d016a30023ee09653a9b5517`.
- Running `pg_catalog.version()` returns `(openGauss 7.0.0 build 2397a86f) compiled at 2026-09-23 00:09:53 ...`. The connection pool verifies this build and read-only status each time a new physical connection is created. Docker Hub's `7.0.0-RC3` has no replacement for LTS testing.
- The isolation container only loops back the mapping port to the host; the synthetic table and the read-only account `agentsql_v240_ro` can only obtain the SELECT of the target ordinary table. This account also gets a test view SELECT to prove that the adapter rejects view bypass. Private keys, passwords, database backups and synthetic records do not enter the repository or public network demo.
- The test CA issued `og-lts.agentsql.test` server certificate, server `ssl=on`; certificate file permissions 0400. Non-TLS network connection for read-only account rejected by HBA. Correct CA and hostname pass; incorrect CA, incorrect hostname and plaintext connection fail. Certificate rotation and production CAs are outside the scope of this article.

## Release threshold for candidate phase to be closed (now closed)

- The first round of the Linux Go all-in short test encounters two new registry count assertions (fixed), as well as old concurrency and parsing P99 threshold timeouts when multitasking on the same machine competes. Affected use cases passed independent rechecking after resources were idle; Go, Web, and govulncheck CI for merge commits all passed. `go vet` passed.
- From v2.3.0 official installation package and data backup to v2.4.0 **official package**, the complete set of SQLite and PostgreSQL metadata/audit recovery re-examination passed; the candidate package drill has also been completed.
- The functional PR's sealed CI, signature dual-architecture assets, GHCR, official website and public website Live Demo have all completed independent release acceptance. The specific SHA, summary, path and log can be found in the official release evidence.

## Support boundaries

This time only restricted read-only paths are demonstrated on openGauss Community Edition 7.0.0 build 2397a86f, official x86_64 single instance container, test CA and synthetic data. Other openGauss versions, GaussDB Business Edition, active/standby, production certificate rotation, long term load, customer topology, B2, B5, write, arbitrary SQL and full production support are not verified. The public Live Demo maintains synthetic PostgreSQL data and does not connect to this openGauss test library.
