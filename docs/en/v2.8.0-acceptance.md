# AgentSQL v2.8.0 Candidate Acceptance

**Language:** [English](v2.8.0-acceptance.md) | [Simplified Chinese](../v2.8.0-acceptance.md)

Status: Completed; see [ for official SHA, CI, signature assets, upgrades and public network results. Release evidence ](v2.8.0-release-evidence.md). The test environment is a collection of `milvusdb/milvus:v2.6.25`, TLS/authentication, synthetic `events` and `private_notes` in an isolated Docker network. The `agent_reader` role only has the Search permission of `default.events`.
