# AgentSQL v4.17.0 data onboarding and governed Q&A

**Languages** [Chinese](../v4.17.0-query-guide.md) · [English](v4.17.0-query-guide.md)

## Use native AgentSQL Q&A

1. Install the signed Q&A service and gateway, then configure a local text model in the Q&A service. In gateway administration, register PostgreSQL with a dedicated read-only account and test the connection.
2. Configure personal bindings and table and column permissions for each member. After configuring the binding in Q&A, sign in as a member, choose an authorized source, and ask a business question.
3. Check the result, generated SQL, and gateway audit ID. Opening history or downloading results retrieves data under current permissions.

For managed CSV/XLSX, enable managed-file import on the gateway with separate publisher and read-only accounts. An administrator uploads the file, previews its fields, selects worksheets, and saves the datasource. Members query the sheets they can access. Acceptance used the SQLBot Community v1.10.3 file workflow with a two-sheet workbook and a CSV with Chinese columns. [Deployment and usage modes](PRODUCT_MODES.md) · [SQLBot client setup](SQLBOT.md)

## Use the standalone MCP Server gateway

Create a dedicated read-only Agent in the gateway and specify its datasources and authorized objects. Configure its credential and the gateway MCP endpoint in the MCP client. Call `list_datasources` and `list_schema`, then use `query` for a controlled read. Review the execution by caller, datasource, and audit ID. [MCP Server setup](PRODUCT_MODES.md)

## Use Q&A and MCP together

Register and manage the database connection in one gateway. Employee Q&A uses each person's current binding. External MCP clients use a separate Agent. In a maintenance window, save the replacement credential and restart the gateway to clear old connection pools. Check the connection and run both workflows again. After revoking a binding or Agent access, verify the rejection of old history and tool calls. [Authorization and acceptance evidence](v4.17.0-acceptance.md)
