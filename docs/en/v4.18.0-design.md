# AgentSQL v4.18.0 · Standalone MCP Server and embedded Q&A

**Languages** [Chinese](../v4.18.0-design.md) · [English](v4.18.0-design.md)

AgentSQL v4.18.0 verifies the standalone MCP Server, basic assistant, and Type 4 page embed. These are I2 and I3 in the fixed SQLBot Community v1.10.3 Q&A matrix. The target is 20 of 25 cases (80%) after testing both additions and rerunning the prior cases on the exact release commit. [Scoring contract](sqlbot-community-chatbi-score-v1103.md)

## Standalone MCP Server

Register PostgreSQL, a dedicated read-only database account, and an Agent for the caller. For deployments with PostgreSQL authorization enabled, restart the gateway according to the deployment procedure after registering a new datasource and confirm catalog authorization is active. Grant table access in the console and bind the required columns. An MCP client uses the dedicated Agent credential on Streamable HTTP `/mcp` to call `list_datasources`, `list_schema`, and `query`. Verify the visible structure, controlled execution, result, and audit.

Acceptance uses the Python MCP SDK from the fixed community image and two synthetic tables in isolated PostgreSQL. Check an authorized query, a table the database account can read without a gateway grant, rejection of the old credential after rotation, and database interruption and recovery. Record the observed rows and gateway audit. [Three usage modes](PRODUCT_MODES.md)

## Basic assistant and Type 4 page embed

Use the dedicated embed listener for approved host origins and datasources. The basic assistant executes as the designated guest. The Type 4 page host issues a short-lived identity assertion, and queries use the current member's personal binding. Both paths check current permissions when viewing history and exporting data. The administration listener keeps its own access and frame policies.

Verify Chinese Q&A and history with the unmodified fixed SDK, a local model, the real gateway, and synthetic PostgreSQL data. After disabling the assistant or revoking access, check prior history, client state, and gateway query audits. Label screenshots by native AgentSQL or original client. The public Demo clearly labels its simulated model and synthetic data. [SQLBot client setup](SQLBOT.md)
