# AgentSQL v4.0.0 发布说明

**语言 / Language:** [简体中文](release-notes-v4.0.0.md) | [English](en/release-notes-v4.0.0.md)

本版完善隔离网络交付、跨版本升级与维护诊断，完成已授权的 v3.1.0 至 v4.0.0 十版计划。已正式发布，完整交付结果见[发布证据](v4.0.0-release-evidence.md)。

| 内容 | 用户可见结果 |
| --- | --- |
| 本地发行验签 | 指定版本、独立可信公钥与完整资产目录，一次验证 15 项资产、三份 Ed25519 签名、SBOM、来源证明与哈希。 |
| 离线运输包 | 私有暂存后验签并打包；目标环境重新验证，复用已有 `install.sh --from`。 |
| 最小诊断导出 | 固定字段 JSON、新文件输出、只读存储检查，不导出 SQL、数据、日志、连接信息或凭据。 |
| 升级维护 | 三个正式基线的双存储布局升级/回退演练；控制台与双语手册给出操作入口。 |

## 兼容和范围

本版不增加业务数据库或放宽权限、执行、脱敏、审计合同。Oracle、SQL Server、关系型与原生读取能力沿用各自版本证据；官网 Demo 继续使用 PostgreSQL/MySQL 合成数据。没有客户生产认证、厂商认证、任意数据库完整生产支持或固定 LTS 期限声明。
