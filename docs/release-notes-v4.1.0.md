# v4.1.0 发布说明：Go 原生问数基础

**语言 / Language:** [简体中文](release-notes-v4.1.0.md) | [English](en/release-notes-v4.1.0.md)

已于 2026-10-26 [正式发布](https://github.com/cuipengdba/agentsql/releases/tag/v4.1.0)。发布范围和验证边界见[验收记录](v4.1.0-acceptance.md)。

## 新增能力

| 功能 | 当前实现 |
| --- | --- |
| Go 问数服务 | 独立监听与加密 SQLite 存储；模型编排、用户、会话和查询不依赖 Python/SQLBot 运行时 |
| SQLBot 身份兼容基础 | 固定社区版 v1.10.2 的普通账号、加密表单登录、HS256 令牌与十进制大整数 ID；显式导入旧身份 |
| 真实问数 | OpenAI 兼容模型接口；PostgreSQL/MySQL 单轮自然语言到 SQL、表格与审计编号 |
| 受控查询 | 使用已有个人绑定和双凭据 MCP；每次重新解析身份与授权；拒绝、审计失败及本地持久化失败不释放结果 |
| 问数界面 | 中英文切换、浅色/深色主题、会话历史、SQL 展示、移动端菜单与可滚动侧栏 |
| 运维与离线基础 | `chatbi init/configure/preflight/import/serve`；已校验 Linux 发行包可一条命令安装网关与问数服务；systemd 升级失败回滚 |
| 兼容清单 | 固定 Git blob 哈希的 144 条静态公开 API 基线，动态依赖、SDK、MCP 和完整迁移单独列为待验证 |

操作步骤见[原生问数指南](CHATBI.md)。现有网关、MCP、治理控制台和数据库支持边界继续保留。

## 兼容范围

本版是 v4.1.0–v4.5.0 替换计划的第一个里程碑，未宣称 SQLBot 全部功能或现有业务零改动替换已完成。图表、预测、推荐、多轮语义、文件数据、助手/嵌入 SDK、SQLBot MCP、完整管理及迁移按后续版本推进。

当前历史读取会重新验证并执行 SQL，避免权限撤销后回放旧数据，因此结果可能随数据库变化；尚不等同于 SQLBot 历史缓存语义。新问数与历史数据请求共享有限并发和超时；弱服务器可把 `max_concurrent_data_requests` 配为 1。

离线原生服务安装不需要 Docker、Go 或 Python，但操作系统须具备支持的 Linux/glibc/systemd 基础环境。本版标准包不内置模型权重或模型运行时，不能把安装成功表述为完整断网问数已开箱即用。

## 迁移与安全

身份导出包含密码摘要和认证密钥，仅能在私有运维环境处理。导出器校验原身份源码和依赖版本，预检不修改源库，导入只创建新目标；迁移报告明确 `complete_migration=false`。原实例、凭据与成套备份应保留到最终切换验收。

新 Go 实现依据协议与行为独立开发；没有把 SQLBot 上游实现复制进本项目 Apache 许可文件。官方社区运行路径包含动态 `sqlbot_xpack` 依赖；清单数量不等于全部社区功能已经验证。

## 验证与发布

候选验证使用合成 PostgreSQL/MySQL 数据、真实本地模型、原 SQLBot 登录身份、Edge 浏览器和隔离 Linux 安装环境。正式提交的 CI、双架构签名产物、公开镜像、官网和 Demo 均已复验；正式包完成 amd64 的 SQLite 与 PostgreSQL 升级回退，尚未在实体 arm64 主机安装或从正式包重跑真实模型问数。详见[验收记录](v4.1.0-acceptance.md)。

公网问数页面仅提供明确标注的浏览器内模拟演示，未接入模型或数据库；真实模型问数功能在本地安装环境验证。
