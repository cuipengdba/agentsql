# AgentSQL v4.18.0 · 独立问数、MCP 与嵌入指南

**语言** [简体中文](v4.18.0-query-guide.md) · [English](en/v4.18.0-query-guide.md)

## 独立问数 Agent

1. 管理员在安全网关登记 PostgreSQL，配置受控目录、表列和查询权限，再将数据源绑定到指定成员。
2. 在 AgentSQL 问数工作空间配置本地模型。成员登录，选择自己可见的数据源，使用自然语言提问。例如在授权的合成订单表上问「按区域汇总订单金额」。
3. 在结果中核对图表、数据和查询记录。刷新或重新打开历史时，服务按当前授权重新检查。管理员可在网关审计中定位查询。

## 独立 MCP Server 安全网关

1. 依据 [产品使用方式](PRODUCT_MODES.md) 部署网关。PostgreSQL 目录授权部署在新增数据源后按部署流程重启，确认授权的目录和连接生效。
2. 为外部应用创建专用 Agent，并绑定所需数据源、表列和只读查询能力。
3. 在 MCP 客户端配置 Streamable HTTP 网关地址 `https://<网关主机>/mcp`，通过客户端的安全凭据配置传入该 Agent 的 Bearer 凭据。依次调用 `list_datasources`、`list_schema` 和 `query`。
4. 在网关管理界面核对调用身份、数据对象和审计结果。轮换凭据后，更新客户端凭据再发起新会话。

## 组合使用与网页嵌入

独立问数和外部 MCP 客户端可以共用网关。分别配置成员数据绑定和外部应用的 Agent 身份，按实际调用方核对查询结果与审计。

基本助手使用 `chatbi serve --assistant-only` 专用监听器，按批准的游客身份查询。为它配置允许的宿主来源和数据源，并在独立来源加载原版 `assistant.js`。

Type 4 页面使用独立的浏览器来源。通过受限反向代理提供原版页面资源，并仅转发嵌入握手和受控查询、数据源及历史 API。管理登录和管理 API 留在私有地址。宿主应用签发短期身份声明，查询使用当前成员绑定。按 [SQLBot 客户端接入](SQLBOT.md) 配置网关，再核对问数、历史和撤权。
