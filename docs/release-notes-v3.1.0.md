# AgentSQL v3.1.0 发布说明

**语言 / Language:** [简体中文](release-notes-v3.1.0.md) | [English](en/release-notes-v3.1.0.md)

当前为发布候选；正式发布状态及已通过项目以[发布记录](v3.1.0-release-evidence.md)为准。

## SQLBot 用户级接入

- 增加 SQLBot 工作空间、数据源与用户映射管理，关联已有 AgentSQL 人员及只读 Agent。工作空间和用户 ID 使用字符串保留完整精度。
- 每次操作以独立连接凭据解析当前映射，获取两分钟专用人员令牌。MCP 每请求重新检查用户权限、Agent、映射版本和数据源范围。
- 映射禁用、修改、删除和凭据轮换使旧令牌失效；创建、修改及轮换要求策略、人员和数据源管理权限。凭据只展示一次，配置导出不含秘密。
- SQLBot 普通登录身份显式传递到模型线程，表与字段信息按当前用户的网关权限过滤后进入模型。
- 增加只读审批操作页：用户主动申请、查看状态及执行已批准的封存请求；拒绝不触发模型自动改写或重试 SQL。
- 审批一次执行链路在显式关闭 B2 的隔离环境通过；启用 PostgreSQL B2 列级授权时审批申请由网关拒绝，不自动降级授权。B2 开启环境的只读审批仍待后续版本支持。
- 增加接入诊断和安装清单检查；固定 SQLBot v1.10.2 的上游文件哈希，不匹配即拒绝安装。

## 升级

新增 SQLBot 映射表，组合 schema 24、分库 metadata 23、audit 6。须先备份，再显式迁移；回退通过恢复配套的 v3.0.2 备份完成。见[升级指南](v3.1.0-upgrade.md)。

## 支持范围

本版针对 SQLBot v1.10.2 普通登录、PostgreSQL 和已验收的表格/图表场景。模型、部署和结果以[验收记录](v3.1.0-acceptance.md)为准。嵌入式 assistant/ask-token、其他 SQLBot 版本、MySQL 接入和写操作不在本版范围。旧 v1 配置保留原工作空间级能力；用户级能力须使用 managed v2。

绑定 schema 过滤结构发现，实际 SQL 对象权限仍由原策略判定。SQLBot 服务端是可信身份提供方，独立 Agent Key 仍按原凭据生命周期管理。现有数据库版本、模式和生产支持声明不因本版自动扩大。
