## 关联订单与地区字典

1. 在同一个只读数据源中授权订单表、地区字典及所需字段。用地区编码连接两张表，地区字典的连接字段应唯一。
2. 确认两端都可见，再保存关系配置。给同名表和含义相近的字段写出可以区分的业务备注。
3. 在 AgentSQL 问数中新建对话。例如「把销售订单与地区字典按地区编码关联，按地区展示名汇总一月已完成订单金额，取前三名」。
4. 核对结果、生成的 SQL 和查询审计。审计里的实际查询对象应与本题使用的表一致。

## 管理业务术语和 SQL 示例

| 配置 | 适用场景 | 操作 |
| --- | --- | --- |
| 业务术语 | 团队用简称指代某类业务记录 | 写清含义和数据库中的原始取值，选择适用的数据源，启用后用同一问题核对结果。 |
| SQL 示例 | 同一业务指标有固定的计算方式和过滤条件 | 在目标数据源下保存典型问题及匹配的只读单表 `SELECT`。启用后复测该问题，再用禁用状态做对照。 |
| 表列备注 | 字典或多个业务表的名称相近 | 在当前受权的表和字段上写清各自含义，修改后用同一问题核对选表和查询审计。 |

示例给模型提供业务上下文。模型按当前授权结构重新生成 SQL，网关验证身份、表列和执行权限。更新权限后，可用新会话核对选表和查询结果，同时检查旧会话及导出是否仍符合当前权限。

这套流程用于 AgentSQL 自有问数。独立 MCP Server 安全网关和组合部署见 [三种使用方式](PRODUCT_MODES.md)。固定版本的 SQLBot 接入见 [SQLBot 接入指南](SQLBOT.md)。
