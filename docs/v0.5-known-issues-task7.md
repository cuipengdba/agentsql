## 环境与口径

- 宿主机为 Windows，验证使用 `golang:1.25-bookworm` Linux 容器和 Go 1.25。
- 宿主机 Go 的 `CGO_ENABLED=0` 且没有 C 编译器，不能构建依赖 `pg_query_go` 的完整仓库；构建和测试因此在容器中执行。
- SQLite 并发测试分为两种口径：Docker Desktop 持久化文件系统用于复现 Windows fsync 问题，`--tmpfs /tmp:rw,exec` 用于排除该平台 I/O 后验证业务并发逻辑。
- 本任务没有执行任何 Git 命令。
