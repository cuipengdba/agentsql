# AgentSQL v2.5.0 MongoDB 指定实例候选验收

状态：本文件记录发布前的候选验收；正式 CI、签名资产、GHCR、官网和公网 Live Demo 的最终结果见[正式发布证据](v2.5.0-release-evidence.md)。所有业务数据均为隔离容器中的合成数据。

## 实例与权限边界

- MongoDB `7.0.43`，Linux x86_64 Docker 单实例；本地镜像 `mongo:7` / `mongo@sha256:1f995ad6fdb93244a1addab1b58f934a0bc2f5643c38e02f5e9d7f0c7d227a7b`。
- 测试 CA 为 `mongo-v250.agentsql.test` 签发证书，服务端 `requireTLS`；AgentSQL 数据源使用严格 TLS、显式 CA 和服务器名。CA 私钥与账号密码仅保存在本机 `D:\CodexLS\tmp\agentsql-v250`，不入库。
- `agent_reader` 只获 `app.customers` 的 MongoDB `find` 权限；实测它能读取合成记录 `alice`，读取 `app.private_collection` 返回 `Unauthorized`。合成手机号 `13812345678` 经 MCP 返回 `138****5678`，未返回 `synthetic-secret-canary`。
- MCP `find_documents` 限定当前数据源数据库、简单集合名、1–32 个显式顶层标量字段、1–8 个字符串等值条件与 1–100 行。禁止任意 MongoDB 命令、操作符、嵌套字段、聚合、写入、跨集合读取及未验证的服务器版本。

## 候选阶段的待完成发布门槛

首次 Go 全包短测中存储包在默认 10 分钟上限超时；堆栈停在 SQLite WAL 提交的 `fsync`，未出现断言失败。改用容器可执行 tmpfs 后，存储包单独 22.6 秒通过，全包重跑通过；PR #42 初始提交 `a96fc3b` 的 Go、Web、govulncheck CI 均通过。本机此前 50 并发 HTTP 测试出现过 `audit unavailable`，v2.4.0 基线重复运行也能复现；本次降低包并行度后 MCP 包通过。候选阶段尚未完成的合并提交 CI、正式包升级复验、双架构签名资产、GHCR、官网与公网 Demo，均已在[正式发布证据](v2.5.0-release-evidence.md)中单独记录；不得把未验证的 MongoDB 拓扑或能力描述为已支持。

本次结论只覆盖上述 MongoDB 7.0.43 单实例、测试 CA、最小权限账号及合成数据的受控读取。副本集、分片、生产证书轮换、大数据量、长期负载、任务临时授权、审批、写入和完整生产支持未验证。公开 Live Demo 仍使用合成 PostgreSQL 数据。
