# AgentSQL v2.5.0 设计：MongoDB 受控只读

**语言 / Language:** [简体中文](v2.5.0-design.md) | [English](en/v2.5.0-design.md)

状态：实施中。本版只针对指定 MongoDB 7.0 单实例建立 Agent 级的有界读取路径；支持范围以真库验收记录为准。

## 用户任务与当前缺口

企业 AI 助手需要从指定集合读取少量业务字段，同时让数据管理员限制集合、隐藏敏感值，并追溯每一次允许、拒绝和失败。现有 MongoDB 适配器只提供管理端原生命令预览；该路径的本机日志不含 Agent 级持久审计，也不适合作为 MCP 的授权依据。

## 交付范围

| 路径 | 约束 |
| --- | --- |
| MCP `find_documents` | 绑定当前 Agent；只接受已授权数据源的指定数据库与集合、显式字段、至少一个字符串等值过滤条件和 1–100 行限制。查询结果按字段返回，不返回完整文档。 |
| 数据库访问 | 必须使用严格 TLS、已认证的最小权限账号和只读 `find`；拒绝未知 MongoDB 主版本、集合名/字段名中的操作符、嵌套路径、任意管道、脚本、写命令和未授权字段。 |
| 配置变更 | 每次受控读取使用当前数据源配置建立只读连接，不复用按数据源 ID 缓存的原生预览连接；账号、数据库、证书或主机变更不能继续沿用旧连接。 |
| 授权 | 每次调用重新验证 Agent、数据源和当前策略。集合须有精确授权，显式列策略进一步限制结果字段及过滤字段；撤销后下一次调用拒绝。 |
| 脱敏与审计 | 对确定来源的投影字段应用现有数据源脱敏规则。数据库访问前写入持久预检审计，完成后写入允许/拒绝/错误审计；最终审计失败时不返回数据。审计不记录查询值或连接凭据。 |
| 客户端 | 在 MCP Inspector 与 Dify MCPClient 上各做允许和拒绝的真实 HTTP MCP 调用。 |

暂不支持聚合、`distinct`、`count`、排序、翻页、嵌套字段、数组字段、写入、跨集合查询、任务临时授权和审批执行。管理端原生预览维持现有连接级能力，不计入本版 MCP 安全链路。公网 Demo 保持合成 PostgreSQL 数据。

## 调用与故障边界

`MCP 身份 → 当前 Agent 与租户 → 数据源归属 → 精确集合/字段策略 → 输入封闭验证 → 持久预检审计 → 严格 TLS/最小权限 MongoDB find → 投影字段结构校验 → 脱敏 → 持久终态审计 → MCP 响应`。

负向验收覆盖跨 Agent/租户、策略撤销、无过滤条件、操作符注入、额外字段、隐式 `_id`、数据库账号撤权、证书不可信、连接断开、审计库故障与超时。预检审计不可用时不得访问业务库；终态审计不可用时不得向客户端返回结果。真库测试需记录精确服务端版本、镜像摘要、TLS、账号权限与合成数据范围。

## 发布标准

本版依照 `docs/RELEASE_ROUTINE.md` 完成源码 CI、前后端回归、真实客户端与数据库、从 v2.4.0 正式包升级及恢复、双架构签名资产、GHCR、官网和 Live Demo 公网复验。未通过的环节不得宣称正式发布或完整生产支持。
