## 未验证的能力

1. 达梦 DM8 现用 Go 驱动 `github.com/godoes/gorm-dameng` v0.7.2 的 `security.NewTLSFromTCP` 写死 `InsecureSkipVerify: true`。AgentSQL 继续拒绝达梦显式 TLS 选项；正确 CA/错误 CA/主机名及轮换的真库验收均未完成，不能宣称可验证服务端身份。[上游实现](https://github.com/godoes/gorm-dameng/blob/main/dm8/security/zzi.go)、[达梦通信加密说明](https://eco.dameng.com/document/dm/zh-cn/pm/communication-encryption.html)。
2. 金仓和达梦的正式主备拓扑、故障切换终态与多 Agent 容量结论尚未完成。单实例断线恢复不能替代主备切换。

上述两项不纳入本版支持声明，后续取得驱动与主备拓扑条件后再分别验收；它们不作为已验证金仓单实例 TLS 能力的发布替代证据。
