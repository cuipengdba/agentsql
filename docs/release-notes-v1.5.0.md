# AgentSQL v1.5.0 发布说明（候选）

本版计划深化达梦 DM8 Pack3、金仓 KingbaseES V9R1C10 PG 模式和 Vastbase G100 Build 9 PG 模式的指定实例验收。以隔离合成数据验证最小权限、受控查询、脱敏、拒绝、持久审计、故障关闭与恢复，并分别经 Dify 和 MCP Inspector 实际调用。数据库的支持边界仍以[验收记录](v1.5.0-acceptance.md)所列版本和模式为准。

本版将从 v1.4.0 正式包执行升级和备份恢复，完成 Go/Web/安全 CI、签名双架构发行物、精确版本镜像和独立 GitHub Release。全部发布门槛通过后，官网、下载资料、GHCR `latest` 与公网 Demo 将从 v1.0.0 直接更新至 v1.5.0，并保留切换前快照做公网复验。

暂不声明厂商认证、正式生产许可、TLS/HA/长时负载或所有方言的完整生产支持。未通过的检查项不会写作已发布能力。
