# v2.3.0 SQL Server 指定实例深化设计

状态：v2.3.0 已正式发布；本文件记录设计范围，最终结果见[正式发布证据](v2.3.0-release-evidence.md)。

## 用户问题与目标

让使用 SQL Server 2025 的企业试点能以校验证书的 TDS 连接和最小权限账号完成 Agent 查询，同时在规则拒绝、数据库撤权、断线和审计库故障时保证不交付原始结果。保持注册数据库、窄只读验证与完整生产支持三个层级区分。

## 指定环境

- 官方镜像 `mcr.microsoft.com/mssql/server@sha256:742481d1b1186cccc81220a1eaacef244ca8d0f7d19c8e5c70df8ae541ffbab2`，SQL Server 2025 Developer、17.00.5015 日志 build，隔离 x86_64 测试实例。
- 服务端证书为本地测试 CA 签署、含 DNS/IP SAN 与 serverAuth EKU，镜像以非 root 用户读取专用卷内的私钥。正确 CA 严格 TLS 查询已通过；错误 CA 拒绝、正确 CA 再次通过的差分预检见 `D:\CodexLS\outputs\agentsql-v230\preflight.md`。
- 预检使用 SA 管理账号，仅证明底层驱动和证书路径；正式验收必须创建随机合成表与只获目标表 SELECT 和必要 SHOWPLAN 权限的读账号。Microsoft 文档要求 SHOWPLAN_XML 对所引用数据库授予 SHOWPLAN；无此权限应失败关闭，不改用管理账号。

## 必须交付的验收

1. 建立随机合成库/表、只读 login 与 user；检查 SQL Server 服务端拒绝 INSERT，读账号无 db_owner/db_datareader；清理测试对象和账号。
2. 正确 CA 与错误 CA、证书主机名不符的连接差分；保持默认严格证书校验，不把 TrustServerCertificate 设为生产默认。
3. 经真实 HTTP MCP 完成 Agent 身份、表级 allow、无权表 R010、窄 SELECT、手机号脱敏和持久审计；写入、多语句、动态来源和存储过程拒绝。
4. 撤销 SELECT、SHOWPLAN 和 Agent 策略分别验证无原始行交付；恢复权限后复测，确认 SHOWPLAN_XML 会话状态清理。
5. SQL Server 停机、独立审计库停机及恢复；验证失败时不交付原始行，恢复后返回脱敏结果并留下可复核审计。
6. MCP Inspector 与 Dify 各完成允许与拒绝调用；用上一正式版 v2.2.0 的发布包演练 SQLite、PostgreSQL metadata/audit 升级与成套备份恢复。
7. 独立 CI、双架构签名资产、GHCR 精确标签、官网和 Live Demo 按 `docs/RELEASE_ROUTINE.md` 交付。

## 不扩大声明

x86_64 Docker Developer 单实例测试不构成 SQL Server 各版本、Windows/Always On、生产证书生命周期或厂商认证；复杂 SQL、B2/B5、写入与完整生产支持另行验收。Live Demo 继续使用合成 PostgreSQL 数据，不宣称展示 SQL Server 真库。
