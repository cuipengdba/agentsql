# AgentSQL v2.7.0 候选验收：ClickHouse 查询治理

状态：候选验收。正式升级、封版 CI、签名资产、GHCR、官网与 Live Demo 另见发布后的独立证据；未完成前不视为正式发布。

## 指定真库范围

隔离环境使用 `clickhouse/clickhouse-server:26.8`，镜像摘要 `sha256:05d2e46507afdcf08da46e5528b68847104dbbed691c327e505414b4b7f4e4c8`，服务端 `26.8.31.2`，Linux x86_64 单节点、原生 TLS 9440、测试 CA、合成 `analytics.events` MergeTree 表。账号 `agent_reader` 仅经 `agent_read` 角色获得 `SELECT(id,name,phone,region) ON analytics.events`；`readonly=1`、`max_execution_time=2` 秒、`max_rows_to_read=10000`、`max_bytes_to_read=1048576`、`max_memory_usage=134217728`、`max_result_rows=100`、`max_threads=2`。私有表读取与写入在数据库端均拒绝。证据：`D:\CodexLS\outputs\agentsql-v270\clickhouse-instance-evidence.log`。

| 门槛 | 实际结果 |
| --- | --- |
| 受控查询和权限 | 真 HTTP MCP 对 `query_analytics` 的显式列、String 等值过滤、限制行数及参数绑定通过。精确表加显式列授权才可访问；宽泛表授权、私有表、非法字段、未授权过滤列和撤权均在业务库前拒绝。恶意过滤值作为参数绑定，仅返回空结果。 |
| TLS、脱敏和审计 | 错误 CA 被拒绝；当前数据源证书和凭据每次重读。允许结果中手机号脱敏，持久预检与终态审计记录对象、决策和审计 ID，不记录过滤值或原始 SQL；终态审计失败时不交付数据。 |
| 双客户端 | MCP Inspector 0.16.8 与 Dify MCPClient 1.17.1 分别完成真实 HTTP MCP 允许和拒绝调用，返回可定位的持久审计 ID；允许结果只含掩码值。证据：`clickhouse-client-orchestration-retry1.log`、`clickhouse-clients.log`。 |
| 故障关闭 | 独立 PostgreSQL 审计库停机时预检拒绝，不访问业务库也不交付结果；恢复后再次允许。ClickHouse 停机时记录错误终态、不交付结果，恢复后再次允许及脱敏。证据：`clickhouse-fault-orchestration.log`、`clickhouse-fault-recovery.log`。 |
| 回归 | 受控单元测试、真库 HTTP MCP、SDK 和 HTTP 工具注册回归通过；前端类型检查、构建和 56 项测试、三份版本 PDF 与网站本地静态 8/8 通过。Windows Docker 上全仓短测因管理 API 包异常缓慢而停止，不能记为本地通过；以 GitHub CI 的全仓短测和 vet 作为封版门槛。证据：`controlled-regression.log`、`clickhouse-final-targeted.log`、`go-short.log`、`go-short-serial.log`、`web-build-final.log`、`web-test-final.log`、`pdf-build-final.log`、`website-static-final.log`。 |

本版不支持任意 SQL、JOIN、聚合、视图、Distributed、表函数、写入、跨库、任务临时授权或审批执行。其他 ClickHouse 版本、复制/集群、证书轮换、长期负载、生产数据与完整生产支持未验证。公网 Live Demo 保持合成 PostgreSQL 数据，不开放公网 ClickHouse。
