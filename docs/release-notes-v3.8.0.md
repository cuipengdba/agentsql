# AgentSQL v3.8.0 发布说明

**语言 / Language:** [简体中文](release-notes-v3.8.0.md) | [English](en/release-notes-v3.8.0.md)

状态：已正式发布；完整结果见[发布证据](v3.8.0-release-evidence.md)。

## 本版能力

1. 指定 ClickHouse 26.8.31.2 单节点的 `query_analytics` 增加可选数据源预算：管理员可将每次读取行数从 10000 收紧到 100–10000、读取字节从 1 MiB 收紧到 64 KiB–1 MiB、内存从 128 MiB 收紧到 16–128 MiB。查询级设置要求溢出时抛错，元数据读取限制为 128 列。只读数据库角色须允许这些设置在约束上限内逐查询修改；缺少约束时请求失败关闭。
2. 指定 Milvus 2.6.25 单机的 `search_vectors` 增加可选行级租户范围。管理员指定静态 String/VarChar 租户字段及最多八个允许过滤字段；当前 Agent 的权威租户 ID 由网关提供。调用者最多提交四个获准字段的等值过滤，无法提交原生表达式或租户值。每个字段必须有精确列授权，命中结果再次核对租户及过滤值，内部校验字段不随结果交付。
3. Web 数据源页面可编辑并显示上述 `read_control_json`；中英文提示同步。原有 `{}` 配置和不带 `filter` 的 MCP 请求继续可用。
4. 前端构建工具锁定到 Vite 8.3.5、Vitest 4.1.12，并更新受影响的传递依赖；锁文件全量依赖审计无已知漏洞。

## 兼容与限制

本版没有 schema 迁移。Milvus 的租户 ID 与标量过滤值目前限 1–128 个 ASCII 字母、数字、点、下划线或短横线；其他字符直接拒绝。Milvus `{}` 路径只保留原有控制面租户隔离，不能宣称共享集合的行级隔离。ClickHouse `{}` 路径保留原有预算和角色要求。以上能力仅针对指定镜像版本、单实例、TLS、最小权限账号及合成数据；集群、任意 SQL/表达式、写入、客户生产负载和完整生产支持均未纳入结论。公网 Demo 仍只展示合成 PostgreSQL/MySQL 场景。

配置、升级和回退见[升级指南](v3.8.0-upgrade.md)；验收范围见[验收记录](v3.8.0-acceptance.md)。
