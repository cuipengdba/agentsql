# AgentSQL v1.7.0 验收记录

状态：**已发布**。以下记录瀚高 HighGo 9.0.10 指定实例测试；封版提交、CI、签名资产、升级恢复、GHCR、官网和 Live Demo 的实际结果见[正式发布验收](v1.7.0-release-evidence.md)。

## 指定实例与安全边界

| 项目 | 已验事实 |
| --- | --- |
| 实例 | 官方安装包构建的 HighGo 9.0.10 企业版，PG 模式，单实例 Linux x86_64 容器；本机镜像 ID `sha256:338d2708c76d283b90b81c64a45e16f76c18f2aa0a5f1c154857b1fd927b5a41`；授权检查到期日 2027-04-08 |
| 账号与数据 | 专用 `agentsql_v170_ro` 仅读取 `public.agentsql_v170_verify` 等合成表；数据库写入被拒绝；演示手机号为虚构测试值 |
| 身份校验 | 连接时由 `pg_catalog.highgo_version()` 返回精确 `瀚高数据库管理系统V9.0-企业版-9.0.10`，`ivorysql.database_mode=pg`，只读事务状态为 `on`；每条池连接均复核。普通 PostgreSQL 18 被拒绝冒充瀚高 |
| SQL 范围 | 显式 schema、单表直接列、非恒真 WHERE、LIMIT 的 SELECT；不继承 B2、B5 或 PostgreSQL 全量方言 |

## 已完成验证

| 场景 | 结果与证据 |
| --- | --- |
| 执行器与解析 | 真库连接、元数据、受限 SELECT、JSON EXPLAIN、写入入口拒绝及负向 SQL 集通过；普通 PostgreSQL 18 身份拒绝通过。`TestHighGoV9010Integration`、`TestHighGoRejectsOrdinaryPostgres`、`TestHighGoParserNarrowReadSubset` |
| Pipeline 与 MCP | 真库允许查询、未授权表 R010、手机号掩码、持久 allow/deny/error 审计、策略撤销及恢复通过。`TestHighGoV9010PipelineRealE2E`、`TestHighGoV9010MCPRealE2E` |
| 真实客户端 | MCP Inspector 0.16.8 CLI 与 Dify 1.17.1 MCPClient 各完成允许和 R010 拒绝；新增四条持久审计 ID 5–8；原始手机号未返回。`D:\CodexLS\outputs\agentsql-v170\highgo-clients-retry.log` |
| 数据库权限与停库 | 撤销只读账号 SELECT 后 MCP 不返回敏感结果并记录稳定错误码，恢复后重新掩码；停库、重启及池重连后仍返回掩码。新增审计码断言后的复跑通过：`D:\CodexLS\outputs\agentsql-v170\highgo-permission-outage-final.log` |
| 独立审计与锁等待 | 独立 PostgreSQL audit 暂停时结果不交付，恢复后审计与掩码重现；真库锁等待超时、客户端取消、数据库活动查询终止与稳定错误码通过。`D:\CodexLS\outputs\agentsql-v170\highgo-audit-lock-fault.log`，`TestVendorIndependentAuditFaultE2E/highgo-v9010` |

## 未验证范围

本版不声明其他瀚高版本或兼容模式、分布式拓扑、TLS、连接池故障切换、扩展类型、B2 列级绑定、B5 写入或生产负载。已完成的发行闸门不扩大上述数据库支持范围。
