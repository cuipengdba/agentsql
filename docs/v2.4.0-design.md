# v2.4.0 openGauss 7.0.0 LTS 指定实例设计

状态：开发中。上一正式版为 v2.3.0；本版仅对指定 openGauss 社区版实例建立可复核的受控只读链路。

## 用户问题与目标

目前 openGauss 只能借 `db_type=postgres` 完成一部分 PG 协议冒烟；其 `server_version_num=90204` 且缺少 PostgreSQL B2 closed query pack 依赖的系统目录。用户需要独立的数据源类型、明确的 SQL 与权限边界，以及身份、授权、执行、脱敏、审批、审计和故障关闭在真库上的证据。不能把协议互通或 RC 镜像结果写成 LTS 或 GaussDB 商业版的支持承诺。

## 指定环境与来源

- 使用[openGauss 7.0.0 官方容器安装文档](https://docs.opengauss.org/zh/docs/7.0.0/installation_guide/installing_the_container_image.html)给出的 x86_64、openEuler 24.03 归档 `openGauss-Docker-7.0.0-x86_64.tar`。官方归档同目录 SHA256 文件声明 `1b72ce6efc0d7885327a7d3daa72232081f40706bb3a7c4613e2f7e7347de3ee`；本地比对通过。加载镜像 ID 为 `sha256:d504c5d14049f225069c87a287931fe543122963d016a30023ee09653a9b5517`；运行中 `version()` 为 `openGauss 7.0.0 build 2397a86f`（编译时间 2026-09-23 00:09:53）。
- 容器仅绑定主机回环端口，使用随机合成数据库、表、手机号和专用最小权限账号。测试对象与凭据不得写入仓库、发布资产或公网 Demo。
- 已有官方 Docker Hub 7.0.0-RC3 镜像只作适配预检；它不能替代 7.0.0 LTS 验收。GaussDB 商业版、其他 openGauss 版本、主备和客户环境均需另测。

## 产品与安全合同

| 路径 | v2.4.0 目标及拒绝边界 |
| --- | --- |
| 数据源身份 | 新增独立 `opengauss` 类型。每个新建池连接都须验证服务端为指定 LTS build，且会话为只读；重连不能静默落到未知主机或模式。 |
| SQL | 仅允许明确 schema、`FROM ONLY` 单表、带 WHERE 和 1–10000 整数 LIMIT 的直接列 SELECT；`ONLY` 避免继承子表越权。多语句、JOIN、函数、聚合、CTE、系统对象、锁定读取、写入、存储过程及来源无法判定的投影失败关闭。不得继承 PostgreSQL B2/B5。 |
| 授权与审批 | Agent/租户/表策略和单次审批按既有合同逐次校验；策略撤销、数据库 SELECT 撤权后不得交付原始结果。未知审批状态拒绝执行。 |
| 结果与审计 | 允许查询只返回完成脱敏后的结果；无权表返回静态 R010。允许、拒绝、数据库错误和审计故障具有关联的持久审计；审计不可用时不交付查询结果。 |
| TLS | 仅在正确 CA 与主机名成功、错误 CA 与错误主机名失败的真库差分均通过后开放 `verify-full` 宣称。TLS 不可证明时保持关闭并在支持矩阵标注。 |
| 运维 | 验证超时/取消、业务库与独立审计库故障及恢复；使用 openGauss `gs_dump`/`gs_restore` 演练合成库备份恢复，同时从 v2.3.0 正式包演练 AgentSQL SQLite 和 PostgreSQL metadata/audit 分库升级及成套恢复。 |

## 发布阻断门槛

1. 真库最小权限直连与 HTTP MCP：允许查询、R010、unsafe SQL、脱敏、持久审计、审批、策略及数据库授权撤销，恢复后复验。
2. MCP Inspector 与 Dify 分别完成真实允许、拒绝调用；标明各自版本、协议入口和测试环境。
3. TLS 正反例、超时/取消、业务库/审计库断连及恢复通过；若某项未完成，不提升该子能力的支持声明。
4. 与上一正式版的兼容升级、备份恢复、Go/Web/网站回归、合并 SHA CI、双架构签名包、GHCR 匿名拉取、官网三份 PDF 和公网 Demo 按 [每版交付流程](RELEASE_ROUTINE.md)逐项验收。

## 不扩大声明

指定 LTS 单实例的受控只读路径不等于完整生产支持或厂商认证。B2 列级授权、B5 会话、写入、主备、证书轮换、长期负载、GaussDB 商业版和客户生产拓扑不由本版推定。公网 Live Demo 继续使用合成 PostgreSQL/MySQL 数据，不展示 openGauss 真库。
