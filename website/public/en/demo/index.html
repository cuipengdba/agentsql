Read the limits before entering the demo

This environment is only for trying the AgentSQL control console and six preset security scenarios. It is not a production service and does not connect to real business databases.

Never enter real data or secrets: Do not submit business SQL, personal information, database addresses, usernames, passwords, API keys, access tokens, private keys, or other confidential content.
  • Synthetic data onlyIdentities, orders, and audit records in the demo database are fictitious.
  • Read-only or controlled scenariosOnly preset read-only or policy-controlled scenarios are available. This is not a general database endpoint.
  • Regular resetDemo data and state are reset periodically. Do not rely on persistent storage here.
  • Non-production configurationAvailability, capacity, retention, and security settings are not production guarantees or an SLA.
